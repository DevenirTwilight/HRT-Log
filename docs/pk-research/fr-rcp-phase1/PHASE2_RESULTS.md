## 1. 口服 P4：相同数据在三个官方 RCP 中重复，绝不能算成三组外验

法国 UTROGESTAN 100mg、200mg 和 PROGESTAN 100mg 的第5.2节复用同一序列：同时口服两粒100mg，服前0.13、服后1/2/4/6/8h为4.25/11.75/8.37/2.00/1.64 ng/mL。应视作**一个重用观测集**，原始论文/受试者数量尚未找到，不可当作3个独立受试者组。

若以数学假设“给药前基线在8h内保持恒定”求群体均值的区段表观半衰期：

| 假设常数基线 ng/mL | 2→4h | 4→6h | 6→8h |
| --- | ---: | ---: | ---: |
| 0.00 | 约4.09h | 约0.97h | 约6.99h |
| 0.13 | 约4.03h | **约0.93h** | **约6.48h** |
| 0.26 | 约3.98h | 约0.90h | 约5.98h |

可见 4→6h 的迅速下降与 6→8h 的相对平尾同时存在，不能用“测到了一个真实 0.93h 清除半衰期”解释。**群体均值区段斜率不等于个体末端消除半衰期**，6/8h接近背景时，分析法、时间点均值及多通道吸收都会影响表现。下一轮应查原始人体研究/检测平台，并进行包含迟滞、多个输入通道的候选比较；不准直接把这些区段值塞进正式引擎。

## 2. ANDROTARDYL TE：证明模型结构有可行参数区间，也揭示基线不可辨识

ANSM 官方：250mg TE≈180mg母体 T，T 总浓度峰约20ng/mL、峰时1.5–3日；药库表观末端释放半衰期约4.5日；总T在第20日仍≥2ng/mL、第26日≥1ng/mL。试验在人群中观察到，个人基线与化验法未知。

探索**两个表观速率**核（不是已确定药理生理结构）：

`C(t)=B+(20−B)·[exp(−λt)−exp(−k t)] / max_t[exp(−λt)−exp(−k t)]`，其中 `λ=ln2/(4.5×24h)`，`k` 是早期*有效*上升参数，**不是**睾酮循环清除率；`B` 是假想的非负常数基线。

| 有效早期率 k (/h) | 模型峰时（天） | 同时满足第20/26天阈值所需最小假想 B（ng/mL） |
| --- | ---: | ---: |
| 0.025 | 3.049 | 0.224（略超官方峰时范围） |
| 0.030 | **2.725** | **0.305** |
| 0.040 | **2.270** | **0.485** |
| 0.050 | **1.963** | **0.618** |
| 0.060 | **1.738** | **0.703** |
| 0.070 | **1.566** | **0.762** |

第一阶段“一室快速清除+90/4.5天慢释放导致太早达峰”的反例，并不意味着 TE 不能建模；有一族形状可满足官方峰时和定性晚期阈值。**但此处 B 是从阈值反推的数学下界，绝不是实际内源T测定值**。同一受试者在不同日的总浓度、自由/总T及检测平台无法识别，不能拿它在正式应用中自动加“基础睾酮”。

## 3. NEBIDO TU：只用官方90±40天“释放半衰期”作为单一核，难解释首针与多针

官方：1000mg TU≈631.5mg母体T。首针群体均值峰约11ng/mL、7日达峰，第二针第42日、随后70日间隔；第二针峰约15ng/mL，第3–5针附近稳态群体峰/谷约11/5ng/mL。末端释放半衰期**90±40天**。不同时间的群体汇总不可强制等同于一人的完整时序。

先固定**数学候选**首针 7日峰和11ng/mL（假想B=0），让两个表观指数核的慢速率等于相应释放半衰期，在第0、42、112、182、252天加上真实给药历史；比较第五针后约70天的峰/谷：

| 假设慢过程半衰期 | 第五针模拟峰 ng/mL | 第五针模拟谷 ng/mL | 无限多针数学稳态峰/谷比上界（B=0） |
| --- | ---: | ---: | ---: |
| 50天 | 17.90 | 7.58 | 2.36 |
| 60天 | 19.89 | 9.69 | 2.05 |
| 70天 | 21.78 | 11.73 | 1.86 |
| **90天** | **25.17** | **15.53** | **1.62** |
| 130天 | 30.48 | 21.78 | 1.40 |

这里“慢过程半衰期”等于整体浓度核的慢速率是**特定假设**，官方原话只说肌注药库释放特征，不能默认它占全部有效 T 暴露。强烈累积只是该模型失败的证据，不是 RCP 错误，更不是预测个人使用 NEBIDO 的真实数值。

### 探索多时间尺度：1260组候选，负面结果也保留

在固定初次7日达峰前提下，将归一化的“快释放核”（假设 5–40日的多个网格值）与90日慢核按其**峰值权重** `w=0,0.025,…,0.5` 组合，并对非负常数基线 `B=0…5` 做有限网格。用RCP的第二针约15、第五针峰约11、谷约5 ng/mL这**三个已经看过的群体近似值**计算等权平方误差：

- 1260 组中最小样本内误差情景：假想快过程半衰期25日、B=3、**90日慢核的峰值权重为0**；第二针预测13.70、第五针峰12.45、谷4.75 ng/mL，SSE约3.852 (ng/mL)²。
- 保留正的慢核权重 `w≥0.025` 时最小：快过程25日、B=3、w=0.025；预测13.78 / 12.67 / 4.98 ng/mL，SSE约4.276。
- **关键含义**：这些摘要统计不支持辨识一个唯一的90日慢核比例；最小样本内 SSE 甚至选择0，**绝不是证明NEBIDO不存在90日释放过程**。模型候选和参数网格是看到官方数据后制定的，没有独立外测。零残差不可能成为准入要求：任何正的非负残留给药核，稳态峰都必大于第一针峰，而官方两者都约11，说明摘要有舍入、群体/测定或模型假设差异。

**禁止将上述25日/90日参数作为生产 TU PK 曲线**；它们只是可辨识性压力测试。

## 4. 睾酮凝胶：法国官方证明产品特异性和涂抹部位差别

ANSM TESTAVAN 20mg/g RCP第5.2节：

| 第90天经调整剂量组 | N | 总T Cavg (ng/dL) | 总T Cmax (ng/dL) | 中位 Tmax |
| --- | ---: | ---: | ---: | ---: |
| 23mg | 5 | 368 | 721 | 4.02h |
| 46mg | 45 | 506 | 1228 | 2.02h |
| 69mg | 89 | 438 | 1099 | 2.08h |

- 69mg剂量组均值 `438/506≈0.866`，比46mg组低。**这是按既往化验结果调整剂量的非随机独立分组，不是个人剂量-暴露反常规律**，不能用它直接拟合单调剂量响应或反驳剂量相关性。
- 部位比较：肩/上臂 vs 腹部 Cmax≈926/451=**2.05**、Cavg≈557/372=**1.50**，表明涂布位置/制剂暴露可显著影响曲线；不等于已知个体乘数或能跨产品套用。
- TESTAVAN RCP称应用后约12h总T接近给药前水平；ANDROGEL 1%和16.2mg/g则说明停药后约24h开始下降、最后一次应用后72–96h恢复基线。**“给药前水平”与“停药后返回治疗前基线”不是同一种终点**，不能因为词面相似就强行证明两种凝胶有12h vs96h的精确清除差异。
- ANDROGEL 1%50mg平均T增量约2.5ng/mL；16.2mg/g下2.5g（含40.5mg T）约+2.2ng/mL；这些也是不同产品/群体条件，不能以比值直接获取吸收系数。现有引擎无T生产曲线，研究仍未形成有可信绝对幅度的个人T凝胶预测。

## 下一步：保证“真正曲线”不是“峰值拼接曲线”

1. **P4**：查原始UTROGESTAN/PROGESTAN共用研究、分析法、受试者数字及不同途径；只在有充分时序的产品层级拟合与外验，保留现有模型作负例。
2. **TE/TU**：有原则地查完整连续采样的人体单针和多针PK数据，识别有效释放 vs 实际母体T清除，明确研究人群和总/游离T；不同候选形状与人群/剂量史、基线联合敏感性分析，不用未经验证的单点归一化当正式数据。
3. **T凝胶**：按品牌/配方分组，尽量找到包括每人用药历史和多时点连续T、基线及涂布部位的原始数据；避免不同制剂和调剂组的汇总均值直接拟合。
4. **其他雌二醇酯和途径**：继续查 EMA、其他国家官方数据库与论文；每剂型区分支持充分、可研究但无外测、无足够模型依据三级状态。
5. **工程禁区**：未满足独立来源和长期兼容性验证之前，不改正式曲线或 LabFit，不改保存的化验/旧 PDF，不向用户建议用量；无 INTERNET、四语、签名和 APK 交付规则继续保持。
