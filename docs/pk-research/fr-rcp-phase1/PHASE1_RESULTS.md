# P-FR-01：法国 ANSM 药代曲线独立研究，第一批数值结果

日期：2026-10-30。状态：**RESEARCH_ONLY / NOT_PRODUCTION / NO_CLINICAL_VALIDATION**。本文件为持续研究首批阶段，不等于“全剂型已完成”。所有观察数据来自官方 RCP §5.2，精确链接、剂型、原单位、数据语境见 [anchors.json](anchors.json)；独立计算复核记录见 [numerical-audit.json](numerical-audit.json)；可复算源码见 [fr_rcp_phase1.py](../../../tools/pk-research/fr_rcp_phase1.py)。

## 源码基线与计算原则

- 直接读取生产 `pk-engine/src/main/resources/pk-params.json`（核对 blob SHA `f0ce49f09da31286f538affd9977ff36c26e272d`）；没有改动该文件或 `Engine.kt`。
- HRT Log 现有单位剂量响应为 `dose * Σ A_j * [exp(-λ_j t) − exp(-ka t)]`，每天间隔 24h 线性叠加前 30 次剂量；0–24h 以 0.05h 梯形积分取均值及峰谷；第一天只放一次药。
- 这是**无基线的模型给药增量**。RCP 通常给的是受试者**总血清浓度**；两者不能直接等同。Cmax、Cmin 往往也是组汇总统计，不保证是同一受试者的配对观测。
- 各官方药代观测受制于妇女绝经状态、男性性腺功能、共服药、车辆/涂布部位、检测方法、采样频率等；未经调整不构成跨人群临床外测。
- Python 重现：`python3 tools/pk-research/fr_rcp_phase1.py --out docs/pk-research/fr-rcp-phase1/recomputed.json`，脚本只用 Python 标准库。**本轮未在完整 Git 工作树执行上述命令**；现有 `numerical-audit.json` 来自 GitHub 精确源码参数的独立 JS 数值复核，P4 的 SSE/网格最小值又通过本地 Python 标准库独立复算一致。没有谎称 Gradle/设备/CI 通过。

## 1. 已有口服 E2：群体统计均值吻合，但不能据此获科学认证

| 每日口服 E2 | 法国 OROMONE 官方稳态观测（pg/mL） | 现有模型无基线增量（pg/mL） | 比较 |
| --- | --- | --- | --- |
| 1mg：Cmax / Cmin / Cavg | 48 / 20.8 / 31.8 | 41.288 / 19.758 / **31.937** | Cavg 数值近似，峰值偏低；模型 Tmax 5.65h，官方范围 4–6h |
| 2mg：Cmax / Cmin / Cavg | 89 / 35 / 62.9 | 82.577 / 39.515 / **63.875** | Cavg 数值近似，峰/谷振幅高于官方，未考虑基线 |

特别警惕 OROMONE RCP 本身写“稳态”但单剂量表述并列，需澄清采样设计。官方亦报告 E1/E1S，它们是**不同分析物**，不得加到 E2 的 pg/mL 上冒充 E2。

**结论**：维持 `E2_ORAL` 现状，增加多剂量、多产品和盲法时序外测；“平均值接近”不表示完整动态曲线准确。

## 2. 已有 EV_ORAL：峰谷幅度相近，绝对观测整体偏高

DUOVA 1/2mg 的 E2 官方单位是 pmol/L；统一按 `1 pg/mL ≈3.671 pmol/L` 换算，药片同时含有醋酸甲羟孕酮 5mg。

| 每日口服 EV | RCP 总 E2 Cmax/Cmin/Cavg（pg/mL） | 模型无基线增量（pg/mL） | 峰谷差：官方 / 模型 |
| --- | --- | --- | --- |
| 1mg | 45.219 / 27.513 / 33.506 | 31.655 / 14.630 / 23.999 | 17.706 / 17.025 |
| 2mg | 83.901 / 46.581 / 62.108 | 63.311 / 29.260 / 47.999 | 37.320 / 34.051 |

**发现**：峰谷跨度较近，不能排除总血清 E2 中基线的影响；但这**不等于**已证明基线是唯一原因，也不能用 DUOVA 随意重标定纯 EV 口服或舌下 EV。待核对检测方法、年龄、内源浓度、共服 MPA 的影响。

## 3. ESTREVA：通用核恰好接近产品级统计，优先验证而不是盲目重做

官方：腹部 400cm²、单次/每日 1.5mg ESTREVA，单次平均峰约 40 pg/mL；第 22 天平均峰约 70，末次应用后 24h 约 40；约第 4 天达稳态。

| 模型（1.5mg） | 单次峰 pg/mL | 第22天峰 pg/mL | 第22天 +24h pg/mL |
| --- | ---: | ---: | ---: |
| ANSM 观察值，**总 E2** | ~40 | ~70 | ~40 |
| `E2_GEL_OTHER`，**增量** | 39.014 | 69.108 | 35.277 |
| `E2_GEL_ESTROGEL`，**增量** | 23.984 | 66.296 | 45.538 |

`E2_GEL_OTHER` 此前靠两个其他凝胶模型的几何中间参数构造，“ESTREVA 没有数据”的备注已被新官方证据否定。**数值巧合吻合不是独立验证**：观察值总浓度、未知基线、同一模型可能跨产品偶然吻合。不得默默将 OTHER 改名 ESTREVA 后宣布已证明。下一步从产品 RCP 原研究获得更密集时序；再判定是否为 ESTREVA 新增产品分派，保持其他不明制剂的保守回退。

## 4. P4_ORAL：尾部与法国 UTROGESTAN 时间序列差异明显

法国官方：200mg 口服，服药前平均 0.13 ng/mL，服药后 1/2/4/6/8h 浓度依次 4.25/11.75/8.37/2.00/1.64 ng/mL。用于此处对照的假设是把给药前 0.13 ng/mL 视为 8h 内不变的基线；官方没有给出个体时间序列和分析方法。

| 服药后（h） | RCP 均值减0.13（ng/mL） | 现有 `P4_ORAL` 模型增量 |
| --- | ---: | ---: |
| 1 | 4.12 | 10.720 |
| 2 | 11.62 | 11.611 |
| 4 | 8.24 | 10.292 |
| 6 | 1.87 | 8.884 |
| 8 | 1.51 | 7.663 |

5 点 SSE ≈ **134.818 (ng/mL)²**；均方根偏差 RMSE ≈ **5.193 ng/mL**，只反映本组在给定基线假设下的描述性拟合误差，**不代表临床模型准确度**。

探索性的 455 组受限双指数 + 共享吸收率候选网格，在**全部 5 个点均用于拟合**时，最低 SSE ≈ **23.853**（RMSE ≈ **2.184**）。最佳解 `ka=0.6/h`、快相 `λ=0.4/h`、系数约 0.30526 ng/mL/mg，**慢相系数恰为0**；它在 1h、2h、6h 等点仍显著不匹配。不能把“两个指数”叙述成经证实更好，也不能把该样本内改善冒充独立验证。下一个候选研究应比较延迟吸收/transit、强烈变异与不同检测法，而非直接投产这组参数。

## 5. T 注射剂：两项模型结构压力测试（不是临床 T 曲线）

**ANDROTARDYL TE**：官方肌注 250mg TE≈180mg T，峰值约 20 ng/mL 发生在 1.5–3 日后，药库释放终端表观半衰期约 4.5 日。作为**跨产品、跨人群的反事实数学实验**，若同时强行使用 NEBIDO RCP 老年男性静脉 T 消除半衰期 1h、并假设单级药库释放，则 Bateman 核达峰约 **6.818小时**，明显早于 36–72h。这说明模型需要研究延迟/多阶段释放；**不能证明** TE 本身真实消除为1h或直接宣称官方数据矛盾。

**NEBIDO TU**：RCP 1000mg TU≈631.5mg T；首针 7 日平均峰约 11ng/mL，随后有 6 周载入与 10 周维持；维持约 11/5 ng/mL 峰/谷；释放半衰期 90±40 日。若构造**固定90日单指数、70日间隔、无负基线**的纯数学过程，其峰谷比上界 `2^(70/90)=1.7145`，低于官方总浓度组均值比 `11/5=2.2`。但 90±40 日包含更多形态和不确定性，且组汇总峰谷未必是配对比值，故**不能据此否决所有一室模型**；需分离中心清除、油剂释放、多剂稳态、基线和统计口径。

两种 T 的化验数据是**总睾酮**，不是药物导致的“增量”；不能将 CPA、SPI 浓度充当 T 抑制量，也不能凭 T→E2 转化发生就自动绘制 E2 额外贡献。
