# P2-AW — 未知背景/幅度下的独立舌下 E2 采样设计：冻结模型形状几何与时钟误差

**研究日期：2026-10-11。研究状态：MODEL-BASED DESIGN AUDIT / NOT A HUMAN TRIAL / NO CLINICAL POWER CLAIM。**

## 1. 为什么做本研究

P2-AR-REAL / P2-AU 已在 Yaish (VNC54) 11 名参与者、20 次配对访视的既有数据上证明：每日四次给药实际时钟、背景和增益未知时，仅给药前与名义 90 分钟采血不能裁决 Legacy 与 M2 的个人预测准确性。P2-AV 筛查的公开队列尚未提供冻结后可直接使用的完整独立人体 SL E2 浓度时间序列。

本阶段的问题不是“把现有已见数据再调到更好”，而是 **在取得新人体数据以前，先量化哪些观测时点有助于区分冻结的两类形状，并明确这种判断不能替代真实人体数据、检测误差、临床授权。**

- P2-X 冻结参数：内部 JSON SHA-256 `7bb08b9e5b397e766cd63018567542520105755c9e578a8cdf4204a6df8d5367`，共 40 组历史候选，按历史 `score ≤ global_best_loss + 0.10` 保留 15 套，不使用新数据选参或重拟合。
- 本次**不读取 OSF 逐人医疗 Excel**，没有新受试者、真实给药史、时点实际血样或实验室结果；全部是假定单次 1mg 剂量的归一化形状 `H(1h)=1`，未换算绝对浓度，也未模拟长期稳态。真实药物暴露和测定平台不可由这里反推。

## 3. 数学：将未知基线与浓度增益作为干扰参数

采样时点向量上，两个理论模型均可有自己的未知常数背景 `b` 与正增益 `G`：`Y_i = b + G H(t_i) + ε_i`。先不设定误差分布或检测阈值，仅在理论形状上考察消去仿射 nuisance 后仍剩多少差异。

定义 `ρ = corr(H_L(t_i), H_M(t_i))`（对时间向量先去均值），当 `ρ>0` 时使用 **`d = sqrt(1−ρ²)`**，否则将不允许负增益的对应残差设为 1。`d` 在 0–1，接近 0 表示给定时点上两形状几乎可由常数加正倍数互相表示。每套设计报告 15 个冻结 M2 对 Legacy 的 **最小 d**（最难区分的候选），以及 15 套 M2 两两之间 105 组的最小 d。

重要限制：这个标量隐含对所采时点等权、同等量纲形状归一、无已知测量协方差和先验背景约束；**不是 p 值、预测误差、power、AUC、置信区间或预期临床优劣**。不同采样数量或时间跨度下 d 的数值不能直接等价于固定绝对 pg/mL 噪声下的鉴别效能。

因为包含 t=0、1h 作为设计锚点，两个时点上的仿射差异可以完全消去（两模型均 H(0)=0、H(1)=1），因此 `d=0`。第三时点可以开始检验曲率，但不保证唯一识别多参数 M2。

## 4. 关键计算结果（无量纲）

候选时间网格为给药后 `0.25,0.5,0.75,1.5,2,3,4,6,8,12,16,24` h（另固定 t=0、1h）。下面的 d 均为 **Legacy 相对 15 套 M2 的最小仿射形状差距**，不是个人浓度变化、准确率或临床概率。

| 理论测点 (h) | 最难区分候选 d | 描述 |
|---|---:|---|
| `0,1` | 0.00000 | 两点完全可被背景+幅度吸收 |
| `0,1,0.25` | **0.44583** | 名义网格中一个额外点的最大分离 |
| `0,1,0.5` | 0.32449 | 早期第二例 |
| `0,1,2` | 0.26306 | 早期下降段也有区分信息 |
| `0,1,8` | 0.03432 | 单独较晚测点的这一几何指标较小 |
| `0,1,24` | 0.00038 | 24h 形状幅度很小，易被基线/增益吸收 |
| `0,1,0.25,0.5,2` | **0.48889** | 预定义 0–8h 网格搜索中三个额外点的最大最小 d |

具体 15min 对照：Legacy 的 `H(.25)=0.52921`，冻结的 15 套 M2 给出 `0.05899–0.10452`；这是**历史模型间的结构差别**，不是今天新发现的人体 15min E2 值。

### 时钟误差敏感性（不能忽视）

将新增的一个采样时刻人为改为 `t−0.25h,t,t+0.25h`，固定 0 与 1h，取三者最小 d：

| 新增标称测点 | 名义 d | 人为 ±15min 最小 d |
|---|---:|---:|
| 15min | 0.44583 | **0.00000**（若实际在给药前 0min，和基线重复） |
| 30min | 0.32449 | 0.00185 |
| 2h | 0.26306 | **0.22732** |
| 8h | 0.03432 | 0.03288 |

这里的 ±15min **不是实测的时间记录误差分布**。这个应力测试不证明 2h 一定是临床最佳采样点；它只表明早期“几何优势”依赖精确采样和真正的给药起点，不能在缺少时间戳时兑现为可靠预测区别。

### 为什么长尾仍要采

冻结 M2 在 24h 的 `H(24h)` 为 **0.000663–0.044764**（约 **67.5 倍**）；Legacy 约 **0.000230**。相对范围很大，但全部是“1h 单剂增量归一为 1”的微小尾值，不能当作 pg/mL 检出概率。**如果目的包括核实慢速输入/多次给药谷值，就需要真实 8–24h 的血药数据、检出限、基线与既往给药史；仅追求 Legacy/M2 的早期分离分数会偏离这个目标。**

即使在理论分离较大的早期组合 `0,1,0.25,0.5,2`，15 套 M2 内部最难区分两套形状的 d 仅 **0.00446**；这不是模型内部参数可辨识性的证据。

## 5. 对既有文献、下一次资料获取的具体意义

- **Doll et al. 2022, PMID 34781041, NCT04036500**：发表的方案/方法采样为给药前、1、2、3、4、6、8h，10 人交叉比较、LC-MS/MS 与免疫测定；没有 15/30min 和 12/24h 的采样。实际逐时 SL 组原始数值未在本轮取得；只用论文所报告的峰值 144 pg/mL 或 AUC 比值无法复算本阶段的理论形状差异。原文：https://pubmed.ncbi.nlm.nih.gov/34781041/ 与 https://www.sciencedirect.com/science/article/pii/S1530891X21013744 。其 2020 会议 n5 为同队列早期分析，不可作为第二项独立资料。
- **Price et al. 1997, PMID 9052581**：已有 0、1、2、3、4、6、8、12、18、24h 的历史计划采样，虽覆盖较晚点，但本项目已在开发中见过其图和汇总。不同剂量来自相同六人；RIA 与 LC-MS/MS 不可未经桥接混算。来源：https://pubmed.ncbi.nlm.nih.gov/9052581/ 。
- **Rosano 1997 与 Komesaroff 1998**：有很早的组级观测，但来源已见、统计协方差不完整，不能将跨研究散点拼成“一个新病人的完整早晚曲线”。
- **TREAT NCT05010707**：公开的是重复给药次晨谷值，没有可用的峰后多时点曲线；与上面的单次理论形状设计不是同一个 estimand。来源见 P2-AV 研究目录。

**非个人化、优先索取字段：** 对研究者先请求每个正式 SL 分组、分析物 E2、制剂/剂量、准确给药零点/观察窗、实际采血时刻、每时点 n、均值+SD（注明 SD/SEM/CI）、基线扣除方式、检测方法/LLOQ、删失处理、AUC 的实际统计口径、数据再使用/公开派生汇总的许可。若获得配对/纵向个体数据，须限于伦理及许可范围，使用受保护的数据环境；不可公开患者行、标识符、数据字典中敏感字段。

对**将来真正新的独立人体队列**：在取得受试者浓度之前冻结 Legacy/M2 参数、候选选择、采样分组、受试者/队列独立性、真实时钟、原始/扣基线策略、幅度是否允许校准、误差评分、排除/缺失/LLOQ 处理，并预设失败标准。冻结后才能称为锁定的外测；在 P2-AR / AU / AW 看过的研究不能重命名成 `LOCKED_EXTERNAL`。

## 6. 复现证据与终态

- 程序：`tools/pk-research/p2aw_sampling_design.py`，仅 Python 标准库；严格复核原始 P2-AS ZIP、内部 P2-X 与 Legacy 三层 SHA-256；拒绝覆盖已有结果。
- 回归：`tools/pk-research/test_p2aw_sampling_design.py`，20 项非个人数据数学单元测试、冻结参数/批次、边界、时钟扰动、输出逐字节一致检查。
- 机器结果：`docs/pk-research/p2/p2aw-identifiability-design/p2aw-geometry.json`（确定性输出；公开浮点字段为小数点后 9 位，SHA-256 `ecb62798eb785d2c4ae6aca48a2dd5a2b0a6b4f65fd4b7fe8ed875271819df90`）。内部模型求解与排序始终采用原始 double 精度。2026-10-11 首次 GitHub 3.11 重算发现 Python 3.13 机器 JSON 浮点末位不同；原版字节比较失败，这是有效的复现门槛反馈，而非模型数值结论被推翻。已增加统一输出舍入并重新跑 CI。
- 自动化：`.github/workflows/p2aw-sampling-design.yml`，从 GitHub 归档的 P2-AS 原始 ZIP 重算并逐字节对照已提交 JSON；单独的 Android/JVM/模拟器 CI 只确认应用未因研究文档受到破坏。

**本研究结论：** 不可以只凭两点给药前后数据判定候选优劣；增加早期真实时间点在冻结形状上可提高区分 Legacy/M2 的数学能力，但若准确时钟无法验证，其信息量可退化；完整长尾与稳态仍需要测量质量和给药历史。没有获得新独立人体临床外测、未为单一人的绝对 pg/mL 标定、没有验证晚期预测覆盖。**P2-C 仍为 HOLD，生产 E2_SL、Kotlin 引擎、数据库、APK 均不变。**
