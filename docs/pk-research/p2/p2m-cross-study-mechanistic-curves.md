# P2-M：跨人体研究舌下 E2 曲线形状的可辨识性测试

2026-10-09。研究问题由用户明确提出：HRT Log 的舌下人口核不能永久把 Doll 2022 的 1mg/1h/LC-MS/MS E2=144pg/mL 当作唯一标定点。Featherline相较HRT在Price1997多个原文AUC与早峰上的支持性证据见[P2-K公平比较](p2k-featherline-hrt-balanced-evidence.md)；但Doll也与Featherline有偏差。**P2-M既不依据Doll定标新形状，也不以任何单个作者的端点决定赢家。**

## 1. 独立来源，而不是拼接虚拟受试者

Rosano1997 的独立PK25人、1mg SL，10/20/40/60min E2组均值234/468/1980/2124pmol/L，SD56/115/456/568。**这25人的给药前E2均值没有得到核实**；不能使用另一个n9心血管干预队列的给药前基线。Komesaroff1998 独立n10健康男性、2mg SL Estrace，0/15/30min E2组均值89.4/486.6/1969pmol/L，SEM9/218/302。采样分析法、性别、制剂、给药剂量不同，因而两项研究不能被硬拼成同一人的血药曲线。

Price1997 n6同人交叉，1mg SL原版Figure1中1h约450、2h约225pg/mL，均为此前P2-I的**人工群体图形估读**，真实给药前基线未知。Price Table1的基线扣除AUC0–24=2109±1031pg·h/mL与原图积分约1558存在未解释的来源内部差异。Price只用于已经暴露的研究后**形状迁移反证**，不参与本轮早期形状参数优化。Doll2022的144、Yaish2023的mean谷与median90min、Yager/Abdelmawla同一个TransPrEP队列各自继续保留证据身份，但不参加这项两研究早期形状定标。

## 2. 最小数学原型：两研究共享形状，保留不同基线与有效幅度

定义 gamma-shaped group curve 原型：

    h_n(t;k)=t^(n-1)*exp(-k*t), n>=2,k>0
    C_s(t)=b_s+A_s*h_n(t;k), A_s>=0.

令两项早期研究暂时共享同一 n 与 k，但各有研究自己的A_s。这里有效幅度不等于实际黏膜吸收比例、F、生理容积分布或LC-MS/MS至RIA校正因子；这是对共享曲线形状零假设的压力测试，并不是生理分室数的确定。Rosano未知b_s假设扫描0/25/.../225pmol/L，Kom使用本研究已公布89.4pmol/L组均值。归一化 h(t)/h(1h) 简化数值稳定性。

遍历n=2..9、k=0.25..12/h步长0.25，对各项研究独立求有效幅度非负约束下加权最小二乘。Rosano将原文SD除以sqrt(25)作**边际SEM**，Kom用其原本的SEM；计算每组时点的平均平方边际SEM缩放残差，再将两个组分数相加。**因为同一人的多时点协方差未知，这不是有效多元似然或卡方检验；对高阶模型的选择不具有统计显著性，也没有惩罚额外的研究级基线灵活性。** 人体各组SD、测定偏倚、随机给药时间可能改变这些结论。正式协议、离散参数范围记录在[p2m-study-shape-design.json](p2m-study-shape-design.json)。

## 3. 可重复的跨研究计算：基线假设令结构偏好跳变

| Rosano允许的最大b (pmol/L) | 探索性最低伪损失n | k(/h) | 选取b |
|---:|---:|---:|---:|
| 0 | 3 | 1.25 | 0 |
| 50 | 3 | 1.00 | 50 |
| 100 | 4 | 2.50 | 100 |
| 150 | 5 | 4.00 | 150 |
| 200 | 7 | 7.00 | 200 |
| 225 | 8 | 8.50 | 225 |

同一套模型与两组相同的发表结果，只因Rosano真实b未知，偏好就从3阶跳成8阶；最宽松情况下b225几乎与其10min组均值234相等。**模型利用未知基线吸收掉首个浓度点，结构与k的可辨识性很弱**，不能宣布八级吸收生理机制被发现。

进一步，最宽松假设n8/k8.5/h的1→2h归一化增量比为

    h(2)/h(1)=2^7*exp(-8.5)≈0.0260。

Price的已见原版图1mg SL人工1h约450、2h约225pg/mL，如果人为尝试b=0/25/50pg/mL，扣除恒定b后的比率约0.500/0.471/0.438。一个为Rosano/Kom早期形状拟合的尖锐单gamma，在1→2h衰减得过快；但这比较仍跨人群、分析法、制剂，且Price图是人工估读而非可计入独立统计验证的数据。相反，较严b=0下n3/k1.25，其2h/1h比≈1.146，表示1→2h仍增加，与Price原图下降方向又不合。**纯粹追求两项15–60分钟组均值的拟合，未得到一条跨第三研究自然迁移的统一曲线。**

## 4. 两套冻结模型的形状也需要直面负证据

以相同已公开组均值比较，Rosano总浓度40/20=4.231倍；Kom使用本研究群体基线89.4pmol/L扣除后30/15≈4.732倍。冻结HRT增量20→40min比≈1.433、15→30min≈1.558；冻结Featherline80kg则≈1.439、≈1.554。**两套单次直接吸收核都无法精确复现早期研究的组均值中心变化**，而Featherline仍有在Price AUC比HRT更接近的支持性证据，不能隐瞒任何一面。

需正确解释统计不确定性：Rosano边际点均值±1SEM的比值敏感性约3.85–4.65，已跨过三阶核的形状上界4，不能因中心均值4.23就声称总体统计显著排除三阶核。Kom的15min SEM218很大，配对相关性、基线误差也未知。数学结构上，任何单一正权重零延迟二级gamma浓度核的2t/t比严格小于2；但对人群参数异质性/时间采样、检测偏差实际仍需要研究验证，而不是用平均值直接证明特定生理lag。

## 5. 下一代药代曲线的严谨候选结构（尚未拟合、投产）

建议先保留受限双输入与一个系统消除尺度：

    I_fast(t)=D*G_f*GammaDensity(t;n,k_f)
    I_slow(t)=D*G_g*k_g*exp(-k_g*t)
    dX/dt=I_fast(t)+I_slow(t)-k_e*X(t)
    E2_measured(t)=baseline_s+X(t)/V_effective.

研究级观测层允许经证据支持的分析法/人群差异，但不可在只有摘要汇总时自由调整n、所有ka、ke、lag、吞咽份额、F和V。**能从浓度识别的通常是G_f/V与G_g/V等有效幅度组合，并非真实吞咽比例或每个微观参数**。第二分布室只有在0–24h高密度数据足以区分慢吸收和真实分布时才考虑。

接下来需要独立、准确标注给药历史/制剂/含服与检测法、给药前实测基线、早期0/10/15/20/30/40/60/90分钟、中晚期2/3/4/6/8/12/24小时E2（优先LC-MS/MS）的合法去标识人体数据。上述时点是理想研究设计建议，不是目前确实存在的研究资料。还应核实Doll真正全文、Price群体基线和AUC方法；这些不会自动赋予已见数据盲测身份。
