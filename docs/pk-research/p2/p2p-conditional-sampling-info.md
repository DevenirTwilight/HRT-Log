# P2-P：哪些新增采样时刻才可能区分快慢输入和重复给药长尾？

研究日期：2026-10-09。**仅面向将来规范人体PK研究的可观测性问题，不是对任何用户的验血时间、用药时间或剂量建议**。这轮沿用[P2-O已公开的11,088组参数网格及其筛选规则](p2o-slow-tail-parameter-scan.json)，不根据Doll2022 144pg/mL重新标定，不动已交付APK、HRT Log生产E2_SL、个人校准、历史数据、P5–P95、旧P2-A/B冻结试验。

## 1. 为什么“抽得更晚”不保证一定更容易鉴别

P2-O以Rosano1997独立n25PK组20→40min原始E2均值增长和Price1997同六人试验Figure1人工群体估读2h/1h、4h/1h比值（未知真实基线）作**已见来源的非统计筛选**。在假设Price基线0pg/mL时75个数学候选通过，且它们预测的0.5mg严格每6h给药前增量、相对1mg单剂1h增量，最高/最低约差6.89倍。真正问题是：**如果还能在同一实际受试者获得少数新的、可信的血样，哪个时点在这些数学候选间最具区分能力？**

本轮没有任何新的人体血样、个体给药时钟、抽血计划审批、测定方差、真实样本量或同人协方差。所有给出的数值都是**模型对模型**的差异。尤其不允许把计算挑出的时点说成临床最佳验血时间。

## 2. 严格定义一个可复算但有明显局限的“辨识”玩具指标

每个候选从P2-N机制模型的单剂增量形状h(t)取 **H(t)=h(t)/h(1h)**，全体都是无量纲，1小时人为统一为1，**没有把Doll的1h=144pg/mL（或Price450pg/mL）加入任何模型**。

对一对候选i,j，在计划增加的所有时点t，若预测的绝对差值都满足

    |H_i(t)-H_j(t)| <= delta,

则称其在本次玩具实验中“尚未区分”（unresolved）。仅计算无序候选组合，总对数N(N-1)/2，**不是患者人数、不是独立观察次数或统计p值**。各场景delta取0.01、0.02、0.05个归一化1小时增量；**delta是模型间差异的条件判别阈值，不等于±delta临床测量误差，更不是检验精度、LLOQ或置信区间**。若把真实两次测量均有的误差和基线误差纳入，通常会更难分辨。

另记录尚未区分的候选中有多少对的未来**q6给药前模拟累积增量相差至少2倍**。这里“2倍”是后续模型预测歧义的探索性定义，不是临床重要性已证实的阈值。

关键的**乐观前提**：未来研究必须独立测量同一真实受试者给药前E2基线与1h给药增量，且有可比测定方法、准确服药/采血时刻；否则假设各候选的H1可统一比较本身就不成立。一个未知研究级倍乘尺度A及未知基线b，只用两个晚期绝对浓度读数，通常不足以识别曲线形状。更不允许假设真实血样能够直接显示归一化增量。

## 3. 计算结果：选6/12h或6/10h是当前假设下的候选，并非24h永远没价值

考虑新增4、6、8、10、12、16、18、24h候选时点。在Rosano和Price现有筛选、Price人为b=0、delta=0.02下，75个候选构成**2775对数学模型**：

| 再增加的测量时点（以给药后计） | 尚未区分的模型对数 / 2775 | 其中未来q6谷增量差至少2倍的模型对 |
|---|---:|---:|
| 8h | 1318 | 121 |
| 10h | 1368 | 81 |
| 12h | 1572 | 73 |
| **24h** | **2467** | **761** |
| 4h + 10h | 738 | 50 |
| **6h + 12h** | **1006** | **36** |
| 8h + 12h | 1163 | 37 |
| 8h + 24h | 1242 | 72 |

即使24h晚尾理论上对慢输入更敏感，在**绝对增量非常低、存在固定绝对区分阈值**时，很多24h预测同时趋近于0，24h单点反而更难分辨。在这一乐观的delta=0.02模型集合中，仅允许增加6h及之后两点时，**6+12h是按总尚未区分对数和大于2倍q6歧义数量都表现较优的组合**（只在本轮给出的离散候选时点内）。4+10h按**总**尚未区分对数更优，但4h正是之前已见Price原图筛选条件之一；在未来独立人体研究重新高质量测4h可能改善其可信度，却不能假装之前的4h没有参与模型筛选。

还必须完整披露敏感性结果：

| Price人为b（pg/mL） | P2-O筛选后候选数 | 允许选≥6h两时点时，按“总未区分模型对最少”得到的组合 | 24h单点尚未区分对数（delta=0.02） |
|---:|---:|---|---:|
| 0 | 75 | **6+12h** | 2467 / 2775 |
| 25 | 97 | **6+10h** | 4317 / 4656 |
| 50 | 62 | **6+10h** | 1891 / 1891 |

这三个所谓基线是人工试探而非Price受试者的真实0h。Rosano n25真实基线同样尚未获得，因此这种排序绝不是独立于先验的人体抽血方案。改动阈值也会明显影响结果：在b=0下，8h单点的尚未区分对数在delta=0.01/0.02/0.05分别为745/1318/2485；而24h单点在delta=0.05时所有2775对都未被区分。

### 3.1 原P2-O相似曲线配对A/B的特例

P2-O说明A/B早期三个比率最大差<1%，但q6预测可差4.60倍。在P2-N同一积分数学核下：

|---|---:|---:|---:|
| 4h | 0.16242 | 0.16294 | 0.00052 |
| 6h | 0.08545 | 0.05737 | 0.02808 |
| 8h | 0.06608 | 0.02288 | 0.04320 |

对这一**特定已选反例**，10–12h比24h数值差更大；但不能拿它代替整个候选集合的设计排名。若所谓检测精度只够分辨归一化差0.05，该反例中所有列举点都不能保证区分，说明长尾研究的高灵敏度测定方法比单纯延长观察窗口更基础。

## 4. 真正的人体PK研究需要如何设计，不等于建议自行抽血

**0h样本**记录实际给药前E2基线，必要时控制此前治疗残留而不能假设0h是真正未给药自然激素；**1h样本**提供同一人当次剂量的幅度参照；0–60min需要密集点识别最初输入；2–4h确认峰后的衰减，再考虑6/8/10/12/24h多点观察。研究分配应评估伦理负担、检测法LLOQ和随时间扩大的相对误差，不是无条件要求每个人都采全套。重复给药研究必须完整记录至少此前若干次实际服药事件和抽血时刻（并明确丢失、含服/吞咽与剂型），才可能实测并区分6h谷浓度机制。

真正优化可考虑人口Fisher信息矩阵/D-optimal或informative-block随机设计，但它们必须有可接受的参数先验、结构和残差/个体随机效应模型。2005年药代实验设计比较显示可用模拟研究这类方案：[A pragmatic approach to the design of population pharmacokinetic studies](https://pmc.ncbi.nlm.nih.gov/articles/PMC2750978/)。2026年生效的[ICH M15](https://database.ich.org/sites/default/files/ICH_M15_Step4_Final_Guideline_2026_0129.pdf)强调预先定义模型用途、证据评价与风险相称的报告。本阶段简单的模型两两距离**不是**D-optimal实验设计，更不是ICH M15正式审核通过的模型证据。
