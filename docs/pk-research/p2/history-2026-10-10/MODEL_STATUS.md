# P2-R → P2-AT：当前科研结论、验证准入和产品决策

**更新：2026-10-10**。所有已接触/合成的人体以外数据均需显式标注。两条被比较的实际 App 模型：Legacy `E2_SL` 与冻结的 P2-X 15 套 M2；P2-AG 的研究 M1 与正式 Legacy **不是同一个对象**。

## 证据等级

1. **数学核验**：两个模型均有计算核复算/自动化测试；只能证明公式按代码运行。
2. **已见人体组均值的形状吻合**：已见 Price、Rosano、Komesaroff 资料上，P2-AT 显示 M2 描述性误差较低；这批数据已经参与 M2 的设计和筛选，因此不能宣称是独立预测准确度。
3. **人体个体时序外部验证**：缺少从未参与开发、给药途径/时钟/背景/测法明确的 0–24h 多点且含重复给药数据；外测证据不足。
4. **个人绝对 pg/mL 与长期谷值**：M2 无个人幅度验证，慢吸收与消除速率可能互换；Legacy 内置名义 pg/mL 标尺并不证明外部校准准确。两者都不能据此自动授权服药建议。

## 已量化的重要问题

- P2-AF：允许同时变化的慢输入与消除速率产生大幅长尾歧义，而早期 AUC 差异可能很小。
- P2-AJ：Price 1mg Figure1 重读 AUC约 1550.6，Table1 2109，来源内口径差异未解决。
- P2-AL：在 10 个比较情景及人工读图区间下，2 个支持研究型 M1、5 个支持研究型 M2、3 个排名不稳定；不是对正式 Legacy 的胜负表。
- P2-AM：M2 早期半小时响应对 ±5min 采血时间误差高度敏感。
- P2-AN：模拟缺失晚期样本可翻转表面模型名次，应按受试者进行配对评分、显式处理缺失与检测误差。
- P2-AQ：真实取得 VNC54/TCRUW 文件，但仅 VNC54 有已辨认的名义 90min 额外 E2 样本（11 名不同参与者）；还不是完整 PK 外测。
- P2-AS：正式 Legacy 数学核重算通过，但早期过快、晚期过快衰退的风险与已发表组均值不一致。
- P2-AT：直接以**正式 Legacy**与 M2 在相同归一尺度对比：已见组级曲线支持 M2 形状改进；不是盲化外部性能验证。

## 功能放行矩阵

| 功能 | 当前判定 | 理由 |
|---|---|---|
| M2 内部数学计算 | 允许实验研究 | 有数值与源到核验证 |
| App 实验页相对曲线 / 候选切换 | 允许受控接入 | 保留旧版、只读历史记录、无量纲和长期不确定性警示 |
| M2 作为默认个人 pg/mL 预测 | **不通过** | 绝对幅度、背景、独立人体长尾未经验证 |
| Legacy 被宣称为已临床验证 | **不通过** | 仅少数已见汇总点为训练依据，缺合格外测 |
| 为令 M2 获胜而重选 Price 基线或候选参数 | **禁止** | 会泄漏开发/验证边界 |
| 删除旧模型或修改既有历史估算 | 暂不允许 | 没有获准的独立产品/科学迁移审查 |
