# P2-C — 生产模型替换准入审查（2026-10-10 补录，仍未获批准）

> P2-C 原本不是缺了一份新的体内动力学测量研究，而是 **P2-A（证据/协议冻结）→ P2-B（隔离候选模型）之后的正式部署闸门**。该阶段不应通过补写文档伪称“已通过”。本页只补齐审查所需的历史定义和现况判定，保留未实施状态。

## 1. 以前确定的原始边界

- P2-A：冻结数据角色、完整研究分割、假设与验收协议；候选拟合前固定 SHA。
- P2-B：隔离候选、339 套条件情景、数值正确性、工程 CI；正式生产 E2_SL 未被替换。
- P2-C：必须另获明确授权，才考虑变更正式引擎、默认预测、个人 pg/mL、版本/历史兼容或发布。参见 [model-selection.md](../../model-selection.md)、[validation-protocol.md](../../validation-protocol.md)。
- 后来的 P2-X/AB/AC、P2-AS/AT 及 UI PR #1–#3 **没有隐式授权 P2-C**。

## 2. 对称审查表

| 必要审查 | Legacy E2_SL | M2 | 判定 |
|---|---|---|---|
| 数学代码可复现 | 有（P2-AS） | 有（P2-AB/AC） | 通过工程级别检查，**不等于医学准确** |
| 已见人体组曲线形状吻合 | 与 Price/Rosano 等存在显著条件偏差 | P2-AT 描述性更接近 | M2 在**已见资料**占优 |
| 未见独立人体多时点预测 | 不足 | 不足 | **阻断** |
| 个人背景/幅度 pg/mL | 名义标尺，但未充分外部校准 | 不具备个人标定 | **阻断** |
| 8–24h 尾部、重复给药 | 已见形状存在偏差，缺外测 | 长尾参数不可辨识 | **阻断** |
| 历史记录、快照、Schema、旧版兼容迁移 | 必须保留 | 尚无正式迁移授权 | 未评审 |
| 正式发布/签名/设备回归 | 原发行流程有历史验收 | 实验界面与临床替换是不同授权 | 未批准 |

任何新的外测应先按受试者/队列独立性核查，冻结对两模型共同适用的背景、幅度、采样时钟、检测平台、误差评分和停止规则。研究性 15 候选不属于人体 95% 区间。不得为了让 M2 获胜重新选择已见 Price 基线/候选。

## 3. P2-C 当前决定

**HOLD — NOT_IMPLEMENTED / NO_PRODUCTION_APPROVAL / EXTERNAL_VALIDATION_INSUFFICIENT。**

可以保留 Legacy 默认、单独展示 M2 相对曲线及明确的“文献研究情景” pg/mL；不可声称两者中任一个已经获得充分个人临床准确性证明，不将 M2 改为默认个人浓度，也不自动写历史估算或改变剂量。此文档没有修改正式应用、引擎、参数、数据库、冻结协议、签名和发行。
