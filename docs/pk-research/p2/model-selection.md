# 研究结论及独立P2-C提案门槛（尚未实施）

本轮完成P2-A证据冻结、P2-B隔离原型与Gate C条件比较。状态：**INSUFFICIENT_EVIDENCE / NUMERICALLY_VALID_ONLY**。不选择新模型，不调整正式参数，不将工程稳定、单点拟合或更接近Featherline包装成临床准确性。

现有HRT主要来自Doll1mg有限摘要；1h附近群体固定点可对照，密集早峰未取得，绝对AUC代理非实测。2/4mg比例、含服档、重复谷及8–24h完整尾仍外推。A低维但缺形状信息，删除训练研究无估计，已见外部点没有一致改善。B通过有效产品降维，仍不能识别微观吞咽份额/吸收生物利用度/V，额外结构只制造更多同样训练匹配的外推。Featherline表现按研究混合，无赢家。

下一最小研究单元建议**取得并许可核对Price/Doll完整浓度表/受试者采样数据**；以study/cohort锁定真正未见外测。资料至少需要：实际E2剂型和操作、每次剂量/时间与完整先前史、给药前基线、0–2h密集早采样（能分辨峰）、2–8h中段以及12/24h晚采样、可靠LC-MS/MS或可分析测定偏差、个体/群体统计类型和分母、真实含服时长及明确许可。至少两个独立、输入足够、未用于调参的研究，再按冻结协议比较有限有效参数；跨剂量/重复给药验证应独立于单次训练。

P2-C只有另获授权才讨论投产；需先验收：

1. 可辨识的人体目标、事先固定复杂度/外测标准；不拿已见外部点重新训练后继续称盲法。没有来源支持的20%等临床阈值不使用。
2. 模型结构/参数版本和来源快照；多人体时点/外测对照与已知方法差异分层、不可估计的不确定性诚实处理。
3. 与当前个人幅度校准/混合非SL行为兼容；不同参数语义不直接复用，算法/冻结版本/旧1/2读取、备份、历史回放和旧PDF保留须独立设计与回归。
4. 生产替换分支/回滚范围明确；不自动重算不可变资料、不改用户剂量/事实。任何持久化格式变化先给独立迁移与旧备份兼容方案。
5. 只有科学门槛达标才谈生产评估，并需用户独立授权。若仍不足，继续当前正式核并保留警示。
