# P2-AZ｜舌下 E2 的回顾性跨研究留一重选与模型复杂度审计

**日期：2026-10-11。真实执行：Python 标准库研究程序、12 项来源／数学／隔离测试、已发表人体组级数据的 54 个回顾性留出研究评估和 Github Actions 机器复算。**

**研究判定：** 本次重新构造的 M2 快慢双输入家族在预先显式列出的 54 个“研究留一 × 已知图像版本 × 假设基线”情景中，**54/54 的留出归一化形状均方误差均低于正式 Legacy**；与新建 M1 单输入家族相比 **48/54 更低**。这是对双输入结构在已知跨研究组均值上的*支持性证据*，并非完全未见的新队列、临床个体预测优势或正式 E2_SL 参数迁移许可。**P2-C HOLD。**

## 1. 为什么以前的 P2-AT 不能直接视为外部验证

P2-X 的15条 M2 形状在 Price1997、Rosano1997 PK25 和 Komesaroff1998 三项群体资料暴露后被条件拟合与挑选，P2-AT 对同一组数据重新评分，即使 M2 比 Legacy 的 RMSE 小很多也属于**开发集的描述性对照**。若只是拿这15条曲线把其中一个研究从汇总得分中删掉，**候选池的形成仍已经利用被删掉的研究**，不能因此称为无泄漏的留一交叉验证。

P2-AZ 引入一个单独重新建立、来源明确的**有限参数网格**，不继承 P2-X 已经用全部三个研究筛过的15条。每个折仅根据剩余的两项研究分组均值选择网格参数。正式 Legacy 完全冻结、参数不从留出组拟合；原始15个冻结 M2 则单独作为“上游已经泄漏的对照”报告。**但是我们在构建这项研究的机制、参数网格及统计口径以前已经读过所有三个研究，所以这仍是事后回顾性的组级留一，绝不是过去从未看到过测试队列的盲法外推。**

外部统计方法学背景：Király et al. 2025 [chemometrics 参数泄漏和交叉验证](https://doi.org/10.1002/cem.70026)；Adin et al. 2024 [group-wise 交叉验证的重要性](https://doi.org/10.1016/j.spasta.2024.100843)。这两篇是方法学参考，并非 E2 模型外部验证研究。

## 3. 拟合、计分、假设背景与复杂度

训练及留出评分均为**按研究内部观察锚点归一化后的群体曲线形状**：
`R_s(t;b_s)=(Y_s(t)-b_s)/(Y_s(t_anchor)-b_s)`；
每项研究各自计算非锚时点 `MSE_s=mean_t[(H(t)/H(t_anchor)-R_s(t;b_s))²]`，训练时对其余两项研究的 `MSE` 等权平均。**对留出研究不使用其其它时点来重新选择候选**，只用该研究已发表的锚点构造无量纲形状目标；该锚点用到了留出观察，意味着本研究不评价“未见研究的绝对pg/mL幅度能否预测”。给药时钟、个体基线和真实共同测量误差都未取得。

三类原模型与重新选择的候选结构：
- **Legacy**：真实正式发布的 `E2_SL` 数学核，源文件为 SHA-256 锁定的原始 P2-AS ZIP 中生产模型快照；**没有在任何折中重新拟合**。
- **新 M1（32个预定网格点）**：单一路径 `w=0`，仅包括快输入 Erlang 阶数 `n`、输入速率 `k_f`、中央清除速率 `k_e`。名义形状维数3。
- **新 M2（216个预定网格点）**：有正权重慢输入，含 `n,k_f,k_e,k_s,w` 五个名义形状自由度。慢输入经中央室消除；这仍不能证明真实人类有对应个数的生理分室。
- **历史 P2-X 15个候选**：冻结，不调参数，只用训练两项重新排序；其候选**早在本次折分组之前已经见过3项研究**，所以其“留出”表现始终标记 `CONTAMINATED`，不列为独立获胜证据。

完整网格和冻结条件请看 [p2az-design.json](p2az-design.json)。每组情景交叉组合：Price读图 P2-I 或 P2-AJ；Price假设基线 0/12/24 pg/mL；Rosano假设基线0/100/200 pmol/L；Komesaroff实际已公布0min 89.4 pmol/L（假设给药期间背景恒定）。`2×3×3=18`情景，每情景留出3项研究，因此 **54个高度相关评分折**。

**重要数值处理勘误：** 例如Price P2-AJ人工重读18h约23.85 pg/mL，假设背景24时扣除增量为 `−0.15 pg/mL`。这接近0的小负值在真实读图/测量误差下完全可能，不意味着原始浓度为负。程序保留此负增量，不截断为0；最初错误地强行要求每个时间点扣背景后非负，已经由失败CI发现并修正。模型曲线仍要求物理非负。

| 模型族 | 留出形状MSE低于正式Legacy | 比新建M1低的情景 |
|---|---:|---:|
| M1，32个条件网格点 | **42/54** | 不适用 |
| **M2，216个条件网格点** | **54/54** | **48/54** |
| P2-X原15候选（上游见过留出研究） | 54/54 | 不用作独立证明 |

不同假设版本在每个原始研究单位上恰好各有18个情景。新建M2对Legacy的留出比较为 **Price18/18、Rosano18/18、Komesaroff18/18**。新建M1对Legacy则是 **Price6/18、Rosano18/18、Komesaroff18/18**。这些18次重复是人为背景/读图敏感性，而不是独立成功重复次数；由于假设共享，不允许由54/54推导p值或置信区间。

三项研究假设 Price P2-I 旧图，Price基线0、Rosano基线0时的**代表性**留出单位归一形状 MSE：

| 留出整个研究 | Legacy固定 | M1仅从另两研究选取 | M2仅从另两研究选取 | P2-X冻结15条重新排序（上游已见） |
|---|---:|---:|---:|---:|
| Price1997 | 0.0131018 | 0.0128444 | **0.0035325** | 0.0030551 |

| Komesaroff1998 | 0.1854836 | 0.0042862 | **0.0025886** | 0.0004040 |

**反例必须保存：** 在代表性 Rosano 留出折中，M1的0.0074380 **低于** M2的0.0153833。M2并不是“每次都比简单模型更好”。固定 Legacy 在 Rosano/Kom 的早期形状误差较大，与 P2-K/AT 之前已经指出的早期响应结构限制一致，但这些资料正是新网格设计时已经知晓的。

跨18情景的**每研究留出MSE中位数**（非独立个体总均值）：

| 留出研究 | Legacy | 新建M1 | 新建M2 |
|---|---:|---:|---:|
| Price | 0.0136071 | 0.0149753 | **0.0006855** |
| Rosano | 0.1063669 | 0.0085899 | **0.0041609** |
| Komesaroff | 0.1854836 | 0.0042862 | **0.0025886** |

每项研究三个不等密度观察窗、不同真实人群/剂量与分析平台，均值无法构造统一“合并患者级预测误差”。不能将上述无量纲形状MSE改名成绝对pg/mL RMSE或统计显著性。

## 5. 不能忽视的复杂度反证：训练集偏好对惩罚高度敏感

如果只用剩余两研究训练形状MSE最小选模型族，不加复杂度惩罚，新建M2家族在全部54折被选中。这符合216候选、5名义形状自由度的更高灵活性，但不自动是“复杂度合理”。本研究明确列出一个**人为**的 `训练目标 + λ×名义形状自由度` 条件压力试验：

| 人工惩罚 λ | 训练两研究选 M2 | 选 M1 | 选固定 Legacy |
|---|---:|---:|---:|
| 0 | **54** | 0 | 0 |
| 0.002 | 22 | **32** | 0 |
| 0.01 | 0 | **54** | 0 |
| 0.05 | 0 | 6 | **48** |

这些 λ 是演示用的**任意惩罚常数**，不是经过科学校准的 AIC、BIC、AICc 或贝叶斯因子。这里只有3个研究级独立单位，且源内反复采样协方差未知、群体均值/SD/SEM混杂，**不满足正当计算AICc或抽样方差的条件**，因此不得根据某个λ人为指定“正式模型赢家”。结果的实质是：**在这批已知群体曲线上双输入结构提供显著形状灵活性；在极少研究和未知误差模型下，怎样惩罚这种灵活性会改变训练阶段最终被选的模型家族。**

## 6. 对“新模型是不是更好”的清晰裁决

1. **可以说：** 用此前已公布且已见的 Price、Rosano、Komesaroff 人体研究，在本项目预先写入P2-AZ设计文件的多个读图/基线情景下，重新从有限网格做研究级留一参数选择，M2家族对3个不同来源群体曲线的归一化形状迁移优于正式 Legacy。在本研究测试框架内，这是强于P2-AT同组重拟合的*额外支持性结果*。
2. **不能说：** 已获得真正未见人体队列的验证；当初设计M2时没有读过被留出的研究；54次是54个独立人体外测；P2-X原15条参数本身具有上述216网格同等的“未训练来源”性质；M2永远优于M1；现已证明个人E2绝对pg/mL、药代半衰期、个体稳态谷值或8–24h增量的准确性。
3. **产品方向：** Legacy与M2作为**模型选择层的研究证据**应分别记录形状和单位标定。无需以“宇宙中永远有未来没见过的数据”为由拒绝研究性结论；同时不应因发表群体曲线的回顾性形状优势就偷偷改变面向真实用户的生产剂量-绝对浓度输出。**P2-C 仍是单独审批闸门。**
4. **最优下一实验不是无穷循环重新打分：** 应优先把已存的同尺度人体群体观测、三研究来源一致性、个体基线/时钟/检测法的可得性整理成预冻结的工程验收标准；进一步扩展公开群体时段只能增加当前研究的解释范围而非强行要求无穷多独立研究。
