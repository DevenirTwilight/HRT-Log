# P2-AV｜舌下 E2 外部人体药代证据的队列去重与数据准入审查

**研究日期：2026-10-11。研究类型：公开研究元数据核查 + 确定性、可复算的证据准入审计。不是新的个人级药代拟合，也不是临床有效性评价。**

## 一、为什么这一步必要

P2-AT 已在早期开发数据上比较 Legacy / M2 的归一化形状，P2-AR-REAL 和 P2-AU 则利用真实 Yaish/VNC54 两点配对浓度说明：背景浓度和服药时钟未确定时，允许每次访视自由剖面背景和幅度会改变“相容性”数量。继续反复使用同一个 VNC54 队列无法创造出独立外部验证。本阶段转向 **“有哪些真正可以在模型冻结后检验其预测能力的新来源？”**

先冻结原则：**文献数不等于队列数；计划采样时点不等于已取得可检验的数值；第 1/6 个月随访不等于给药后第 1/6 小时；队列不同不等于此前模型研究从未接触过其结果。**

## 二、逐源核查的新增信息：TREAT NCT05010707

**原始主来源：** Cortez et al., *Journal of the Endocrine Society* 2024, doi:[10.1210/jendso/bvae108](https://doi.org/10.1210/jendso/bvae108)，文章正文：<https://academic.oup.com/jes/article/8/8/bvae108/7691571>；注册 [NCT05010707](https://clinicaltrials.gov/study/NCT05010707)；先前 [2023 试验方案](https://pmc.ncbi.nlm.nih.gov/articles/PMC10770781/)；同项目的 [2025 大会摘要](https://academic.oup.com/jes/article/8/Supplement_1/bvae163.2429/8122897)。三者属于 **同一队列**，不可按三项独立临床试验计算。

- 随机化总人数 39，其中 **舌下每日一次 13 人、舌下每日两次 14 人、透皮组 12 人**。这些是入组分组人数，**不是所有后续时间点的可用血样人数**。
- 随访分析包括启动前、第 1 个月和第 6 个月等门诊检查。**舌下组在晨间服药之前取谷值/空腹血样**；并非给药后 1h 或 6h 的 PK 采样序列。文中明确指出未测各组峰值。前一天末次舌下给药的准确时间戳未从发表内容中取得。
- E2 使用 **免疫测定（immunoassay）**；E1 为 LC-MS/MS；**不能把 E1 的检测方法错赋给 E2**。受试者长期剂量按睾酮抑制目标逐月调整，还同时使用螺内酯；不同组的剂量和用药史不一致。
- 论文表 3 发布的舌下组 E2 谷值组均值：**每日一次 1 月 52.6 pg/mL，6 月 95.3 pg/mL；每日两次 1 月 55.2 pg/mL，6 月 79.4 pg/mL**。这些只可作为具有明确来源的**治疗随访汇总**；不能编造个体峰值、AUC 或 8–24h 尾部测量。
- 论文数据声明说研究所得资料包含在发表文章或 ClinicalTrials.gov 上；试验登记有汇总结果记录。**这不等于已找到带准确每剂时钟的可复用个体多时点 E2 CSV。** 本次审查没有取得满足模型直接验证要求的逐时数据。**不得断言作者没有其他可申请的原始记录。**
- 它有独立的 NCT 号码和研究方案，不能和 Doll/TransPrEP/Yaish 混算；但以本项目证据分割口径，**Cortez 组级结果在 P2-X 阶段已作为设计/条件信息接触过**，因此不能无条件改称冻结后从未看过的盲法外部集。

重要参考点：论文公开的 group mean/SD 的统计口径须按原表说明保留；本阶段不为预测模型构造标准差或似然、也不把治疗终点当药代峰形终点。

## 三、既有与其他来源的独立性去重

| 队列/研究 | 本轮来源与主要结论 | 当前阻断 |
|---|---|---|
| **TREAT / NCT05010707** | 2023 protocol、2024 结果、2025 摘要：一队列 | 只有纵向给药前谷值/随访汇总；E2 免疫法；缺逐剂时钟/多时点曲线；曾接触组级证据 |
| **Doll / NCT04036500** | 2020 N5 会议阶段与 2022 N10 正式结果：一队列 | 计划 0/1/2/3/4/6/8h，但当前只可靠记录已报告峰值等指标；无授权原始逐时数值；已见 |
| **TransPrEP / NCT03652623** | Yager 2022 与 Abdelmawla 2023 模型再分析：一队列 | PO/SL 合并；拟合/采样安排不是已获得纯 SL 个体时序 |
| **Yaish / VNC54** | 11 人、20 次有效前后配对；P2-AR/AU 已实际分析 | 给药后只有名义 90min 一个时点；剂量史缺失；已见数据 |
| **Price 1997** | n6，已见 1–24h 舌下组曲线数字化 | 手工/第三方图像点；AUC 图表不一致；已用于 M2 候选筛选 |
| **Rosano 1997** | n25，10/20/40/60min 组均值 | 背景与同人误差相关性未知；早期、已见、不能作为盲法外测 |
| **Komesaroff 1998** | n10，15/30min 组均值 | 仅两个给药后点，SEM 大、配对协方差缺失；已见 |
| **Burnier 1981** | 0.5mg SL 的相对增幅研究 | 相对/折数和部分摘要不能冒充可量化的个体绝对浓度时序 |

上述 8 个唯一队列由本轮 **12 条记录**映射产生，只代表本轮指定研究来源的去重结果，不是所有已发表舌下 E2 人体研究的完整文献计量。详情见 [机器可读来源](p2av-source-registry.json)。

## 四、形式化准入门槛与可辨识性

评价舌下 E2 **曲线形状**需要真实可用的不同给药后时间点、基线/背景定义、真实或合理可审计的给药历史、相应检测方法/测量时钟和合法复用许可。仅有计划采血表但未取得真实测量数值，不能通过。

对**锁定外部检验**，还必须可核对队列独立、冻结参数与评分规则在数据获得/阅览之前完成、候选没有接触该数据。对**个人绝对 pg/mL**，还需足够的个人曲线及预先固定的背景/增益/幅度标定，不能在预测后用真人观察再对每次访视任意重估尺度。

**严格单次给药 8–24h 长尾评价**至少要求实际晚期样本，而 TREAT 只有晨间下一剂前谷值（还受先前剂量积累、剂量变更及未记录时钟影响）。因此**TREAT 的“月度谷值”不能代替单次 8–24h 响应**，也不能从第 1 月、第 6 月重建浓度—时间曲线。

新程序 `tools/pk-research/p2av_external_source_gate.py` 是只读、纯 Python 标准库的门控器，实际输入仅含公开文章元数据。其分类不计算任何真实受试者血药数值或个体模型残差。针对 12 条文献记录，当前四个门槛：

- 可用于严格连续形状评价：**0/12 条记录**。
- 可用于严格 8h+ 尾部评价：**0/12 条记录**。
- 锁定独立形状外测：**0/12 条记录**。
- 个人绝对浓度外测：**0/12 条记录**。

这里的分母是**文献/记录条目，不是受试者**；分母包括同队列的不同发表形态。所有未通过只描述此轮可核实/可合法使用资料的**准入状态**，**不是说明研究本身不存在相关观测、数据持有者拒绝共享或模型已被证伪**。

## 五、按优先级的数据获取任务

1. **Doll 团队**：在合法许可下先申请 SL 1mg 0/1/2/3/4/6/8h 的 LC-MS/MS E2 **每时点组均值、离散度与有效 n**，再核实绝对 AUC0–8 和基线定义，不把早期 N5 算第二队列。这些依旧是**开发已见**群体曲线，不可追认盲法外测。
2. **TREAT / Cortez 团队**：询问 1/6 月谷值可否以 SL 每日一次/两次独立提供按剂量层级汇总、最后一剂实际时间、化验平台/LLOQ、测量时钟窗口、缺失数据规则；如只获得这一批数据，最多做有条件的慢性谷值评价，**不能验证峰形或 8–24h 单剂长尾**。公开通讯作者联系方式见上文正式论文，不在本阶段发信。
3. **TransPrEP 团队**：确认 13 个混合 PO/SL 人中纯 SL 成员、0–24h 实际时钟、剂量史及是否存在合法的途径分层非个人汇总，不能借模型摘要恢复不存在的曲线。
4. **另找真正未接触的独立队列**：先冻结 Legacy 与 M2、预测目标、背景/绝对浓度标定、统计评分和停止规则，再在符合许可的环境下加载完整数据；以后新数据不得为了追求更好误差被返工成训练资料而又叫作独立外测。
