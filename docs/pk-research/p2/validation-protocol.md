# P2-A/B 拟合前冻结协议（2026-10-09）

研究授权，非生产替换。先独立提交本协议、证据、分割和机器设置；提交并推送后才实现/拟合/评价候选。P0/P1和正式参数只读。详细数值假设以 experiment-settings.json 为准，所有情景保留，不挑赢家。

纳入七项直接人体舌下 E2 研究。人群、检测和基线未知保持未知；无个人原始数据，不能排除跨研究隐含队列重叠。新搜索仅初页筛查，不声称系统综述。Doll会议前身不另计研究。全文状态人工核实，不按HTTP200自动提升。

按整项study划分：Doll TRAIN；Pines、Yaish、Burnier DESIGN_EXPOSED；Price、Casper、Cortez QUALITATIVE。全部P0已见；LOCKED_EXTERNAL=0。不得把一项研究拆点训练/外测。任何真正新锁定外测仅最终一次运行；本轮没有这样的数据。

只有Doll 1mg/1h/144pg/mL用于条件幅度拟合，不把1h当真实Tmax，不用旧口服推算的绝对AUC代理。固定共享基线0/25/50只是工程敏感性，非人体测量；不为单个验证点另拟基线。不同检测不转换、不合并总分、不以SD/SE未明者加权。

A为gamma2核；固定k五档，每档仅拟合正E。B为共享消除双途径核；固定三种快率×三种慢率×三种消除率×四种有效慢份额，每情景仅拟合正G。E/G边界和四初值预定，目标为Doll固定时点未加权平方残差；可解析求解并以有界一维搜索独立验证。形状/基线是假设，非估计；名义参数A2/B5，单观测Jacobian秩至多1。禁止根据外部误差再调速率。删除唯一训练研究后幅度not_estimable，无留一研究排行榜。

同单位、剂量、时点比较四模型。Doll/Pines只比较1h；Yaish只比较90min，假设q6h30天及单次/漏服/12h夜间间隔敏感性；其治疗谷不能当内源基线。Burnier只比较26-fold，在预定5/24/50基线条件下，不生成并保存虚构实测1h绝对浓度。Casper无精确时点不算误差，Cortez无当天历史不算误差。Featherline80kg只是条件，另报60/100kg；不声称研究实测体重。17β-E2为所有主要比较；EV必须明确质量272.39/356.51折算；pmol/L使用既有3.671换算，不做免疫法经验倍数校正。

每研究单列绝对差、相对差/正值log差，负结果与完整超参数清单保留。Cmax/Tmax/AUC0–8/24只属于模型内部，论文无相同定义观察则不算人体误差。8–24h没有完整独立序列，不估计整段人体误差。Doll采样最高值/比例仅作原始证据，后两项不参加候选拟合。Burnier24h返基线仅定性，不反推终末半衰期。

数学验收相对误差1e-6，近等速率expm1/连续极限与独立ODE/积分oracle；非负有限、剂量线性作为软件假设、q6/12/24×30天、跳过/改剂量/停药48h。可辨识性报告多初值/形状profile/单点Jacobian秩、至少两组微参数相同轨迹、flip-flop反例。固定seed仅合成试验，人体样本量不增加。含服2/5/10/15无候选量化依据，标unsupported；当前核工程缩放不称人体证据。

外部放行至少两项未参与候选调参且输入足以匹配的独立人体研究；无无来源临床误差阈值。目前 external_validation_insufficient；数学通过也只NUMERICALLY_VALID_ONLY，clinical_accuracy_established=false；不批准替换。
