# P2 全阶段：证据资格、模型能力与发布限制

**结论截至 2026-10-10：科研计算可以继续、M2 可展示实验相对曲线；尚不能据此替换正式个人 pg/mL 模型，也不能宣称旧模型已经通过临床预测验证。**

| 关键问题 | 已取得的证据 | 目前不能宣称 |
|---|---|---|
| 实验核是否数值可运行？ | P2-X/AB/AC 与后续数学、Kotlin 测试已形成；实现见 PR #1 | 数值一致性不是人体准确度 |
| 旧模型是否经过同等审查？ | P2-AS 对正式 E2_SL 重现，发现对 Price 2h/8h、Rosano10/20min、Komesaroff15/30min 的组级形状不一致 | 这些是已见研究组均值，不能量化个人临床误差 |
| M2 是否比 Legacy 更准？ | P2-AT 显示在**曾参与 M2 设计或筛选**的 Price/Rosano/Komesaroff 点上，15 候选描述性误差较低 | 不能称为独立外推获胜；P2-AG 研究型 M1≠正式 Legacy |
| Price AUC 与原图能否统一？ | P2-AJ 原版图重读 1mg AUC ≈1550.6；原文 Table1 ≈2109（0–24h）；P2-AK 低剂量读图区间较宽 | 不能强迫模型同时命中，也不能武断说原文错误 |
| 慢尾、谷值可辨识吗？ | P2-AF 等揭示不同合格参数在 ≥8h、24h 后可严重分歧，慢吸收与消除交换 | 冻结15候选 min-max 不是患者95%覆盖区间 |
| 取得真实人体数据了吗？ | P2-AQ 已核验 VNC54 11 位舌下受试者、21 次名义90min观察（相同参与者重复访视）；TCRUW 30 行基线/随访 | 无单次0–24h逐人完整序列，不能把21样本当21独立患者，也不能把已暴露队列当盲化外测 |

| 生产部署放行了吗？ | 可在通过独立 UI/发布审核后选择显示研究相对曲线；PR #2 独立推进 | 没有授权将 M2 相对曲线包装为个人 pg/mL |

## 对所有报告一视同仁的验证规则

1. 为每一模型冻结计算代码、参数哈希、适用人群、输入资格与采样设计；旧模型默认存在不构成额外证据。
2. **形状验证**和**绝对 pg/mL 验证**分别评分；已知锚点的事后标定不能算无锚点独立预测。
3. 不能以“取 Price/Rosano/Kom 已见汇总均值更接近”为理由，选 M2 后再称其为未见测试。
4. 必须有逐人实际给药/采血时刻、基线、剂量、制剂、检测方法、LLOQ/BLQ、缺失和多次给药历史；同人重复采样做受试者级配对统计。
5. 评价窗口分开：0–90min、1–4h、6–24h 和重复给药下一次给药前谷值；禁用事后只挑一个有利窗口的证据。
6. 对 P2-R 的 10%/5%、两个独立 holdout 等内部暂定门槛，正式开封新验证数据前还需要科学复审，不是 FDA/EMA 的法定临床界值。
7. 新旧模型若都没有通过外部验证，结论应当是**双方临床准确性未知**，不是自动承认旧模型优越或 M2 已经胜出。
