# P2-T｜舌下雌二醇的原始数据可获得性、队列身份与采样信息缺口

日期：2026-10-10。版本：research-only / EXPOSED_METADATA_AUDIT；对照仓库 HEAD `7a45741f1a83646195db0a0e20c9806da4878af3`。不改正式参数、APK、P1、P2-A/B冻结、个人数据或软件临床声明。

## 结论摘要

**实质新增数据线索：NCT04036500（Doll 2022）在 2025-04-11 更新的公开试验登记记录中声明，论文结果所依据的个体数据可通过直接联系 PI 申请，开放期为论文发表后三个月。** 这项声明不等于已取回数据、PI 保证批准分享、共享范围不受伦理或许可限制。本次未联系 PI、未获得 IPD，所有人体浓度原始时序的真实锁定外测仍为0。见 [临床试验登记](https://clinicaltrials.gov/study/NCT04036500) 及 [镜像完整条目](https://ichgcp.net/clinical-trials-registry/NCT04036500)。通讯作者可由 [PubMed](https://pubmed.ncbi.nlm.nih.gov/34781041/) 直接核对。

Doll 2020 [会议初报](https://pmc.ncbi.nlm.nih.gov/articles/PMC7208646/) 是该研究前5人的结果（SL peak 178±47 pg/mL），2022 [正式文](https://pubmed.ncbi.nlm.nih.gov/34781041/) 是10人的结果（LC-MS/MS SL peak 144 pg/mL）。NCT04036500 登记的实际入组数为11，不是正式文献分析人数10。不能将 2020 n5 与 2022 n10 当作两个独立队列，也不能将登记入组数误当已分析人数。两个峰值差异不证明跨研究 PK 差异。2020摘要的 `±47` 不自动解释为 SD 或 SEM。

## 1. 已见研究采样窗口：**同一已核对时序表**没有兼具 sub-1h 密集上升与 ≥12h 长尾

| 来源 | 观察/文献的名义采样时刻 | <1h 峰前证据 | ≥12h尾段 | 个体纯SL时序已取得？ | 目前用途 |
|---|---|---|---|---|---|
| Rosano1997 PK25 | 10,20,40,60 min | 是 | 否 | 否 | 早期形状组均值；PK组基线未知 |
| Komesaroff1998 n10 | 0,15,30 min | 是 | 否 | 否 | 早期形状组均值±SEM |
| Doll2022 n10 | 0,1,2,3,4,6,8h | 否 | 否 | 否 | 1–8h峰后走势、AUC0–8；旧训练锚 |
| Price1997 crossover n6 | 0,1,2,3,4,6,8,12,18,24h | 否 | 是 | 否 | 中晚期/AUC；图表内口径冲突待查 |
| Yager2022 / TransPrEP | 0,1,2,4,6,8,24h | 否 | 是 | 否（PO/SL合并） | 重复给药混合路线，不能直接作为纯SL外测 |
| Cortez2024 / TREAT n39 | 随访时每次晨间服药前采血，非单剂相对时钟序列 | 否 | 未定义 | 否 | 各组真实慢性给药谷值背景；需要实际前剂时刻 |
| NCT05428215 | 登记拟采0,1,2,4,6,8h等，已终止，仅n2 | 计划没有 | 未公布 | 否 | 询问性线索，不是研究结果 |
| NCT07145281 | 6个月激素/凝血随访，非逐时PK | 否 | 未定义 | 无可核验文件 | 登记OSF潜在线索，不得冒充获得时间序列 |

因此，**将 Rosano 上升段直接接在 Price/Doll 晚期形状之后拟合同一个人口曲线，需要跨人群、制剂、基线、检测法与时钟的额外可迁移性假设**。P2-Q 已证明这些假设没有足够约束，故单凭多研究均值“拼接”不能识别生理慢尾或人体吸收阶段数。

这不是声称世界上不存在满足条件的研究，只是目前已核对来源的观察/报告采样表没有满足此组合的队列。不同研究给药后的第一时点信息含量不同，应分模型决策用途使用。

## 2. 针对正式模型潜在缺陷的「先获取哪批真实数据」

**A（优先第一）：Doll 原始 LC-MS/MS 0–8h**

- 借公开 IPD 分享计划，以 PI 审批和研究伦理许可为前提，申请每位实际纳入分析受试者的 SL/PO 两次访视原始 0/1/2/3/4/6/8h E2 和 E1，检验方法、LLOQ/QC、是否采血超时或缺失、真实采血时间和给药操作、日0基线、AUC与Cmax计算规则、非识别参与者配对键、可分享的汇总表和方法学文档。
- 若原始个体数据不可分享，按分级回退：逐时组均值/SD和每点有效n；同人时点相关矩阵或逐人基线扣除 AUC 汇总；仅官方图像坐标和误差带。不同层级不可伪装成完整个人数据。
- 即使获得完整数据也属于**已见、已用于模型构建**的来源，只能训练重查、证据质量审计、探索性比较，绝不能变成新盲法 heldout。
- 首个真实post-dose时点为1h，不能单凭 Doll 数据决定 10–40min 的零延迟一阶与 transit 差别；缺12/24h，无法单独证实长期尾段。

**B（早期结构关键）：Rosano1997 PK25 / Komesaroff1998 PK10**

- Rosano 首要获取该**独立PK25**组实际给药前 E2、逐受试者10/20/40/60min浓度、检测技术/批次、精确剂型/吞咽条件和个体协方差；不能借论文另一个9人冠心病介入组的基线。
- Komesaroff获取0/15/30min原始同人记录，区分原文的SEM和受试者SD，原始相关矩阵；若不可得，P2-S仅允许条件性的协方差界。
- 二者若仅获群体均值，仍可检验模型族的条件上界，**不能**估计个体 PK 参数分布或临床90%覆盖率。

**C（长尾与积分口径关键）：Price1997**

- 要求同6人在1/0.5/0.25mg SL交叉各时点的 E2（基线及是否逐人先扣基线），原Figure1图点/图像制表原数据、Table1 AUC计算脚本或统计口径、个体缺失/插补、检测法方法学。
- 图像手工/第三方数字化结果与作者Table1的差别，必须做**同一量纲/同一基线/同一受试者/同一时间网格**的线性运算一致性核查。组均曲线梯形AUC和各人同网格梯形AUC的均值在上述全部条件相同时应相等；不满足条件时不可推断原文算错。

**D（真实重复给药信息）：Cortez2024 和 Yaish2023**

- Cortez [开放全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11220669/) 报告39名受试者随机分配为13人每日一次SL、14人每日两次SL、12人透皮，随访晨间给药前采血。要求个体历史、实际最后一剂到采血的时间、剂量变更、检测方法及定量下限。该研究对慢性谷值背景有价值，但不是单剂浓度-时间曲线，也不能把一次/两次给药的参与者当成完全独立的外部研究。
- Yaish 2023 舌下90min的**median**与晨间predose的**mean**不能构造逐人的峰谷比；需要同一受试者配对序列、剂量与实际采血时钟；与后来 Yaish / Bar-On 人群的交叉重叠需要实证辨认。

## 3. 公开新线索的现实状态（不夸大）

- NCT05428215： [登记](https://clinicaltrials.gov/study/NCT05428215) 2023-07-20实际结束、实际入组2、招募不足终止、没有可核对的公开结果。2人即使有数据，也不能单凭该组对人群参数或临床覆盖率作稳健断言。
- NCT07145281： [登记](https://clinicaltrials.gov/study/NCT07145281) 宣称去识别 IPD 已放在 [OSF DOI](https://doi.org/10.17605/OSF.IO/TCRUW)，但本次 OSF 页面/文件列表访问失败；**没有下载、没有核对文件类型，也没有核对前剂时间和时间点精度**。该试验关注的是凝血与6个月随访，并非完整单剂浓度时序。队列身份与 Yaish 历史样本可能重叠，尚未核实，不能自动算独立队列。
- NCT03652623：Yager2022与Abdelmawla建模论文是同一TransPrEP队列，口服与舌下合并，不能因为有两篇文献就得到两份独立纯舌下验证证据。

## 4. 真正需要科学审核的数据模式与准入分层

> `TRIAL_DECLARED_SHARE` ≠ `DATA_RECEIVED` ≠ `LEGAL_REUSE_CONFIRMED` ≠ `PK_ADEQUATE` ≠ `LOCKED_EXTERNAL_UNSEEN`。

只有实际收到文件并核对哈希、学术引用/研究许可、伦理条件、研究与受试者身份、时间单位、测定平台/QC、药物制剂、口服或舌下路线、基线来源、前剂残留和真实剂量/采血相对时间，才能评估其是否能进入模型拟合或外测。

推荐P2-U在获取第一份原始数据后执行：

1. **原始文件只读与哈希登记**，研究用途权限和敏感字段最小化；先记录真实观测与单位、无预处理镜像，绝不填造缺失浓度。
2. **统计口径区分**：个体纵向样本、群体均值±SD、群体均值±SEM、中位数/IQR、基线扣除前后和不同检测平台分层。
3. **给药时钟审计**：实际服药时间、含服持续时间、每个采血的采集时间、此前历史。将名义1h与实际1h区分；因模型的早期曲线对时钟敏感。
4. **源身份去重**：以 trial/cohort_id 加来源访视/arm 标记，同研究不同剂量和2020/2022两个报告永远不计为新独立人群。
5. **不可辨识性与偏差敏感性**：先用简单 M0 和共享 shape 核逐来源预测检查，再研究 M1；保持检测平台不互换，单独拟合研究级有效背景/幅度，仅在方法桥接真实存在时估计跨检测转换。
6. **绝不回标成盲外测**：目前所有使用过的已见研究保留 EXPLORED/EXPOSED 标签；真正新外测必须按P2-R先锁协议、数据身份/观察权限，再进行模型选择与性能评估。

## 5. 可复现与工程边界

- `p2t-acquisition-ledger.json`：11条可追踪报告记录，对应9个命名队列ID（个别跨研究实际受试者重叠未查），来源身份和名义采样时刻；与既有P2-R台账并行，**不可直接合并参与者数**。
- `p2t_acquisition_audit.py`：只检查仓库内来源元数据，列出可申请IPD、双重报告身份、各来源时间窗口、已实际取得IPD数；对不合法时间序列/重复报告ID或越界获取状态拒绝。
- `test_p2t_acquisition_audit.py`：14项单元测试（这些是代码测试，不是人体验证）。
- `p2t-acquisition-checkpoints.json`：运行得到的审计结果；无真实人体数据，任何成功均不产生准确性/发布批准。

在仓库根目录：

