# HRT Log｜P2-AG：早期拟合能否迁移到独立研究的 2–24 小时曲线？

**完成日期：2026-10-10**  
**性质：回顾性、此前已接触资料的跨来源时间留出检验；不是预注册、盲化、逐人外部验证。**  
**工程隔离：** 仅创建本地文件；未访问或修改 GitHub、HRT Log、PR #1、Gradle、APK、数据库及 Claude 的压缩工作。本研究不是个人浓度或用药指导。

## 1. 主要结论

P2-AE/P2-AF 已证明长尾参数的条件可辨识性有限。P2-AG 提出另一个必须回答的问题：**模型即使拟合好了不同研究在 0–1 小时的组均值，能否预测另一研究在 2–24 小时的相对时间变化？**

回答是：**在本轮限定的模型、研究级幅度校准、边界和人工数字化数据下，不能据现有早期拟合确立这样的迁移能力。** 特别是，较复杂的 M2 可将早期两项研究的训练伪损失降到近零，但在部分假设下对留出的 Price 曲线预测比 M1 更差。该比较不能证明 M1 普遍更准确，只能反驳「较低训练损失足以支持正式替换」这一论证。

本轮分析中，使用 Rosano1997 的 4 个早期点（10、20、40、60 分钟）与 Komesaroff1998 的 3 个点（0、15、30 分钟）训练模型形状；**完全不把 Price 的 2–24 小时点送入训练和模型选择**。Price 的 1 小时人工读图值只用于计算该研究自己的绝对幅度锚点，再拿后续 8 个点进行留出诊断。

| 仅早期研究训练的形状 | Rosano 假设基线上限 | 训练伪损失 | Price 2 小时预测¹ | Price 2–24 h 留出 RMSE¹ |
|---|---:|---:|---:|---:|
| M1：Erlang 快输入 + 一阶消除 | 100 pmol/L | 0.80261 | 217.7 pg/mL | **23.77 pg/mL** |
| M2：上式 + 慢 Bateman 输入 | 100 pmol/L | **约 0** | 154.4 pg/mL | **35.97 pg/mL** |
| M1 | 225 pmol/L | 0.20880 | 141.5 pg/mL | 45.19 pg/mL |
| M2 | 225 pmol/L | **约 0** | 154.4 pg/mL | 35.97 pg/mL |

¹ 全部以 **Price 背景 b=24 pg/mL（假设，非实测）**，且 Price 1h 人工读图 **450 pg/mL** 作为一点评价前幅度校准条件。Price 2h 原人工读图值约 **225 pg/mL**。表中 pg/mL 是以**指定研究观察进行幅度校准后的组级条件情景**，不是患者绝对浓度预测，也不代表样本外人的预期误差。

## 2. 有多少真正可用的时间支持？

| 来源 | 观测时点 | 单位 | 本轮角色 |
|---|---|---|---|
| Rosano 1997，25人 PK 组 | 0.167、0.333、0.667、1h | pmol/L | 训练；背景未知 |
| Komesaroff 1998，10人 | 0、0.25、0.5h | pmol/L | 训练；有 0h |
| Price 1997，六名绝经后女性 | 1、2、3、4、6、8、12、18、24h | pg/mL | 1h 做该研究幅度锚；其余八个点留出 |

![各研究的时间支撑矩阵](figures/p2ag-time-support-matrix.png)

**关键约束：训练来源根本没有任何 1h 之后的独立观测。** 不论优化器收敛得多好，它都无法从这些资料直接得到 2–24h 长尾的经验校验。这不是复杂的统计结论，而是数据时间覆盖的结构性缺口。Price 图线的点为此前 P2-U **人工读图**，没有原始逐人血样与完整组内协方差；表格及 Figure 1 的 AUC 口径冲突仍未解决。

此外，Rosano 和 Komesaroff 的受试人群、剂量与检测方法并不完全相同，使用共享**形状**而允许各研究分别有背景／幅度，是一个明确需要验证的跨研究可运输性假设。

## 3. 如何避免训练与留出泄漏？

训练模型：

\[
H(t;\theta)=\frac{(1-w)F(t;n,k_f,k_e)+wS(t;k_s,k_e)}{(1-w)F(1;n,k_f,k_e)+wS(1;k_s,k_e)}.
\]

M1 相当于 \(w=0\)。训练两研究时分别剖面：

\[
\widehat{C}_s(t)=b_s+A_s H(t;\theta),\qquad A_s\ge0,\quad 0\le b_s\le b_{s,\max}.
\]

- 保留 P2-V 中相同的数学核与误差假设：每研究组均值的边际误差取报告 SE 或人工宽度与观测值 15% 之**较大者**，未知的组内协方差暂时设为零。伪损失不是统计似然。
- Rosano 背景上限分别取 100、225 pmol/L；Komesaroff 继续使用 160 pmol/L。模型阶数分别枚举 4、6、8、10；每阶 3 个确定性初始值、局部 L-BFGS-B 优化。
- 只按照 **Rosano+Komesaroff 的训练伪损失**挑选每个结构与背景情景的一套结果，不允许依据 Price 留出 RMSE 挑选最终参数。
- 对 Price，不直接转移 Rosano/Komesaroff 的幅度，也不误将 pmol/L 当 pg/mL。给定研究背景假设 \(b_P\in\{0,6,12,18,24\}\) pg/mL 与 Price 1h 读图 \(y_1=450\)，利用 \(H(1)=1\) 得 \(A_P=y_1-b_P\)。随后锁住参数，仅对 \(t=2,3,4,6,8,12,18,24\) 计算预测。
- 误差：原始浓度 RMSE 与人为设定 \(\sigma_t=\max(\mathrm{读图宽度}_t,0.15y_t)\) 下的标准化 RMSE；不把 1h 校准点算进留出分母。
- 这里并不是无条件预测 Price 的绝对浓度；它是**使用 Price 一次观测校准幅度后的曲线形状迁移**。如果没有那一次目标研究观测，不能输出这些 pg/mL 数值。

**为什么仍不能称为真正外部盲化验证？** 模型家族、候选速率范围与历史初值设计本就受包含 Price 的既往研究启发；Price 也曾直接参与早期 P2-X 的拟合。虽然本轮优化器与最终模型排序没有读入其 2–24h 点，但我们研究者此前已经看过它们。因此只能称作「回顾性留出重拟合实验」，不能据此宣布外部准确率，也不能把其留出残差当成人体总体的泛化误差。

## 4. 复杂模型为何容易做到训练伪损失近零？

这不是神奇的预测能力。Rosano + Komesaroff 合计只有 **7 个组级时点**。在两个研究各自背景与幅度自由的情况下：

- 研究级干扰参数：两个背景 \(b_R,b_K\) 与两个幅度 \(A_R,A_K\) = **4 个连续参数**；
- M1：\(k_e,k_f\) = **2 个**共享连续形状参数，总计6个；
- M2：\(k_e,k_f,k_s,w\) = **4 个**共享连续形状参数，总计 **8 个**；
- 数学阶数 \(n\) 还是额外的离散选择。7 个重复测量组均值也并不等于7个独立受试者。

因此，M2 在这7个观测点上逼近零训练伪损失，是**过度参数化风险的直接警报**。两组受试者之间的来源差异、基线约束与测量协方差都尚未建立独立误差模型。早期训练的最佳 M2 还将 \(k_e\) 推到本轮允许的上界 **1.6 h⁻¹**，进一步提示估计受参数盒边界影响。

![Price 背景敏感性](figures/p2ag-price-baseline-sensitivity.png)

每组均按各自 Price 假设背景重新以1h 值做幅度校准；**b=24 在这些模型下残差较低，不等于 b=24 被实测或其真实概率最高**。若观察这张表之后再选择 b=24 宣称模型预测成功，实际上已经把留出结果用于调参。不同基线下的 RMSE 不是校准过的统计显著性或临床真值误差。

作为透明对照：以前用 **Price 本身参与拟合** 的 P2-X 最佳候选，在 b=24、同样的1h幅度固定方式下，Price 2–24h 的表面 RMSE 约 **8.38 pg/mL**，标准化 RMSE 约0.323。该数字**严重信息泄漏**，不能与本轮真正排除 Price 2–24h 的留出数字做公平外部预测排名。它只能说明同一组数据用于定形时能够大幅缩小残差。

### 读图误差的非概率性压力检验

若人为允许 Price 1h 锚点在450±15 pg/mL，背景在0–24 pg/mL，保持早期 M2 的形状锁定，其 2h 预测范围仅约 **133.1–159.0 pg/mL**；Price 人工读图2h的225±32.5 pg/mL 区间约为 **192.5–257.5 pg/mL**。在这些人为读图区间内不重叠。**这不是95%置信检验，也不能代替对期刊原 Figure 1 的正确数字化核对。** 一旦数字化、时间归属或来源曲线选错，以上压力结论会随之改变。

## 6. 哪些主张可以支持，哪些不能？

**可支持：**

- 既有公开训练来源仅覆盖0–1h，无法直接校验新的2–24h函数形状。
- 一个训练误差近零的复杂模型，经过只使用目标来源单个早期观测作幅度标定后，可以对较晚时点表现更差；本轮至少给出明确、可复算的数值反例。
- 在这些具体模型与数据下，模型排序取决于背景假设与训练来源背景上限，复杂度不等于迁移性能。
- 将 Price 长尾用于原模型拟合，再以 Price 长尾「验证」同一模型，是来源重用，不是独立验证。

**不能支持：**

- 「M1普遍优于M2」「M2人体药代机制错误」或任何实际跨人群预测胜率。
- 推导出个人1mg→pg/mL幅度、真实消除半衰期、稳态24小时谷值和治疗决策。
- 把「7点和8参数」当成完整结构不可辨识的严格全局证明；这是自由度压力和过拟合风险指标，具体可辨识性仍依赖非线性几何、边界和更多数据。
- 使用读图宽度作为标准差或计算合格的统计置信区间。

## 7. 对正式替换旧模型的开发门槛

**本轮没有证据支持直接替换旧版 E2_SL。** M2 可继续作为 Debug 研究的相对曲线和候选集，但尚不适合默认显示临床 pg/mL、个人谷值或者基于它的用药建议。比再增加新的自由参数更优先的下一项工作是：寻找或获取研究对象层面包含准确给药时间、基线、剂量、持药方式、测定平台、至少若干2–24h时间点的资料，并在查看这些新资料之前冻结比较指标与候选参数选择；同时复核 Price 原图/表格 AUC 的口径。**没有新的独立资料，就不声称完成模型临床升级。**

另外，Doll/Sarvaideo 2022 的舌下1mg研究有 0、1、2、3、4、6、8 小时的定时抽血、LC-MS/MS E2峰144 pg/mL。由于其0–8h证据与本项目之前模型开发决策均已接触过，即使再纳入它，也不能冒充完全未见的盲化保留集。参见 [PubMed PMID 34781041](https://pubmed.ncbi.nlm.nih.gov/34781041/)。

## 8. 复现方法、文件与引用

依赖 Python3.11+、NumPy、SciPy、Matplotlib。解压 `P2-AG/` 根目录后执行：

```bash
OPENBLAS_NUM_THREADS=1 python tools/p2ag_cross_source.py --output /tmp/p2ag-rebuilt.json
OPENBLAS_NUM_THREADS=1 python tools/p2ag_diagnostics.py
OPENBLAS_NUM_THREADS=1 python -m unittest discover -s tools -p 'test_p2ag.py' -v
python tools/verify_manifest.py
sha256sum /tmp/p2ag-rebuilt.json data/p2ag-cross-source.json
```

在本轮环境中，**完整 JSON 独立重算逐字节一致**，SHA-256 均为 `7ebf1308552b20f85e5eb02bcc19dfff27101488d97a221dec91bee59582031c`。脚本默认拒绝覆盖输出，避免与既有证据混淆。跨软件库版本，浮点优化结果可能存在细微数值差异，不能强行要求不同 SciPy/BLAS 版本的 JSON 也逐字节一致。

- 数据：`data/p2u-observed-aggregates.json`（此前P2-U）、`data/p2x-conditional-ensemble-results.json`（此前P2-X；**只作有信息泄漏的内部对照，不作为本轮拟合输入**）。
- 模型：`tools/p2v_continuous_fit.py`（原 P2-V 数学核，不改原式）；`tools/p2ag_cross_source.py`（留出训练和检查）；`tools/p2ag_diagnostics.py`（CSV、摘要、图表）。
- 结果：`data/p2ag-cross-source.json`（全部 48 次确定性局部训练拟合）；`data/p2ag-compact-summary.json`；`data/p2ag-conditional-holdout-metrics.csv`（20种模型×Price背景场景）；`figures/` 3 张图；19项自动测试与哈希清单。

**已发表研究（研究设计与样本信息的来源）：**

- Komesaroff PA et al. (1998), *JCEM*, [DOI 10.1210/jcem.83.7.4945](https://doi.org/10.1210/jcem.83.7.4945). 早期时间组均值。
