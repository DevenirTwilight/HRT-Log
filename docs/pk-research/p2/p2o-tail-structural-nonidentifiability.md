# P2-O：跨研究快慢输入 PK 模型的实际不可辨识性与长尾风险

日期2026-10-09，研究级假设扫描。**不使用 Doll 的1h 144pg/mL作为定标**，不变更生产模型/ P1历史校准/签名 APK/原P2冻结协议。与P2-N单独展示若干形状不同，本轮系统扫描完整网格，且将所有符合早期约束的候选保留，不挑一个赢家。

## 1. 源头与证据的可比性

已见Rosano1997独立PK25人的1mg舌下 E2 20/40min **组总浓度468/1980pmol/L**，真实给药前基线未知；已见Price1997原版Figure1 1mg舌下 1h约450、2h约225、4h约85pg/mL（原图人工估读、真实基线未知）。Price原论文Table1给1mg单剂基线扣除AUC0–24=2109±1031pg·h/mL，P2-I/J发现该原图人工积分≈1558并存在尚未解释的来源一致性问题。这三种数据不是同一来源的同一统计估计量，**不能拿模型与它们的比较结果制造真实准确率。**

Komesaroff1998 n10、2mg SL，15/30min E2组均值并有本研究0h基线；它可对候选早期形状提出进一步反证，但本阶段并没有利用它选择或排除网格候选（原文15min SEM218pmol/L，个体时点相关性未知）。Yaish2023则含0.5mg q6h反复给药组晨间均值与90min中位数，但不掌握真实完整时钟/协方差，不可拿来校准模型真实谷值。Doll2022已见训练点不用于本扫描任何模型的幅度、形状筛选和验收；仍是记录在来源目录里的有效负证据，而不是唯一标准。

## 2. 模型与受限参数网格

重用[P2-N非负双输入中央室卷积](../../../tools/pk-research/p2n_transit_convolution.py)，形式为

    input(t)= (1-w)*ErlangPDF(n,kfast;t) + w*kslow*exp(-kslow*t)
    h(t)= integral_0^t input(u)*exp(-ke*(t-u)) du
    H(t)=h(t)/h(1 hour).

n是数学输入延迟阶数，不是已证实的人体吸收分室数；w是有效慢输入权重，不是已测吞咽比例；ke不是已测清除常数。**所有曲线1h都归一化到无量纲的1**，所以这轮没有解出mg→pg/mL的绝对转换，更没有人体F/V或患者体重。

全部候选笛卡尔积：

- n={3,4,5,6,7,8}，kf=5、6…15/h；
- ke={0.25,0.40,0.55,0.70,0.85,1.0}/h；
- ks={0.05,0.1,0.2,0.4}/h；
- w={0,0.05,0.10,0.20,0.30,0.40,0.50}。

完整网格6×11×6×4×7=**11088种**；特别补入**ks=ke=0.4/h的462组**，使用连续极限，不能因为公式分母为0就删除有效情景。各参数均为已读论文之后人为提出的探索性范围，不是由独立临床资料定义的有效参数先验。

## 3. 统一且透明的探索性筛选

只使用Rosano raw组均值的40/20min比=4.23077，以及Price旧人工估读的2h/1h≈0.5、4h/1h≈85/450=0.18889（基线假设0）。设三个各自的**人工相对窗口**分别±10%、±15%、±25%，候选满足三个窗口才纳入集合。筛选窗不是从SD/SEM、真实同人相关性、研究校样精度计算的统计CI；也不是预注册的独立验证。

完整结果：

|---:|---:|---:|---:|
| 0 | 75 | 2.198–3.293 | 0.02397–0.16525（**6.89倍**） |
| 25 | 97 | 1.983–2.935 | 0.01460–0.13811 |
| 50 | 62 | 1.727–2.400 | 0.00649–0.08560 |

基线25和50只是**人为灵敏度条件**，不应写成Price已测基线；Rosano真实基线仍未知，筛选其原始均值比不能等价于肯定的“增量比匹配”。因此相同固定网格在假设基线变化时集合也大变；这进一步证明现有汇总资料不足以稳定识别单一人口模型，而不是任何一个候选已被统计证实。

## 4. 极具解释力的近同形状反例：前期比率相差不到1%，谷值却相差约4.6倍

在b=0、三个指标均通过上方筛选的75组中，再要求两个候选的这三个时间比的**相互相对差值均≤1%**，选择谷浓度差异最大的配对（这也是事后探索性选择，不是独立验证）：

| 参数/结果 | A：慢输入极慢 | B：慢输入较快 |
|---|---:|---:|
| n | 5 | 6 |
| kf (/h) | 8 | 10 |
| ke (/h) | 0.85 | 0.85 |
| ks (/h) | 0.05 | 0.40 |
| w（有效慢权重） | 0.50 | 0.30 |
| 20→40min | 3.9056 | 3.9008 |
| 2h/1h | 0.5510 | 0.5556 |
| 4h/1h | 0.1624 | 0.1629 |
| 0–24h Price网格AUC / H1 (h) | 3.019 | 2.301 |
| 真正连续0–24h积分 / H1 (h) | 2.983 | 2.262 |
| 0–∞ AUC / H1 (h) | 3.552 | 2.262 |
| 前120剂每6h一次0.5mg的下一剂前增量 / 单剂1mg的1h增量 | **0.14265** | **0.03104** |

这两个候选在公开组曲线的三个比率上彼此最大相对差约**0.83%**，而重复给药谷增量却差 **4.60倍**。这比“几条模型曲线肉眼相似”更强，因为它可重算、明确指定验收指标和未知状态。它仍不能推断任何患者真实血浓度，表格q6值是**无量纲的比例**，不是pg/mL；选A或B都会强烈改变HRT Log在不规则服药和长期间隔的预测。

另一个关键差别：A有很慢的有效输入ks=.05/h，**24h之后还有浓度面积**；B则在24h基本衰减完成。两模型都使用相同的假设中央消除ke=.85/h，所以尾部不同并不需要假定临床实测清除率改变，单靠吸收输入就足够制造长尾歧义。不能把A的慢输入时间尺度叫作人体真实E2消除半衰期。

## 5. 积分严格恒等式与独立验证

对单位总吸收权重且归一化之前的双输入中央室方程：

    dX/dt=Input(t)-ke*X(t), X(0)=0, integral_0^∞ Input(t)dt=1,

积分得到 **∫_0^∞ X(t)dt=1/ke**。如果将每条曲线再除以X(1h)，归一化后的AUC∞ = 1/(ke*X(1h))；它随kfast、kslow、w、n改变，不能只用早期相对形状识别。对任意T，未归一化积分可直接从质量守恒计算

    ∫_0^T X(t)dt = [F_input(T)-X(T)]/ke,

其中F_input(T)是输入分布到T为止的累计份额。用这个**独立于图像梯形法**的连续积分恒等式，可检查模拟器尾部是否为数值积分伪象。

结果显示A组离散AUC0–24≈3.019h、连续积分≈2.983h，AUC∞≈3.552h；B组分别≈2.301h、2.262h、2.262h。Price作者Table1单剂AUC/H1从不同统计对象粗算≈2109/451=4.676h，原Figure1手工估算≈1558/450=3.462h，**两者原论文还相互不一致**；不能利用其中任一个单值择优修改kslow使软件看似更精准。

## 6. 研究意义与下一步真实验收

**结论不是“六级比五级好”，而是：仅靠三个单剂形状比，晚期AUC和规律给药谷值高度不确定；有效慢输入速率、份额、中央室消除组合存在实际不可辨识性。** Rosano/Price的不同人口和检测法、不同个体基线、Rosano SEM与Price断轴扫描读图的不确定性、Price Table1与Figure1无法调和，均令这些窗口只具探索价值。通过这次筛选的75组不能称作临床有效参数后验或95%置信区域。

真正需要后续可用的独立验证包括早期10/15/20/30/40/60min与1/2/3/4/6/8/12/24h的同研究E2 LC-MS/MS，实测各人基线、准确给药/采血时间、实际前剂历史、制剂/吞咽/含服，以及样本间协方差。无法获得前，不能声称可稳定推算重复给药浓度、F/V、个体CV或软件P5–P95对90%真实人体覆盖。
