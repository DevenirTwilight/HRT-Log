# 敏感性与失败边界

冻结experiment-settings.json预定所有假设；完整339档拟合及外部负结果见results/analysis.json.profiles，不筛最佳档。15个A、324个B情景均在预设幅度界内；残差最大约8.1e-28，无边界失败。测试另用合成越界目标证明显式失败，不靠裁剪通过。

- 形状/尾：训练残差近0仍24h相差巨大，见identifiability。缺8–24h完整人体验证；模型内部AUC0–8/24、连续峰不能冒充人体观察。
- 基线：固定0/25/50同时改变Doll条件拟合幅度和外部绝对输出；并非各点自由修正。Burnier fold另固定5/24/50，不当个体基线。Yaish治疗谷不用于拟合内源基线。
- 体重：仅Featherline按软件假设60/80/100kg比较；A/B无实证V随体重规律，未施加。不存在“研究实测80kg”。
- 含服：当前HRT2/5/10/15分钟工程变换记录在hold_sensitivity；A/Bunsupported，不凭直觉添加缩放，任何档位都不称人体验证。
- 剂量：1/2/4/10mg与时点序列均合成，10明确越界；数学线性叠加不是人体剂量比例证明。不把1mg群体均值乘4当4mg人体观察。
- 历史：q6/12/24×30天、最后漏服、实际剂量更正到4mg、停药48h保留完整事件和叠加误差。Yaish另比较单次、缺最近一剂、夜间12h间隔，所有是假设历史；不是偷换论文四次/日为任意q4频率。
- 检测：LC-MS/MS/未知/Immulite/其他免疫不强合并、不做经验倍数修正；pmol/L仅3.671单位转换，不是检测法转换。EV质量比272.39/356.51仅合成单位回归。
- 删除研究：删除Doll无估计；删除已见外部研究不改拟合。没有可支持留一研究模型选择的数据量，不提供排名稳定性百分比。
- 不确定性：人体参数分布、测量误差、研究异质性、结构误差分别not_estimable；固定形状范围不是95%区间，随机压力测试不是人体验证覆盖率。

数值：独立RK4（三状态ODE）/Simpson与解析gamma/双途径积分一致；精确/近等率以及率穿越不符号翻转，压力率1e-6–1e3/h、早时到长尾、3000固定种子抽样皆有限非负，不用浓度上限或负值钳制。相对数学验收1e-6，与生理准确度阈值无关。旧P0九个Kotlin人口场景117个固定时点独立回放，正式未校准模型保持既有输出。
