# P2-AU：真实配对数据的背景剖面、零残留负对照与给药时钟不确定性

研究日期：2026-10-11。研究类型：**已见人体数据的回顾性数学敏感性分析**。不是新的人体研究，不是独立预测验证，也不批准模型替换。

## 研究依据与新增问题

P2-AR-REAL 用 VNC54（Yaish）11 名舌下组参与者、20 次有效前后配对访视，比较正式 Legacy 与 P2-X 冻结的 15 套 M2 候选。原始 Excel 在私人环境重新核实 SHA-256，来源 `038a935f699ddadc9f0d843e125e5ee8047132773d1d6485085d6302066867dd`。同时冻结 P2-X JSON SHA-256 `7bb08b9e5b397e766cd63018567542520105755c9e578a8cdf4204a6df8d5367` 与 Legacy 快照 SHA-256 `70d95c7e38222520b09c0d7a740ccf5c92d94775e3aea589cc157daff1ebd2e2`。研究没有拟合新参数，没有再选候选。个体记录没有进入公开仓库。

P2-AR-REAL 使用了每次访视可自由选择的非负背景 b 与正幅度 G：

\[C_{pre} = b + G S_{pre},\quad C_{post} = b + G S_{post}.\]

对于 Cpost>Cpre>0 和 Spost>Spre>=0，令实测比率 q=Cpre/Cpost、模型残留比率 r=Spre/Spost。无需统计拟合，就有：

\[\alpha = \frac{b}{C_{pre}}=\frac{q-r}{q(1-r)}.\]

原条件 **b≥0** 等价于 q≥r。**r 越小，不一定代表模型越接近真人；它可能只是把更多的给药前浓度转移给自由背景 b。** 本轮增加未知背景分数的硬上限 \(\alpha\le B\)（B=0、0.25、0.50、0.75、1）。这些上限完全是研究者设置的应力情景，**不能作为真实内源性 E2 或检测误差比例**。

## 负对照：为何“相容”不能等于“正确”

如果创造一个无生物合理性要求的数学核，使给药前模型残留 Spre=0、给药后响应 Spost=1，那么任何 Cpost>Cpre>0 均可由 b=Cpre、G=Cpost−Cpre 精确解释。它对现有 **20/20 配对**全部相容，却并没有证明任何药代准确性。此时背景分数必为 **100%**；当 B<1 时这个退化负对照即无法通过。

此控制不是候选模型，也不能据此推断真实 Legacy/M2 的参数。

## 跨时钟集合的进一步识别区间

强制全队列用五种时钟中的某一固定时钟，和允许每一次访视分别挑最有利时钟，是不同的问题。后者只是宽松的**上界**，并不代表任何人的真实用药情况。B=1 时，Legacy 在固定时钟中的最小/最大相容数是 **16–20/20**，M2 有 **5/15** 个候选在五种情景中至少有一种可使 20 次全部相容，但 **0/15** 能在五种情景下同时全部相容。B=0.75 时，Legacy 各情景最大相容数只有 **8/20**，M2 各候选的最佳固定情景最大可到 **10/20**，同样无模型能覆盖所有配对与五种假设。

这种集合区间是**条件数学约束**，不是人群药代浓度的预测区间或 95% 可信带。

## 限制、研究伦理与后续数据门槛

1. 真实来源是已经参与 P2-Y/Z 开发判断的 VNC54；数据不盲、并非未经接触的外部验证。20 次访视来自 11 人，不能按 20 个独立患者做二项统计。
2. b 代表未解释的 additive background（可能包含分析误差、非当前模型的其他贡献），**不等于未治疗时内源性雌二醇**；不能根据本研究的 50%/75% 情景宣布现实背景有该比例，也不能未经外测为其赋物理上限。
3. 含服时长、真实既往剂量时钟、实际采血分钟、跨访视的幅度稳定性及检验平台误差机制均不充分；零噪声自由参数模型只是方法学压力测试。
4. 全 60 天稳定给药、统一四次固定剂量为数学情景；模型可被真实时钟、漏服、代谢变异推翻，数值不能用于个体治疗或剂量选择。
5. **旧、新模型同样没有可用的全时程未见个体 E2 实测外部验证**；个人 pg/mL 和晚期 8–24h 残留仍不得放行。P2-C 保持 HOLD。
