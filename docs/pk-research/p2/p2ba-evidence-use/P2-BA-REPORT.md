# P2-BA｜在真实研究单位上重新计数证据，并建立按用途放行的 M2 可执行契约

**2026-10-11｜科研状态：基于公开、已见群体资料的后验审核与软件研究能力风险分级；没有新人体给药样本，也没有批准改变正式个人 PK 模型。** 研究源是 [P2-AZ 已归档的54折结果](../p2az-retrospective-transfer/p2az-results.json)，以 Git Blob SHA-1 `38fb3ccc4521f8f0d683d2c755c0370539831ed9` 不可变绑定。P2-BA **不重新拟合** Legacy/M1/M2；把已完成研究的统计单位与产品真实使用目的拉回一致。

## 一、核心问题：54/54 胜出究竟相当于多少份证据？

P2-AZ 54 折严格展开为：**3项原始已发表人群药代研究**（Price1997 1mg，同一批6名交叉参与者；Rosano1997 独立25名PK组；Komesaroff1998 n10）× **18个围绕原图读法、假设基线的条件情景**。

每次留出整个研究时，只在其余两项研究的组均值形状上从**另外新建的**216条双输入M2模型中选择曲线，以1h（Komesaroff为30min）组级浓度增量为锚点，比较留出研究的其他时点。**它不是54次独立临床外部验证，也不是冻结P2-X15条模型的盲测**：所有研究在架构/有限候选参数网格设计以前已经暴露给研究者。

P2-BA按三项实际研究单位重新统计 **18种假设情景下所有三来源是否同时保持优于Legacy**：

| 比较范围 | P2-BA实际计算 | 可以讲清楚的命题 |
|---|---:|---|
| 新建M2 vs 正式 Legacy | **18/18个假设情景的三项研究全部较低形状MSE** | 已见三队列的跨研究形状迁移获得稳健的回顾性支持 |
| 新建M2 vs 新建M1 | **12/18个情景的三项研究同时较低** | 简单双输入结构增益并不在全部条件下对M1成立 |
| Rosano留出：M2 vs M1 | **12/18个情景较低；6/18反例** | 不得宣称双输入模型始终优于单输入模型 |

**务必保留最重要的限定：** 只有三项真正不同来源的组级药代研究；18种情景只是同一资料的扰动，既不是18次独立试验，也不可用作p值、置信区间、贝叶斯概率或个体预测成功概率。

## 二、使用相同研究单位的误差比例压力核查

以下数字为每项留出研究的 `MSE(M2)/MSE(Legacy)`，且各时点先按该研究的观察锚点归一化。该比值**不是个人误差比、不代表实际绝对血清E2估算误差下降百分比**。

| 留出研究 | 18种情景内最低 | 情景中位数 | 最高（最不利于M2） |
|---|---:|---:|---:|
| Price1997 | 0.012835 | 0.052689 | **0.269619** |
| Rosano1997 | 0.014152 | 0.031695 | **0.213371** |
| Komesaroff1998 | 0.005705 | 0.013956 | **0.070805** |

全部三项在此有限假设集合中甚至最不利情景的比例也小于1，强化了已经发表曲线的形状证据。不过 **Komesaroff留出仅有15分钟这一个非锚计分点**；由于研究内部未知协方差且人群、剂型、检测平台各异，三个MSE比值都**不是统计独立可相乘的似然证据**。数学上更小的无量纲形状误差，不能通过简单乘以剂量或 Doll2022 的1h总峰值变成个人绝对浓度。

相对于新建单输入M1：
- Price：M2/M1情景中位MSE比 0.047324、最高0.275023，18/18更小；
- Rosano：中位 0.384510、最坏 **2.342728**（M2反而差），仅12/18较小；
- Komesaroff：中位0.246862、最高0.881616，18/18较小。

这种记录比简单的“54/54胜出”更真实：M2相对真实Legacy的**形状表现**已有支持，但它超过一个合适的简单模型的**必要性/复杂度效益**并未充分定论。

P2-AZ自拟 `训练MSE + λ×名义自由度` 选家族，在λ0时54次都挑M2；λ0.002时22次挑M2、32次挑M1；λ0.01时54次挑M1。λ为人为灵敏度设置，**不能被包装成正式AIC/BIC信息量或经过预注册的惩罚阈值**。

## 三、按模型用途区分风险，而不是永远要求“新数据”

欧洲药品管理局 EMA 已实施 [ICH M15（2026-07-23生效）](https://www.ema.europa.eu/en/ich-m15-guideline-general-principles-model-informed-drug-development-step-2b-scientific-guideline)：研究者应针对特定决策明确“question of interest”“context of use”、模型影响、错误决定的后果、证据与可信度。**该指南为药物研发模型证据框架，并非 HRT Log Android 软件的官方认证证书或自动法律批准。**

当用途仅是“科研查看两套模型为何形状不同”时，P2-AZ/BA的模型对照、条件计算和准确标注就有实际价值；当用途升级为“用户根据pg/mL预测改变剂量”时，错误决定的后果和证据门槛完全不同。

另见 [EMA ICH M10生物分析方法指南](https://www.ema.europa.eu/en/scientific-guidelines/ich-m10-bioanalytical-method-validation)，提醒 E2 这样的内源性分析物涉及背景、QC与测定方法验证；现有三项研究的不同测定方法和边际组统计不能被视为同一实验室的配对个体校准。

### 10项**可执行**软件能力门槛

| 预期 App 用途 | P2-BA 结果 | 显示/逻辑上的强制边界 |
|---|---|---|
| 现有 Legacy 的历史 pg/mL 视图 | **保留、带不确定性文字** | 不擅自改写用户旧记录，不声称临床验证 |
| M2 实验性归一化单剂曲线 | **允许用户主动开启研究页面** | 单位为无量纲 `H(t)/H(1h)`，不能称为个人血药浓度 |
| Legacy/M2 同屏相对形状比较 | **允许用户主动开启** | 两条都按本模型1h响应归一，不可混用绝对pg/mL和无量纲纵轴 |
| M2 条件性峰值时刻 | **可展示研究模拟值** | 不是用户真实 Tmax 或诊疗采血建议 |
| M2 个人绝对浓度 pg/mL | **禁止** | 未验证个人基线、幅度、时间与真实人体预测精度 |
| 将冻结15个候选直接标成“90%人体预测区间” | **禁止** | 参数集合不是有覆盖率保证的概率分布 |
| M2 个人长期稳态谷值 | **禁止作为可信预测** | 慢尾/真实用药史/基线/消除联合不确定 |
| M2 自动成为正式默认模型 | **禁止** | P2-C正式迁移闸门仍 HOLD |
| 按 M2 自动建议增减激素剂量 | **禁止** | 不具任何药物个体决策授权 |
| 用 Doll2022 144 pg/mL 群体总峰直接标定全部 M2 个体 | **禁止** | 群体总峰不等于该用户1h扣基线的响应幅度 |

研究代码 `tools/pk-research/p2ba_evidence_use_gate.py` 实现了逐项能力裁决 `choose_permission(capability,opt_in,label_unverified)`：
- **未知能力名直接报错、fail-closed**；即使设置所有 opt-in 及提示标记，六类未获证据的能力仍拒绝；
- “允许的实验比较”必须真有用户主动选择 `opt_in=true`，并明确两套模型同为无量纲；
- 现有 Legacy 历史视图本来就在用户软件里，保留功能不表示用历史安装默认推定其临床准确，必须标明其未被个人外部确认；
- **本阶段只生成可供工程集成审核的研究能力矩阵，不修改 Android 界面/血药浓度显示页面的实际代码。** 未来若落地，需独立工程 PR 验证对应页面真的把各条规则落到 UI/图例/单位/持久化逻辑上，不能把 Python 规则CI通过说成 Android 已有这些保护。

科研产物：本报告、[完整机器结果/能力矩阵](p2ba-results.json)、[README和复现说明](README.md)、Python标准库实现 `tools/pk-research/p2ba_evidence_use_gate.py`、15项组级折分隔离/拒绝临床能力测试 `test_p2ba_evidence_use_gate.py` 与独立工作流 `.github/workflows/p2ba-evidence-use.yml`。输入是**P2-AZ真正生成、逐字节归档**的原始JSON；运行时核对 Git BLOB SHA-1，防止上游偷偷重算、更换背景或修改折分。
