# P2-J — Price 1997 原始图表的独立积分与基线数学审计

## 1. 原论文到底记载了什么

用户已上传 Price 等1997年 Obstetrics & Gynecology 89:340–345 原版六页PDF（DOI 10.1016/S0029-7844(96)00513-3，sha256 40ecaf3a36b6481bbf2e9fc074066700f141ae3a51959b5bf6138cd920deb70a）。印刷341页 Methods 声称六名绝经后女性随机交叉单剂，E2为提取后RIA，0/1/2/3/4/6/8/12/18/24小时采血；各人计算PK参数前扣给药前值，AUC采用梯形法。印刷342页 Table1 的1mg SL E2 AUC0-24为2109±1031 pg·h/mL（mean±SD）、Cmax451±162 pg/mL。印刷343页 Figure1是 E2 的群体均值±SD，1mg SL为实线，Y轴180至约300pg/mL有刻意断裂；图中未直接画出真实0h基线，也没有明确声明图值是否已经扣基线。不能用Figure2的E1或误差棒当Figure1 E2均值。

## 2. 延续P2-I旧人工采点，明确两个不同的积分定义

P2-I原始图在PDF300dpi人工估读1/2/3/4/6/8/12/18/24h群体均值450/225/116/85/56/45/34/25/24 pg/mL；不是原作者逐时表。之前P2-I为敏感性**人为指定0h=20**，其原始梯形积分为1567.5。现在P2-J暂设0h=0，仅作为数学极限情景，1–24h现有采点给出1557.5。图的较高人工读取情景（并非置信区间、并非严格可证明的图像最大误差）在设0h=0时积分1760.5。另一个Wikimedia Commons 2018/2019 WebPlotDigitizer+Plotly重绘同一Price Figure1，图读数积分1557.5；这是同源重建，不是独立临床数据集。

定义线性梯形算子 T。Figure若是未扣基线的同六名个体、相同时间加权的算术平均，令其未知非负0h平均浓度b，则T(图浓度，首点=b)=1557.5+0.5b。论文声称个体先扣给药前基线、然后积分；如果使用完全相同0–24h数据和同一采样权重，则平均后的基线修正AUC恰好为：

  AUC_adj(b) = 1557.5 + 0.5b -24b =1557.5 -23.5b。

因此只要b≥0，按该条件最大不超过1557.5，不可能达到Table1的2109。数学上要让当前中心读图硬匹配2109，需b=(1557.5-2109)/23.5≈负23.47pg/mL；它只是不可行条件反证，不是实际人体测得的负基线。即便人工全部取较高点且非负基线，最有利的设0h=0面积也仅1760.5，仍低348.5。

重要区分：如果Figure本来就绘制已经扣除基线的增量，则不再二次扣基线，0h应当为0，图积分仍约1557.5；这同样是条件情景，而不是已证明作者的Figure绘图规则。

## 3. 为什么不应以统计波动掩盖这个疑问

相同个体同一采样时间网格，T(算术平均C)=算术平均T(C)，T(C-b)=T(C)-24b。个体AUC的±1031是跨人的SD，Figure各时点的SD是时间点群体离散度；SD不是估读误差，也不解除同来源均值与积分的线性恒等式。“先每人算AUC再求平均”本身不能解释差异。“研究人数只有六人”也是重要外部不确定性，但不是忽略内部计算定义的理由。若每人的实际时间权重不同、缺失/插补/图线非算术均值、图像错误、未披露的作者AUC处理，则上述条件可能不成立；这些尚未被逐一排除。因此绝不直接宣布论文错误。

## 4. 新的定量错误定位能力

标称采样0/1/2/3/4/6/8/12/18/24h的梯形权重分别为0.5/1/1/1/1.5/2/3/5/6/3小时。对于P2-I的中心读图原始积分1567.5，达到2109需补541.5。若这差额仅来自18h一处均值，需要把原图18h的25提高约90.25pg/mL；若来自12h一处，需提高约108.3pg/mL。这是线性敏感性指示，不是已排除所有图像误差的严格上界，更不建议据此修改HRT生理模型。

下一步先向能取得原论文内部方法的人核实：Figure1是否基线修正、每个图点人数及群体统计类型；Table1具体AUC算法、是否有实际采血时刻差异/缺测；0h个体与群体均值；是否存在作者正式勘误。最好安排第二名独立观察者在不知道P2-I坐标的情况下重标定Figure1断轴，而非重复同一个Wikimedia图。如果这些都不能解决，再联系论文研究者问清楚准确的计算定义，而不申请可识别患者记录。

## 6. 新增 P2-J 末端外推反事实检验：数值接近，不等于证据解决

对 P2-I 的同一已见人工群体读数，若假设24h E2 **原始总浓度约24 pg/mL**，且暂时错误地把原文 Table1 报告的 **18.0h平均终末半衰期**作为图中群体曲线的单指数下降率，则将24h之后继续积分到无穷远，会人为增加

AUC_tail(raw)=C24 × t_half / ln2 = 24×18/ln2 ≈ **623.24 pg·h/mL**。

于是原图的假设0h=0总浓度梯形面积1557.5 + 上述原始总浓度外推 ≈ **2180.74**，数值上距离 Table1 的2109仅71.74。这是一个值得登记的**反事实相近现象**，不是原作者确实采用0–∞外推的证据：

- 原文正式标记的是 AUC0–24，且说明在计算PK参数前扣除每人的0h值，并非AUC0–∞。把未经基线扣除的原始总浓度外推到无穷会累计永久背景浓度，本身就不符合药代增量总暴露的定义。
- 论文的18.0h是**各受试者终末半衰期的群体统计均值**，不是原Figure1群体均值在24h之后的真正斜率，不能无条件把均值半衰期和均值浓度直接相乘。
- 如果为演示假设图的18h均值25、24h均值24都是原始总浓度且真实0h平均背景恰好20（**并非已获原作者数据**），那么最后两个点的扣基线增量为5与4，按6h间隔估出的图形末段半衰期是 6ln2/ln(5/4)≈**18.64h**，与报告的18h在数量级上一致。可是其0–24h基线扣除AUC只有 **1087.5**，继续用增量4pg/mL和18.64h指数尾外推也只得到约 **1195.05**，反而与2109更远。
- 若不扣背景，18h均值25、24h均值24的原始总浓度尾斜率给出约**101.88h**，而不是18h；这说明是否扣基线能极大改变终末斜率解释。

**科学判断：** 出现接近的raw extrapolation 2181数值，提示应向原作者询问其AUC0–24计算的实现与期刊标签；但没有任何正当依据将Table1重命名AUC∞。绝不据此给HRT Log追加18h慢尾、填新的预测覆盖率、或更改P2-A/B数据身份。这个反事实的每一个数字都是旧手工图值加数学假设，不是新增人体测量。计算与6项边界测试见 [p2j_tail_hypothesis.py](../../../tools/pk-research/p2j_tail_hypothesis.py)。
