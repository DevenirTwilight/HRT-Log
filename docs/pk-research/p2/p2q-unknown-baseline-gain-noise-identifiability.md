# P2-Q｜未知基线、幅度与检测误差时的舌下 E2 参数可辨识性与简繁模型稳健性

2026-10-09。**此报告是完全合成（synthetic）与已见模型结构的研究，不是新增临床验证、患者血药浓度或用药建议。** 不改 HRT Log 正式 E2_SL 人口参数、P1 校准、P2-A/B 冻结资料、历史计算、数据库、P5–P95、Android 或已签 APK。特别地，**Doll2022 的 144 pg/mL 未用来选择、训练或验收 P2-Q 的任何模型**。

## 1. 原研究能支持的陈述与严格的证据边界

- 上游 P2-O 曾用**已见** Rosano1997 n25 的 20/40 分钟汇总均值与 Price1997 n6 的 Figure1 人工估读（2h/1h、4h/1h），加人为误差窗口选出 **75 条数学曲线**。这些不是 75 位受试者，也不是后验抽样。Rosano n25 给药前基线仍未知；Price Figure1 与原 Table1 的 AUC 差别仍未解决。
- 已见 Yaish2023 q6h 的晨间 **mean**、90min **median** 不能拼成同一人的完整序列；Yager2022 与 Abdelmawla2023 属于同一个途径混合的 TransPrEP 队列。不存在已锁定、可用于估计个体随机效应、测定误差分布或临床90%覆盖率的独立人体轨迹。
- 本次设定合成基线 **b=30 pg/mL**、合成 1h 增量 **A=150 pg/mL**；这两个量**不是任何发表论文或用户的测量**。每个研究样本假想满足 `Y(t)=b+A×H(t)`，`H(t)=h(t)/h(1h)`，输入核由 P2-N/P2-O 原样复用。给定实验设计只用这些量作灵敏度分析；不同研究的免疫测定/RIA/LC-MS/MS 偏差绝不被解释为已校准的换算系数。

## 2. 不需要统计拟合就可以**严格证明**的结构不可辨识性

1. **F/V 不可单独辨识**：单剂浓度可写作 `C(t)=b+D×(F/V)×g(t;θ)`。对任意正数 `c`，把 `(F,V)` 替换成 `(cF,cV)`，浓度不变。因此没有静脉给药或其他额外约束时，不应分别输出“真实舌下生物利用度 F”和“真实分布容积 V”。可推断的至多是组合有效幅度（如 F/V）。方法文献：[Parameter Identifiability of Fundamental Pharmacodynamic Models](https://pmc.ncbi.nlm.nih.gov/articles/PMC5136565/)（该文明确以线性口服一室PK的F/V作为例子）。
2. **路径权重为0时，慢输入速率完全不可辨识**：双输入模型 `h=(1-w)g_fast+w g_slow`，若 `w=0`，所有 `k_slow` 取值都给出完全相同的 C(t)。同理 `w=1` 时快输入的 `n,k_fast` 不影响输出。只因优化器打印了一个数，并不表示它被人体数据识别。
3. **一阶吸收与一阶消除的调换（flip-flop）**：`g_1(t;k_a,k_e)=k_a(e^{-k_e t}-e^{-k_a t})/(k_a-k_e)`。调换两者后，整条曲线仅相差常数 `k_e/k_a`；当研究级幅度自由时，两条**归一化曲线完全相同**，即使理想连续无噪声观测也无法单靠该输出标注哪一个速率属于吸收、哪一个属于清除。这是该简化结构的严格别名，并不宣称所有多输入/多室结构均有该等价性。
4. **只有两次有值采样且 b、A 同时自由时**：`Y_i=b+A H_i` 的两个方程通常允许很多不同形状以各自 `(b,A)` 精确插值（只要所求 b、A 非负）。这是局部实验设计/正约束下的事实；并不意味着3点或更多点必然足以辨识所有参数。

## 3. 实际 P2-Q：解析消去未知 b 与 A 后，能区分多少模型？

程序使用**精确非负二元加权最小二乘（含正交象限边界）**：已知 b/A、仅 A 未知、b/A 都未知三层逐层比较；给定目标曲线 `Y_i` 使用固定的合成边际误差

`σ_i = sqrt(σ_abs² + (σ_rel × Y_i)²)`。

这是用于比较的**固定参考加权距离**，不是在未知 σ 下联合拟合的异方差高斯似然。筛选只看 `Σ[(Y_i−b−A H_i)/σ_i]² ≤ 9`，9 是人为设置的无量纲容忍阈值，**绝非 χ²的临床显著性阈值或统计置信区间**。比较75×74=**5550个有方向的异模型预测**，不是2775对人体轨迹；由于每个目标形状定义自己的 σ，A→B 和 B→A 不一定等价。晚期时间指 6/8/12/24h，另测试加入合成0h给药前测定。

| 假设的检测误差（不是实测精度） | 采样点 | b、A已知时尚无法区分/5550 | 仅A未知 | **b、A均未知** |
|---|---|---:|---:|---:|
| 极理想化：绝对误差下限1 pg/mL、比例2% | 0.25/0.5/1/2/4h | 527 | 654 | **1249** |
| 极理想化，同上 | 增加6/8/12/24h | 143 | 178 | **372** |
| 极理想化，同上 | 再加给药前0h | 143 | 178 | **294** |
| 合成较小误差：绝对下限5 pg/mL、比例10% | 0.25/0.5/1/2/4h | 5489 | 5530 | **5534** |
| 合成较小误差，同上 | 增加6/8/12/24h | 5362 | 5477 | **5521** |
| 合成较大误差：绝对下限15 pg/mL、比例25% | 增加晚期点甚至0h | 5550 | 5550 | **5550** |

**解释：** 即使在理想精度下，单让基线与幅度自由就把早期未分辨的比较从527增加到1249；加入所有晚期点与0h仍留下294。在误差较大时，给定 A=150 和 b=30 的这组条件场景下模型区分基本失效。这是**敏感性证明，不是说任何真实LC-MS/MS实验真的只能有这些分辨能力**；实际 0h 和1h也有误差、相关性、检测下限，未知剂型和个体差异可能使条件更困难。外部误差标准不可凭空从研究论文借过来。

即使理想精度且增加6/8/12/24h，b/A自由时尚有**74个有方向的未区分比较**，其候选预测的q6合成谷增量彼此差至少2倍；加0h后降低至34（同一人为合成）。可见“拟合得类似”并不能确保对重复给药谷值可用。

## 4. 简单 vs 复杂：三类结构的**合成真值**竞争，不选定医学赢家

共同训练窗口 `0.25/0.5/1/2/4h`（仅5个值，且b/A两个自由未知），真正未参与**该次合成拟合**的测试窗口 `6/8/12/24h`。选三种完全人工真值：

- **M0 一阶直接输入**：n=1, k_fast=1.8/h, k_e=.4/h, w=0；候选网格6种。
- **M1 单一路径transit**：n=5, k_fast=8/h, k_e=.85/h, w=0；候选网格18种。
- **M2 双输入**：n=5, k_fast=8/h, k_e=.85/h, k_slow=.05/h, w=.5；候选为上述已见75种，且有效慢路径为正。这一真值是 P2-O 已展示过的反例之一，不是实际人体配置。

对每个真值和每种合成误差分别产生40套**固定种子高斯模拟值**，仅训练时拟合 b≥0/A≥0 和预定网格候选曲线；在合成的“真实无噪声”晚期轨迹上报告以参考σ标准化的**平均平方预测差**。这并非人类数据上的 cross-validation，也不预测真实临床样本误差。

同时比较：无结构惩罚 `SSE` 与人为偏好简洁的 `SSE+(d_shape−2)×ln(5)`（M0/M1/M2的形状自由度分别2/3/5）。因为网格采样密度、形状离散化、噪声方差的固定方式均人为决定，**这不是严格的AIC、BIC或Bayes factor**。

| 合成条件与真实曲线 | 不惩罚：40次中 M0/M1/M2 获选 | 偏好简洁：M0/M1/M2 获选 | 未惩罚/有惩罚的**晚期中位预测误差** |
|---|---|---|---|
| 极理想精度，真M0 | 40/0/0 | 40/0/0 | 1.52 / 1.52 |
| 极理想精度，真M1 | 0/38/2 | 0/39/1 | 0.53 / 0.53 |
| 极理想精度，真M2 | 0/0/40 | 0/3/37 | 8.94 / 7.65 |
| 5pg/mL＋10%，真M0 | 26/12/2 | 37/3/0 | **7.27 / 3.40** |
| 5pg/mL＋10%，真M1 | 0/21/19 | 0/40/0 | 1.19 / 0.70 |
| 5pg/mL＋10%，真M2 | 0/12/28 | 0/40/0 | 1.56 / 0.96 |
| 15pg/mL＋25%，真M0 | 12/24/4 | 32/8/0 | **2.82 / 2.18** |
| 15pg/mL＋25%，真M1 | 0/23/17 | 6/34/0 | 0.72 / 0.91 |
| 15pg/mL＋25%，真M2 | 0/20/20 | **7/33/0** | **0.70 / 1.29** |

**稳健性结论不是“简单模型永远对”**：在真值确实有慢输入、测量很精确时，复杂模型几乎总是被识别；误差增大则强简洁惩罚倾向错选单一路径（真M2时甚至0/40选中M2）。反过来，当真值确实简单时，无惩罚的复杂族会吸收训练误差、在晚期有更高风险，简洁惩罚常改善外推。**即便正确模型类获选，晚期个别连续参数、尤其慢尾和b仍可能高度不稳**（理想精度真M2晚期标准化误差中位仍接近9），不能把分类正确率等于准确的个人浓度预测。

模拟模型网格**不均衡**（6/18/75），后一类来自Price/Rosano已筛选的同源证据，且使用固定参数非真实极大似然优化；替换任一误差、真值、时钟、选择惩罚或候选范围都可能反转排名。实际模型精度主张只能建立在未见的新人体数据上。

## 5. 当前能够识别与不能识别的参数：分层建议

| 对象 | 在本轮条件下能否得到可信人体估计 | 说明 |
|---|---|---|
| 单研究0h真实浓度 b_s | **不能** | 这里只有合成b=30；若将来0h实测，按给药历史检验是否是真正基线还是既往剂量残余。 |
| 单剂有效幅度 `D × F/V` | **只能在足够采样、控制背景并固定结构后估计组合** | 缺未知真实b时更难；个体体重、分析法、剂型都可能使幅度研究间变化。 |
| 单独的F、V、真实黏膜比例与吞咽比例 | **结构上不足** | 需要不同途径/静脉或额外可追溯测量与结构约束；w不等于吞咽率。 |
| n、kfast、kslow、w、ke | **本轮不能唯一人体估计** | 在w=0等处存在精确不可辨识，在有限错误数据下有实际混淆；必要时降低阶数或仅报告形状区间。 |
| 6–24h AUC及q6谷值 | **无法临床验证** | 本轮只能给模拟反例；不是P5–P95人体覆盖率。 |
| 分析法残差σabs、σprop及研究级校准偏差 | **不能** | σ仅是三种假设；不同平台测定不应合并未知真实误差。 |

文献方法依据：[Structural and practical identifiability analysis — beginner’s guide](https://pmc.ncbi.nlm.nih.gov/articles/PMC11465550/)（profile likelihood是正式实际辨识工具；**本轮只对b/A做固定权重WLS投影，不应称为完整profile likelihood**）；[Structural identifiability of PBPK models](https://pubmed.ncbi.nlm.nih.gov/9189655/)；[Proost 2017 combined proportional/additive residual errors](https://pubmed.ncbi.nlm.nih.gov/28512056/)。这些论文解释方法，**不**提供本研究的合成σ或临床有效性认可。

## 6. 最小模型建议、下一项能真正改变决策的研究

- 将正式产品中的当前E2_SL模型**保持冻结**，但避免把其参数带宽叫作临床90%预测区间；未来若必须研究性输出，优先展示模型适用性警示、输入数据状态和不同模型的分叉，而非假定个人尾部精度。
- **科学研究版先保留 M0（一阶）/M1（有限transit）/M2（正双输入）三类，先检查M0/M1是否达到预先定义的跨研究硬性形状门槛，再考虑增加慢输入。** M0在Rosano/Kom早期形状可能不合，但这是研究级负证据；本轮合成数据不能直接淘汰生产或选M2。
- 最优下一步不是继续为现有Price或Doll调参，而是取得带给药前（考虑残余）、独立1h幅度、6/8/12/24h密集测量、真实给药和采血时钟及检测法CV/LLOQ的**同一试验人体时序**；需要各人配对结构/研究级相关性才能进行真正的NLME残差与区间校准。
- 在真实观测中使用经批准的测量误差模型做参数 profile likelihood、恰当的缺失/检出限处理、按完整研究留出验证，并开展结构简化/研究间偏倚敏感性；不要把本轮合成风险矩阵当作药代方案自动治疗或采血建议。
