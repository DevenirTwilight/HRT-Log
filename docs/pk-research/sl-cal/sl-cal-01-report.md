# SL-CAL-01：用化验校准 E2 合计（研究与设计阶段）

日期：2026-10-28 · 任务书原文：[TASK_BOOK_ORIGINAL.md](TASK_BOOK_ORIGINAL.md) · REQUIREMENTS §163
状态：**只研究，不改产品。** 没有任何生产文件被修改（见审计报告 79 的守卫结果）。全部数字来自合成用户；**外部临床准确性仍未确立**（`external_validation_insufficient` / `clinical_accuracy_established=false`），`m2_absolute_pgml` 保持 `false`。本文不提供剂量建议，也不把模型残差解释为“化验错了”。

## 0. 结论摘要（先给结论）

1. **能做，而且有用，但只能做到“整体比例校正”。** 对 E2 合计乘一个个人系数后，合成用户的曲线误差（中位 |ln 比|）：只有舌下 0.26 → 0.12；混合途径 0.38 → 0.16。残差下限由背景基线、曲线形状和采样时间误差决定，校准修不了这些（真值系数的“下限”行：真实基线偏离假设 14–16 pg/mL 时，只有舌下的下限就是 0.30–0.39）。
2. **舌下系数和非舌下系数分不开**，除非化验采样时间足够分散。只在谷值或只在峰值附近抽血时，两个系数完全共线（信息矩阵秩亏）；随机时点且至少 3–5 次化验时才有 60–80% 的概率可分离。分不开时必须收缩到一个共同系数。
3. **推荐方案（SL-CAL-02 的起点）：方案 C“一个共同系数”**，配合“峰值附近降权（delta 法）”和“信息增益不足就拒绝”两条规则。方案 B2（两个系数 + 部分合并先验）精度几乎相同，留作化验足够多时的升级。方案 A（只校舌下）在混合途径下几乎无效；方案 B（两个独立系数）不稳定；方案 D（复用 P1-A 框架，共同幅度 + 非舌下速率）精度与 C 持平但多一个参数，没有收益。
4. **先验宽度必须改。** P1-A 的幅度先验 sd=0.455 是旧舌下模型的语义；M2 以 Price 幅度为中心，而仓库里其他研究摘要换算出的“所需系数”在 0.28–3.7 倍之间（ln 标准差 0.69–1.18）。合成验证里，sd=0.9 比 0.455 更好（只有舌下 0.124→0.102），90% 区间覆盖率也从 0.80 回到 0.90。建议 M2 总量校准用 0.9。
5. **后验区间不能直接展示。** 在检测噪声、采样时间误差、检测偏差、基线或形状偏离存在时，名义 90% 区间的实际覆盖率只有 0.53–0.80。负责人已决定浓度页不再显示区间带；校准后建议用“留一化验一致性”这类不依赖区间的表达（见第 9 节）。
6. **峰值附近的化验：降权，不要排除。** 排除（2.5 小时内）会把峰值设计的用户拒绝掉 87–100%，而这些化验恰恰信息最多；delta 法降权保留了几乎全部收益，并在采样时间有误差时更稳（见 4.3）。

## 1. 问题定义

**校准对象**：E2 合计 `C(t) = B + S(t) + N(t)`。
- `S(t)`：舌下部分，冻结的 M2 形状（候选 `p2x-39`，Price 幅度 `A=434.8357 pg/mL/mg`，响应以单剂 1 小时值归一）；
- `N(t)`：非舌下部分，现有兼容曲线（本研究用 `E2_ORAL`、`E2_GEL_ESTROGEL` 两种形状，参数取自 `pk-params.json`，不改）；
- `B`：背景基线 24 pg/mL，**合计里只计一次**，不随系数缩放。

**观测**：用户化验的总 E2（pg/mL，或 pmol/L ÷ 3.671）和采样时刻。观测模型 `ln y ~ N(ln μ, σ²)`，`σ` 取生产值 `SIGMA_LAB=0.2937`（Zhang 2024 个体内 Cmax CV 29.9%）。

**检测方法与单位**：免疫法与 LC-MS/MS 的系统偏差无法与个人幅度区分——校准会把“这家检测的偏差”吸收进系数。合成扫描里用 ×1.25 的偏差做压力测试（这是**设计假设，不是文献事实**）：曲线误差只增加约 0.01–0.02，但系数不再代表“真实浓度比例”。单位换算用生产常数 `PMOL_PER_PG=3.671`，换算误差为零，但**必须在录入处保留原单位**，否则无法追溯。

## 2. 方法

### 2.1 合成用户
- 方案、先验、采样策略、噪声全部在 `tools/pk-research/sl_cal/`，随机种子 `ROOT_SEED=20261028`，每个单元独立种子，结果与执行顺序、进程数无关（有测试）。
- 4 种给药方案：`SL 1 mg q12h`、`SL 2 mg q24h`、`SL 1 mg q12h + 口服 E2 2 mg/日`、`SL 1 mg q24h + 凝胶 1.5 mg/日`；14 天，化验在最后 5 天。
- 真值个体差异：舌下系数 `g_sl ~ logU(0.3, 3)`；非舌下系数 `g_nsl` 与 `g_sl` 相同（common）或独立同分布（distinct）。
- 化验次数 1/2/3/5；采样方式：谷值（下次舌下服药前 0–30 分钟）、峰值附近（舌下服药后 0.5–2 小时）、随机。
- 基线 100 人/单元 × 72 单元；10 个敏感性扫描各 30 人/单元：噪声（σ=0.10/0.2937/0.45）、记录时间误差（0/15/30 分钟）、检测偏差 ×1.25、真实背景 10/24/40 pg/mL、形状偏离（真值用另一个冻结候选 `p2x-22`）、先验 sd 0.9、“先验一致”真值（`ln g ~ N(0, 0.455)`）。共 17,640 个汇总行。
- 指标：曲线误差（最后 72 小时网格上 `|ln ĉ − ln c|` 的中位数及 p90）、1.5 倍内占比、峰/谷误差、系数恢复误差、留一化验预测误差（LOO）、90% 区间覆盖率、信息增益、拒绝率。

### 2.2 候选方案
| | 参数 | 先验与边界 | 拟合 | 最少化验数 | 不确定性 | 计算成本 |
|---|---|---|---|---|---|---|
| **A 只校舌下** | `ln k_sl` | `N(0, s²)`；非舌下沿用人口曲线 | 1 维 MAP | 1（需有信息） | Laplace sd | 极低 |
| **B 两系数独立** | `ln k_sl, ln k_nsl` | 各 `N(0,s²)` 独立 | 2 维 MAP | ≥3–5 且时点分散 | 2×2 协方差（常强负相关） | 低 |
| **B2 两系数部分合并** | 同上 | 共同水平 `u~N(0,s²)`，差 `δ~N(0,0.25²)` | 2 维 MAP | 1 起可用，分离需更多 | 同上，相关为正 | 低 |
| **C 共同系数** | `ln k`（`C=B+k(S+N)`） | `N(0, s²)` | 1 维 MAP | 1 | Laplace sd | 极低 |
| **D 复用 P1-A** | 共同幅度 `u` + 非舌下速率 `v` | `u~N(0,s²)`，`v~N(0,0.284²)`（生产常数） | 2 维 GN | 1–2 | 2×2 | 低 |

所有方案：不设浓度上限，不裁剪区间，MAP 用阻尼 Gauss–Newton + 回溯，参数只做数值阻尼（±1.5 步长、±5 的 ln 范围），安全上限由先验和第 6 节的资格/拒绝规则表达，不用截断掩盖。只有舌下时 A、B、B2、C、D 数学上相同（实验结果逐位相同，是测试之一）。

**与 P1-A 的兼容性**（`p2/model-selection.md` 第 3 条）：P1-A 的幅度语义是“旧 E2_SL 人口曲线（Doll 1 mg，峰 144 pg/mL）的乘数，先验 sd 0.455”；M2 是“Price 条件情景曲线（1 mg 约 459 pg/mL）的乘数”。两者数值中心相差 3 倍以上，**不能直接复用旧先验或旧冻结参数**。算法框架（MAP/Laplace/资格门控/因果截止）可以复用；参数语义必须新开版本（见第 12 节）。

## 3. 可辨识性（`results/sl-cal-01-identifiability.json`，每格 300 次时点抽样）

混合途径、两个系数的 Gauss–Newton 信息矩阵（σ=0.2937）：

| 方案/采样 | 化验次数 | 秩亏比例 | 平坦先验后验相关 | 独立两系数可接受比例（先验 sd 0.9） |
|---|---|---|---|---|
| q12 + 口服 · 谷值 | 1 / 3 / 5 | 1.00 / 0.05 / 0 | — / −0.9997 / −0.9996 | 0 |
| q12 + 口服 · 峰值 | 1 / 3 / 5 | 1.00 / 0.003 / 0 | — / −0.975 / −0.962 | 0 |
| q12 + 口服 · 随机 | 2 / 3 / 5 | 0.007 / 0 / 0 | −0.88 / −0.78 / −0.71 | 0.36 / 0.60 / 0.81 |
| q24 + 凝胶 · 随机 | 2 / 3 / 5 | 0.02 / 0 / 0 | −0.75 / −0.62 / −0.51 | 0.27 / 0.44 / 0.71 |

“可接受”= 两个系数各自的信息增益 ≥0.5 且后验相关绝对值 ≤0.8。读法：
- **谷值**化验几乎只含非舌下信息（舌下 12 小时后只剩尾部：M2 单剂增量降到峰值的 1% 要 13.7 小时）；**峰值**化验几乎只含舌下信息。只有两类都有（随机时点）才可能分开，而且即使分开，相关仍在 −0.5 到 −0.8。
- 只有舌下时背景与舌下系数的混淆：谷值设计下（先验 sd 0.9）背景已知时信息增益 0.37–0.74，背景不确定（sd 12 pg/mL）降到 0.18–0.24；峰值设计几乎不受背景影响（0.89–0.98）。**2 mg q24 的纯谷值设计几乎没有信息（增益 <0.04）。**
- 因此：**分不开时收缩为一个共同系数（C），或用部分合并先验（B2）**。B 独立先验在峰值/谷值设计里非舌下或舌下系数的误差达 0.5–0.6，不稳定（表 4.2）。

| 只有舌下 · 峰值附近 | 1 / 5 | 0.28 / 0.29 | 0.10 / 0.04 | = A | = A | = A | = A |
| 只有舌下 · 随机 | 1 / 5 | 0.27 / 0.26 | 0.15 / 0.08 | = A | = A | = A | = A |
| 混合 · 谷值 | 1 / 5 | 0.38 / 0.39 | 0.38 / 0.32 | 0.24 / 0.13 | 0.21 / 0.10 | 0.22 / 0.11 | 0.21 / 0.12 |
| 混合 · 峰值附近 | 1 / 5 | 0.40 / 0.41 | 0.36 / 0.32 | 0.31 / 0.24 | 0.23 / 0.16 | 0.22 / 0.17 | 0.23 / 0.17 |
| 混合 · 随机 | 1 / 5 | 0.38 / 0.40 | 0.37 / 0.31 | 0.24 / 0.12 | 0.20 / 0.11 | 0.21 / 0.12 | 0.20 / 0.11 |

要点：
- **谷值化验对只有舌下的用户几乎没用**（0.26→0.21–0.25，信息增益 0.07–0.21）；信息增益规则应拒绝。
- A 在混合途径下基本无效（非舌下部分没校，误差 0.32–0.38），**不推荐**。
- B2、C、D 在混合途径下几乎并列；差异 ≤0.012 的 ln 比，小于合成噪声。

### 4.2 真值系数相同 vs 不同（混合，policy=all，曲线误差 / 舌下系数误差）
| 真值 | 未校准 | A | B | B2 | C | D |
|---|---|---|---|---|---|---|
| 两系数相同 | 0.434 / 0.58 | 0.354 / 0.23 | 0.205 / 0.30 | **0.125 / 0.18** | **0.123 / 0.15** | 0.119 / 0.21 |
| 两系数不同 | 0.360 / 0.57 | 0.311 / 0.37 | 0.200 / 0.35 | **0.185 / 0.40** | 0.197 / 0.44 | 0.192 / 0.42 |

共同系数在“两途径个体差异不同”时仍把曲线误差从 0.36 降到 0.20，但**舌下系数本身的恢复误差高达 0.44**（共同系数吃掉了两种途径的差异）。适用：只要整体曲线；不适用：想从系数解读“舌下吸收多/少”。B2 在两种真值下都不比 C 差，在“不同”时略好。

### 4.3 峰值附近化验：排除还是降权（基线 + 记录时间误差 30 分钟）
| 采样 | 策略 | 只有舌下·A（曲线误差 / 拒绝率） | 混合·B2（曲线误差，common / distinct；各采样方式合并） |
|---|---|---|---|
| 峰值附近 | 全部使用 | 0.104 / 0% | 0.211 / 0.237 |
| 峰值附近 | delta 降权 | **0.100** / 0% | **0.179** / 0.211 |
| 峰值附近 | 排除 2.5 小时内 | 0.284（回到未校准）/ **87%** | 0.219 / **0.198** |
| 随机 | 全部 / delta / 排除 | 0.152 / **0.146** / 0.161 | — |
| 谷值 | 全部 / delta / 排除 | 0.249 / 0.214 / 0.213 | — |

- 记录时间准确（基线）时“全部使用”最好，delta 只多 0.001–0.012；
- **有 30 分钟记录误差时 delta 不劣于“全部使用”**（上表所有格）；“排除”在混合途径且两系数不同时略好（0.198 对 0.211，差别在合成噪声量级），但它把峰值设计的只有舌下用户整体拒绝（87%），丢掉信息最多的化验；
- delta 法：`σ_eff² = σ² + (σ_t · d ln μ/dt)²`，`σ_t` 假设 15 分钟（设计假设），导数用人口曲线。
- LOO（基线，N≥2）：全部使用最好（0.306）、delta 0.317、排除 2.5h 0.340（只有舌下）；混合：B2 的全部/ delta/ 排除为 0.311 / 0.314 / 0.335。LOO 只在基线扫描中计算，其“目标”是带噪声的原观测，不是真值。
- 原因：排除丢掉信息最多的化验；降权既保留信息又承认时间不确定。

## 5. 已发表数据的条件性诊断（`results/sl-cal-01-external-diagnostic.json`；不是验证）

只用仓库 `sublingual-literature-validation.json` 里已有的汇总统计，不复制原文、图表或个体数据。对每个汇总，计算让 M2 总量等于该汇总所需的单一系数 `g=(观测−B)/(剂量·A·response(t))`（**假设剂量成比例，这本身未验证**；“fold over basal”用 B=24 换算）：

| 来源（仓库分组） | 剂量 / 时点 / 检测 | 所需 g |
|---|---|---|
| Doll 2022（A_fitting，旧模型已用） | 1 mg · 1 h · LC-MS/MS | 0.28 |
| Pines 1998（B_external） | 4 mg · 1 h · 未知 | 1.00 |
| Yaish 2023（B_external） | 0.5 mg · 1.5 h · 免疫化学发光 | 3.73 |
| Burnier 1981（B_external） | 0.5 mg · 1 h · 未知 | 2.76 |

ln g 标准差：四组 1.18，三个外部组 0.69。**研究间异质性（人群、检测方法、基线处理、剂量依赖都不同）已经跨越任务书假设的 0.3×–3× 范围**，P1-A 的 0.455 只覆盖其 0.39–0.66。这是对“需要个体校准”和“先验要宽”的支持，不是说任何个人落在该范围内，也不能当作校准有效的证据。这四个汇总来自不同检测方法，系数分歧里有多少来自免疫法偏差无法分离。

| E5 | 至少 1 次可用化验 | 否 → 拒绝校准 | — | `NO_USABLE_LAB` |
| E6 | 舌下系数的信息增益 ≥0.5（`1−后验方差/先验方差`） | 否 → 拒绝校准，曲线仍显示未校准 | 谷值设计增益仅 0.07–0.21，校准不比不校准好 | `INSUFFICIENT_INFORMATION` |
| E7 | 混合途径：只在“两系数可分离”（信息增益≥0.5 且 |相关|≤0.8）时才输出分系数，否则只输出共同系数 | 3 节 | 界面说明“按整体校准” |
| E8 | 单位与检测方法保留原值（pmol/L、pg/mL；LC-MS/MS/免疫法/未知） | 未知也可用，但需标注 | 检测偏差无法与幅度分离 | 校准卡显示“检测方法未知”提示 |

用户可见原因文字的草案（zh、en）已写在 `eligibility_rules.REASON_TEXT`：描述数据，不责怪化验、不给剂量建议；fr 与 zh-Hant 在 SL-CAL-02 按四语规则补齐。

**化验数量不足**：没有“最少 N 次”的硬数字，只有信息增益规则——1 次峰值化验（增益 0.69）可校准、1 次谷值化验（0.07）不可；随机时点至少需 2 次（0.60，1 次仅 0.33）。这比“≥3 次”更能区分真实情形。

## 8. E. 产品层面（只写设计，不实现）

- **UI-12 的“有舌下记录时暂不能校准”**：SL-CAL-02 落地后，校准开关在满足 E1–E6 且信息增益通过时可用；不满足时开关保持“暂不能用”，卡片显示具体的 `REASON_TEXT`（例如“没有记录到分钟的抽血时间”）。没有舌下记录的用户行为不变（Legacy 校准继续）。
- **校准后估算卡和曲线**：估算卡加“已按化验校准”标签 + “使用了 n 次化验”；混合途径写“整体校准”（共同系数），可分离时才写分系数。化验圆点保持 UI-12 的画法。曲线仍以合计一条线显示。
- **不确定性表达（不用区间带，交负责人决定）**：区间不可靠（4.4）。候选表达：(a) **留一化验一致性**：“用其余 n−1 次化验预测这一次，相差 x%（中位）”，在合成研究里 LOO 是最稳定的诚实指标；(b) **校准档位**：“信息充分 / 信息有限（仅谷值）”，直接来自信息增益；(c) 一句话的“校准系数 1.4（随记录增加会更稳）”。三者都不是概率区间，都不暗示精度。建议先上 (a)+(b)。
- **PDF、就诊资料包、化验快照**：§67 D-2 继续有效，本阶段不改导出。若实施时需要让校准结果进入导出（新快照写入合计），列为**单独待决定事项**，需新的 `calculator_version` 与旧快照兼容测试。
- **备份、Room schema、旧快照**（只写方案）：校准系数现在不持久化（实时由化验+记录算出）；SL-CAL-02 应保持“不持久化”以避免 schema 变化。若需要保存“检测方法”（E8），那是一个 Room 迁移，**必须另行请示**；可先不加，用“检测方法未知”提示。新算法应使用新的 `algorithm_version` / `calculator_version=3`，旧 1/2 快照继续按原样只读；备份格式不变。

## 9. 推荐方案及理由

**SL-CAL-02 起点：方案 C（整体共同系数）+ delta 降权 + 信息增益拒绝 + 宽先验（sd≈0.9）。**
1. 与负责人的决定一致（对合计整体校准，化验测的就是总 E2）。
2. 一维问题，参数少，Laplace 不确定性稳定，计算成本与 P1-A 相同。
3. 在混合途径里精度与更复杂的 B2/D 无实质差别，不会在峰值/谷值设计里崩（B 会）。
4. 缺点已写明：不能解读单一途径的吸收；两途径差异大时系数偏向某一方（4.2）。
5. B2 作为升级路径：化验多且时点分散时可把共同系数拆开，先验收缩保证不会比 C 差；是否实施由负责人在 SL-CAL-02 决定。
6. D（复用 P1-A 框架）多一个非舌下速率参数，精度无增益，且语义需新开版本，**不推荐**，除非希望最大限度复用生产代码。
7. A（只校舌下）仅适用于“只有舌下”用户，这时它就等于 C。

## 10. 风险与仍未解决的问题

1. **外部临床准确性未确立。** 合成验证只证明数学可行，不证明 M2 形状对真人成立；形状偏离扫描中误差大幅上升（只有舌下 0.67）。
2. **背景基线**：真实基线偏离假设 14–16 pg/mL 时，只有舌下的误差下限就有 0.30–0.39。需决定是否用用户确认过的治疗前化验（P1-B 已有基线资格）估计 B，或明确“基线是假设”并提示。
3. **检测方法偏差**无法与幅度分离；校准的是“这家检测上的比例”。
4. **采样时间记录质量**：App 里化验时间是否总是精确到分钟，需要产品核查（E1 可能让大量历史化验不可用）。
5. **剂量比例性、含服时长、吸收变异**未建模；4 mg 与 0.5 mg 的外部汇总换算在假设成比例下进行。
6. 合成研究的限制：只有一种形状偏离候选（p2x-22）、只有两种非舌下曲线、真值系数用对数均匀分布、检测噪声为对数正态；未按真值幅度分层报告；LOO 只在基线扫描里算；用药依从性（漏服/延迟）未模拟。
7. 单次抽血 + 无历史完整性的用户会被 P1-B 拒绝，这与本研究无关，但会限制实际覆盖面。
