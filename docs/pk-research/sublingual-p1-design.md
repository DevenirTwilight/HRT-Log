# 舌下 E2 P1：后续改进设计与验收建议

2026-10-09。P1-A已获§46授权并实际编码（验收见下）；P1-B及人口模型研究尚未实施，后续须单独授权。依据 [P0科学审查](sublingual-v2.md)、[独立对照](results/sublingual-p0-report.md)及[校准缺陷](sublingual-calibration-audit.md)。目标是可复现、可辨识和可独立验证，不是使2mg/46min等于914或277。更复杂的结构不能自动代表更准确。

## P1-A 当前实现（2026-10-09，REQUIREMENTS §46）

采用方案B：完整舌下E2事件（快速黏膜核和吞咽慢项）固定速率，仅共享暴露幅度。纯舌下拟合一维logAmplitude，logRate及其协方差维固定0；混合给药仍拟合共同幅度及仅作用非舌下事件的模型速率。不能将它解释为人体清除率。方案A数学稳定但缺可信舌下速率先验，保留测试，不投产。人口参数JSON、文献版本/来源未改，2mg/46min人口值仍278.8647796；旧P0结果保持只读。

运行时校准算法版本2；个人拟合值不持久化，不复用旧u/v。新冻结估算沿既有calculator_version写2，JSON envelope version仍1，旧1/新2均可读取，无字段形状/Schema/备份格式迁移。旧快照/PDF不自动重算。新区间只覆盖假定参数不确定性，不含全部测量误差、研究异质性或结构误差，不是临床可信区间。实际验收、数值与命令见[P1-A记录](sublingual-p1a-verification.md)及[新报告](results/sublingual-p1a-report.md)。

**下一轮顺序**：P1-B历史覆盖完整性门控（待实施）；随后分别处理因果插值/摘要与离群记录一致性。新舌下人口模型P2仍为研究规划，外部人体准确性尚未确立。P1-A不解决上述已确认缺陷，原反例保留；应用四语增加准确警告。

## P1-B：先处理历史覆盖，独立于人口模型研究

建议下一轮最小单元：**历史覆盖完整性门控**。只处理Calculator/LabFit的数据纳入资格，人口E2_SL参数及全部途径公式不变；不重算已保存LabEstimate/Visit Pack，不删旧化验或用药，尽量无Schema变更。

规格：先定义每条化验附近真实E2历史是否覆盖且上下文完整。超过180天的化验或用药缺快照不能被默认为“治疗前”；首条当前窗口事件不是治疗开始证明。完整性不明时不以该结果估计内源基线/个体参数，保留原始化验和明确原因。若按化验扩展只读历史加载，需限定资源并保留冻结途径/实际服药时刻；仅扩大天数不能处理未知导入史。真正基线需要显式已知治疗前语义，否则保持未知，不能把未知改为0的已知事实。

验收：P0的201天用药/200天化验和12h缺快照反例不产生假基线；覆盖充分的现有合成拟合不变；跳过/删除/导入未知上下文、采样时刻、完整老治疗记录分别测试；无DB/备份格式变化、不可变快照字节不变。可一个提交回滚。历史缺口是警告还是禁用校准、可靠基线是否需要独立确认，请在实施前决定。

其后分别执行，不能混成一次大重写：

1. 因果边界与摘要：当前时刻精确求值或加入必要网格点，禁止跨化验边界借用后段；摘要按当前时刻筛选。任意过去t修改未来化验后中心/区间/摘要保持一致。回顾式允许后来化验解释过去，但不改冻结资料。
2. P1-A稳定性已独立实施B；不再作为待实施项。方案A仅保留独立数学测试。
3. 全离群计数/标识：真正未参与的集合与计数一致；自动警告、用户明确排除及全离群时行为需独立产品决定。

速率稳定化候选不是本轮实现：令B=A(ka−λ0)，h(t;r)=B[exp(−λ0rt)−exp(−kat)]/(ka−λ0r)，交点取极限B·t·exp(−kat)。r=1精确保存原快核。它修复“固定巨大差指数振幅”问题，但改变r的含义、分布和口服慢项联动，需重新审查校准先验；不能把计算稳定当生理正确。另一策略固定SL速率r=1、只估幅度，可降低过拟合，却不能从单点解释尾部形状。方案B已由§46授权并实施，A未投产。

下方A/B是**P2人口模型**策略，不是P1-A的“归一化/仅幅度”修复候选。

## P2人口策略 A：改进经验拟合（未实施）

保留少量可辨识有效参数：幅度、快速峰时/形状，慢尾只有独立数据支持才添加。可以使用稳定gamma核或稳定Bateman核；把幅度与速率解耦，避免近相等指数差。不要将快项幅度和慢项系数直接命名为绝对生物吸收比例。

先核实Doll全文的基线、完整均值/散布和绝对AUC；只用A拟合数据估参数。B的Pines/Yaish等保留外部，不同时拿来优化和验收。参数总数建议2–3个有效量，不能凭三个摘要目标自由估计更多量。新的8–24h尾部若缺证据，保留多个受约束情景/外推区间而不是硬选一条“正确”尾。

## P2人口策略 B：快速黏膜 + 吞咽胃肠双途径（未实施）

一个可研究的最小结构如下（剂量为mg，时间h）：

```text
M(0)=f_m D,       G(0)=(1−f_m) D,       X(0)=0
 dM/dt = −k_am M
 dG/dt = −k_ag G
 dX/dt = F_m k_am M + F_g k_ag G − k_e X
 C(t)  = C_base(t) + 10^6 X(t)/V_L   [pg/mL]
```

解析单剂核：`C_ex(t)=10^6 D/V_L · [f_m F_m q(t;k_am,k_e)+(1−f_m)F_g q(t;k_ag,k_e)]`，q为一阶Bateman核，速率相等用连续极限。多剂只在参数/基线/吸收线性且时间不变条件下按实际时刻叠加；药物相互作用、饱和吸收、制剂/吞咽行为变化不满足时不能默默线性外推。

参数含义：f_m为进入黏膜途径的剂量份额，不等于已进入全身的比例；F_m/F_g为各途径有效生物利用度；k_am/k_ag为有效吸收率；k_e为共同分布/消除的简化有效率；V_L为有效分布容积，是否按体重标化须独立人体依据。任何参数都不能直接沿用Featherline默认值并称其已验证。

数据来源与可辨识性：Doll仅1mg/0–8h群体目标，不能分离f_m、F_m、F_g、V，也不能可靠区分慢吸收与终末消除（flip-flop）。主要可识别的是`f_m F_m/V`和`(1−f_m)F_g/V`这类乘积及有实际时间覆盖的形状。若只有Cmax/Tmax/代理AUC，连这些乘积也不稳。不得用0.24%锁定f_m。可固定/约束某些有效乘积、对合理尾部情景边际化，或完全不估计未被数据支持的参数；固定值也须来源与敏感性说明。双途径自由参数约5–7个，远超现有稀疏统计提供的信息。

与口服模型关系：吞咽部分可研究共享胃肠核，但现有口服模型的约14h表观半衰期包含制剂、分布、首过/代谢与输入形状，不能直接当纯静脉清除率；也不能用SL约0.69h快速下降当共同清除率。可比较“经验口服核+有效黏膜核”和“共享消除ODE”，先验证兼容性，研究阶段不改变已发布口服途径。

基线：无可靠治疗前信息则未知；Yaish治疗谷含残余，不当作纯内源基线。条件群体谷校正仅敏感性展示，不是每人的基线估计。研究级和个体级基线分开；不同检测方法偏差、内源波动、共药及其他途径分开记录，不能统归吸收份额。

个体差异与研究异质性：将制剂、实际溶解/吞咽、剂量、检测法、研究人群、既往给药、基线处理列为层级/协变量候选。有足够个体重复资料再估随机效应相关性；目前不从一篇群体SD推个体轨迹。旧免疫法与LC-MS/MS不无条件合并，不以简单固定倍数“校正”。

## P2两种人口策略的选择门槛

| 维度 | A 经验核 | B 双途径 |
| --- | --- | --- |
| 有效自由量 | 约2–3，尾项另需证据 | 约5–7，需约束到数据实际支持的量 |
| 所需数据 | 同剂量早期密集点、基线、绝对AUC、独立晚期点 | 还需口服对照、操作/制剂信息、晚期采样，最好个体交叉数据 |
| 解释边界 | 不宣称吸收份额/真实清除 | 生理解释直观但份额/F/V不可独立识别 |
| 外部表现 | 本轮没有新A候选，尚无表现结论 | 本轮没有新B候选，尚无表现结论 |
| 过拟合风险 | 较少参数仍可能结构偏差 | 数据不足时更大；复杂不自动更准 |

P0仅对现有HRT/Featherline做独立测试，gamma族只是结构不可辨识压力演示，不能算已验证第三模型。暂不选择A或B投产。

## 科学验收与可回滚交付

分步实施：先取得可靠原文/数据并冻结训练与外部集合；后独立试验分支内测试工具拟合A/B（沿现有开发分支逻辑提交，不新增长期分支）；再评估，不先改UI。保留输入版本、来源版本、代码版本、参数、命令和输出。不得把从图估读当作者原始数据；如以后数字化需单独标记方法/误差/许可。

独立外部验证至少两项可核对研究，按真实报道指标、剂量/采样/方法分别报告绝对误差、相对误差、AUC/峰时（只有报道才比）。不以简单±1SD视为合格个体预测；SD/SE类型必须核实，不完整输入不能当失败或通过的同质对照。接受阈值必须在看验证集/拟合前制定，依据研究误差而非希望贴近914。进行留研究外验证和方法分层敏感性；如果不足，交付结论可以是“不应替换”。

数值验收：近等速率连续、非负有限、积分与解析一致；1/2/4mg区分实测范围与外推；6/12/24h间隔、长期叠加、停药、跳过、UTC/DST、因果及历史覆盖；全部原PK测试和冻结/备份回归。含服2/5/10/15min没有分钟与份额定量数据时不新增“已验证”映射。

生产采用需要另次授权：新增独立算法/参数/来源版本标识，保留旧核可回放；是否版本化可执行历史bundle/体重与校准快照需单独兼容设计。不得重算旧化验/资料包或静默改历史显示。单一模块可回滚，先测试再开生产，不发布未经验证的“更准确”开关；任何Schema变化另案迁移及测试。
