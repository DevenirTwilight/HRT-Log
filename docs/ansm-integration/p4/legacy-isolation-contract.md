# 旧库存路径隔离合同

2026-10-16，负责人联合生产授权 REQUIREMENTS §102。当前唯一库存/数据层开放 PR 为 #57；无其他开发分支占用本组文件。以下不是正式入口启用证明。

## 要修改的路径

- `NotesDao`：从容器稳定身份及历史 PRESENTATION 快照查询新计量容器；不依赖药物名称、当前产品引用、当前剂量或整数 ID 原始值。曾具有独立包装单位的容器不能因以后取消当前引用而重新降格为旧标量。
- `SupplyLedger.allocate`：旧自动分配仅遍历旧容器，不能把整数刻度当 mg 或片数；已有 measured_operation 的实际记录拒绝走此入口。没有可分配的旧库存继续保留原有未分配剂量，不从新包装猜测换算。
- `SupplyLedger.reverse`：拒绝绕过冻结量与来源证据的旧逆操作；正式修订/删除必须由独立计量逆事务完成。
- `SupplyLedger.setRemaining`：拒绝新计量容器；不得把旧 Double 参数解释成新的物理用量。
- `NotesRepository.replaceContainer` / `discardContainer`：新模式不得通过不含稳定包装确认的旧入口自动关闭、重开或丢弃；明确新包装入口未实现前安全拒绝。
- `NotesRepository.saveMedication`：用户选择调整旧包装容量时排除新计量容器，独立包装规格与来源保持冻结。旧容器调整行为保留。

## 验证

共享合成真实数据库合同先证明现状不足：较早创建的新容器会被旧分配优先使用；旧剩余量入口接受整数刻度；修改药物容量会 resize 新包装。先运行负向测试，再加隔离，原有 SupplyLedger/库存预测/时期稳定性断言不变。

本组保护不等于整个库存接线完成。备份接受仍 OFF；StockForecast、库存页、日历和提醒仍需统一不确定性保护；实际来源确认、记录修订/删除和恢复语义未接好前不能启用新格式。
