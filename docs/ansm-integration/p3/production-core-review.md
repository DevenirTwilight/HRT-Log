## 复核结论与修正

- 保留BigDecimal有界策略：非负、数值≤10^18、scale -18…18，文本输入≤80字符。算术精确，除法不能有限表示或结果超范围时结构化失败，不舍入；零可表示余额，actualUse必须正数。
- 保留量纲、化合物/盐/酯/水合物/SA/FT/ST的不透明身份隔离。无关系不跨质量/体积/次数；关系有方向，不能反推另一方向；不计算吸收量或从载药量推释放率。
- 保留来源与实际包装独立确认。ConversionEvidence.verified是调用方已冻结的事实声明，不是本算法完成的官方核实。正式存储/人工确认必须自行验来源、版本和快照摘要，不得直接把UI任意布尔值当官方认证。
- 生产边界增加身份/来源文本长度及NUL限制；结果仍为原有结构化失败，不抛出数值转换失败给业务层。
- PresentationSnapshot的关系列表改为不可变副本。原原型虽复制调用方列表，但调用方仍可能通过MutableList强转修改已暴露的副本。
- 新增decimalText：仅对经过有界校验的BigDecimal输出规范plain decimal字符串。没有Double入口，不用指数形式持久化，不自动应用地区小数格式。
- 算法版本明确为ansm03-exact-v2。旧v1原型保留，不能把生产边界修改冒充同一算法版本。
