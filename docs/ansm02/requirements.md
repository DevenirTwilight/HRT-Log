# ANSM-02 本轮要求（2026-10-16，任务书摘要）

本文件记录本轮会话的新增要求，不替代原任务书。主线REQUIREMENTS §98的资料/参数边界继续适用。
PR47正在修改共享REQUIREMENTS/HANDOFF及正式字符串，本轮暂存独立目录，后续由集成负责人索引。

- 先核对实际默认分支、PR45/CI/评审、许可1.0与2.0冲突、成分FT/ST差异。
- 02A允许离线目录搜索（商品/成分、重音和大小写兼容）、剂型/规格/途径筛选、只读详情、
  CIS-CIP所属、独立授权/销售/供应状态、来源/日期以及RCP/Notice独立入口。
- 01未合并或数据分发/许可未确认时，只允许明确合成的独立Mock UI和测试，不复制正式目录
  到Android、不接正式药物编辑入口或绑定。面板存在不表示正文核实，不生成医学摘要。
- 正式关联必须可空、可解除、有不可变身份/版本/快照；目录更新不改历史、剂量、途径、计划、
  容器/流水/预测或PK。不能把身份放PK、needs_review、自由文本或偏好侧车。
- 02B的Room/备份修改未获授权，先交独立设计和测试方案。旧Room10/PNBAK1保持。
- 保留快捷手动创建和非法国商品路径；取消保留草稿，重复确认不产生额外药物。
- Material3及既有token，英/法/简/繁，320/411dp，1×/2×，明暗、三档对比度、TalkBack及键盘、
  长名称、未知/归档/加载中/失败/无结果/返回恢复；没有真机证据标NOT_RUN。
- 六项必需CI及原断言不弱化，特别是PeriodStability、Room/PNBAK、库存/VOIDED、锁/伪装、
  No INTERNET、四语和PK守卫；生产持久化测试NOT_IMPLEMENTED，不以Mock冒充成功。
- 不改PK/参数/浓度/PDF、库存算法、历史记录、网络权限/账户/遥测、附件功能、版本/包名/
  签名/Release，不交付APK、不合并PR。只用合成测试数据。
- 最多02A/02B两个PR；当前仅交02A Mock与兼容设计。03需独立单位与包装/容器历史方案及批准。
