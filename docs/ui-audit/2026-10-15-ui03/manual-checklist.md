## 8. 抽屉分组与入口改名（UI-03A）
- [ ] 8.1 打开 TalkBack，打开抽屉，从上往下逐项滑动，朗读顺序应为：
  应用名 → 日历 → 治疗时间线 → “日常记录，标题” → 服药记录 → 身心状态 → “用药管理，标题” → 药物方案 → 库存 → 浓度估算 → “就医资料，标题” → 医疗档案 → 复诊 → 化验 → 设置 → 关于。
  - 日历和治疗时间线之前没有任何标题；
  - 3 个组标题都被读作“标题”；
  - “就医资料”与紧随其后的“医疗档案”听起来不重复。
  结果：NOT_RUN
- [ ] 8.2 依次点开“服药记录”“治疗时间线”“药物方案”“浓度估算”，顶栏标题与抽屉中的名字完全一致；在中文、繁体中文、English、Français 各看一遍。结果：NOT_RUN
- [ ] 8.3 用 320dp 宽的小屏或分屏，把系统字体和显示大小都调到最大，打开抽屉：可以滚动到“关于”并点开。结果：NOT_RUN
