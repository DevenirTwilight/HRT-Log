# Visit Pack 合成验证步骤

2026-10-07，schema6/build11，仅full。只用合成数据，不需要上传真实健康记录。

1. 升级前导出加密备份，用原正式签名覆盖安装。原有预约全部保留，均显示“未确认是否已就诊”；没有问题和资料包记录。
2. 侧边栏进入“复诊”：分“即将到来/已过去”。日历当天的预约卡片、时间线中的预约条目点击都进入同一详情页；Back 回到列表。
3. 编辑预约（时间、医生、地点、备注、提醒）后，已确认状态不变；新建预约一定是未确认。点“确认已就诊”记录确认时间，可撤销。时间过去本身不算确认。
4. 问题清单：新增、修改、勾选已问、记回答、上移/下移、删除；空白问题不能保存。
5. 生成资料包：有更早的已确认就诊时，区间从那天开始并说明来源；没有时红字提示“未找到”，暂按最近90天，需自己核对。结束日不能晚于今天。包装来源/批号、里程碑默认不勾选；全部取消时不能导出。勾选“事实摘要”时显示与PDF相同的预览。
6. PDF只出现勾选的部分；事实摘要只有计数：已服（迟服/导入）、确认漏服、跳过、未确认分列，“未确认不计为漏服”。方案版本按当时冻结的快照描述，改了药名后旧版本仍显示旧名。没有百分比、评分、正常/异常、趋势或剂量建议；不含浓度曲线。
7. 导出成功后详情页出现生成记录（时间、区间、校验码前12位），与PDF页首校验码一致。取消文件选择不产生记录。再次生成是新记录，旧记录不可修改。
8. 删除预约需确认，同时删除问题和生成记录；已保存的PDF文件不受影响。
9. 加密备份往返保留确认状态、问题和生成记录；schema1–5旧备份可恢复（预约未确认、无问题/记录）。

自动覆盖：VisitPackDataTest（确认只能显式设置、问题排序/校验、记录不可改与级联删除、备份往返/旧schema/恶意字段回滚）、VisitPackTest（默认区间、事实按实际/计划时间归属与边界、未确认分开、快照药名、校验码只覆盖勾选部分、对话框默认勾选与预览及合成截图）、TranslationsTest；原生 MigrationBaselineTest 含 5→6 及 1/3/4→6，WellbeingAndroidTest 原生PDF分页加入资料包。

OEM、大字体、TalkBack 与用户真实覆盖安装仍需在设备上确认。
