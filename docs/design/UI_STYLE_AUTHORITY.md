# HRT Log UI 设计权威与继承规则

生效：2026-10-28，负责人 ANSM-04 / ANSM-06 任务明确授权。适用于整个项目，包括后续开发者与代理。

## 优先级

1. 负责人已经确认的最新设计决定。
2. 已经实际验收、并有对照证据证明表现更好的正式应用设计。
3. Claude 原始样图与历史设计审查。
4. 其他外部视觉参考。

Claude 样图是重要基线，不是永久上限。正式应用在可用性、视觉一致性、信息表达、无障碍、响应式布局和用户认可方面，经对照验证优于旧样图时，该正式界面成为后续设计的新基线。不得为了机械复刻静态图而破坏更优秀的正式界面；也不得无证据宣称任意新设计更优。静态图不能代替真实交互、数据语义与安全约束；样图中的占位医疗数据不是产品事实。

## 必须继承的语言

Material 3 Expressive + Quiet Healthcare Design：温和、安静、专业、可信赖；低饱和背景、深青绿与柔和健康主题强调色；**负责人 2026-10-30 决定：青绿是主色，蓝、紫、玫红为小面积点缀色（图标块、小标签、日期方块、时间线小圆点；不用于按钮、大卡、选中项、曲线），底色为中性暖白**（见 [UI-13 样图与记录](ui13-accent-colors-2026-10-30/README.md)）；清楚的信息层次、舒适留白、一致的圆角/形状/间距/阴影；明确主次操作，Material 3 原生交互与适度动效。继承现有 `NotesTheme`、`Corners`、语义色、`GroupedItem`、按钮及响应式组件，不为药品中心或其他业务另造不兼容体系。不因“Expressive”名称擅自升级依赖或采用实验性 API。

明暗主题、动态颜色、高对比、减少动态、四语、320/411dp 与大字号都是设计输入。错误色只用于真实错误；不能仅凭颜色表达来源或状态。主要操作可发现，返回行为可预期，触摸目标和 TalkBack 文本有意义。不得因增加字段退化为一串默认 AlertDialog、杂乱按钮或深层弹窗；优先沿用已验收的页面结构、分组与展开行。

## 设计证据与评审

修改前先查看当前正式页面及下列样图/审查，不以记忆或单张截图重建 UI。提交真实 before/after（同一合成数据、相同语言/尺寸/字号/主题，注明精确源码与生成方式），列出代表性用户任务的点击路径、主次操作、返回与取消行为，以及新增/保留的状态。对照至少覆盖小屏/大字号、明暗与四语；验证自动语义、触摸区域、文本溢出，人工 TalkBack/真机未执行时标记 NOT_RUN。

说明改进在哪些维度成立、哪些保留取舍，引用负责人反馈或验收记录。只有完成对照与实际验收，才能将新实现提升为基线；不把 AI 自评、示意图或单独编译成功当作用户认可。保留历史图与审查，记录后继基线的 PR/SHA，不改写过去的验收事实。
