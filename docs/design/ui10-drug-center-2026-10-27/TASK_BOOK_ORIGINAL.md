## 0. 目标与边界

把“药品资料中心”和“商品资料关联”两个页面改成 UI-06/UI-07 的视觉体系：大圆角主卡、分组列表、胶囊按钮、纯线条图标、语义色。同时按负责人的决定：

1. **左上角“取消”改为“返回”**：两个页面都用 ← 返回图标按钮。
2. **药品资料中心删除“药物”和“库存”两个按钮**：用户返回后从抽屉进入，不需要替代入口。

**本任务只改展示和导航，不改业务**：
- 不改 BDPM 目录数据、搜索算法和结果排序；
- 不改关联、解除关联、自行录入的逻辑，也不改确认对话框的触发条件；
- 不改 Room schema 和备份；
- 关联操作仍然不得改变剂量、方案或库存，现有证明这一点的测试全部保留。

## 2. 实现

### A. 共用：返回按钮

- 两个页面的顶栏统一为：48dp 图标按钮（← 箭头，纯线条），后面跟标题。
- 无障碍名称为“返回”。新增四语字符串 `nav_back`：en “Back”、zh-CN “返回”、zh-TW “返回”、fr “Retour”。不要复用 `cancel`。
- 行为与原来的“取消”完全相同：关闭当前页，回到进入前的位置。系统返回键的行为也不变。
- 保留现有 testTag（`drug-center-close`、`reference-close`），避免无意义的测试改动。
- `RecordedReferenceDialog`（`record-reference-close`）如果也用“取消”作为页面级关闭，一并改成“返回”。

### B. 药品资料中心（`DrugReferenceCenterScreen.kt`）

从上到下：

1. **主卡**：`successContainer`（或现有对应令牌）底色，大圆角（UI-07 的最大圆角级）。
   - 卡内依次为：地区标签胶囊“法国 · ANSM / BDPM 参考”（地点图标）；
   - 标题“查找商品资料”（emphasized 字体）；
   - 现有范围说明（`drug_center_scope`，文字可以精简，但必须保留“只读、不提供用药建议、不改变剂量和库存”的意思）；
   - 白色胶囊搜索入口（≥56dp，搜索图标），点击行为等同原来的“搜索 BDPM 与已保存资料”按钮，保留 tag `drug-center-catalogue`。
2. **删除**“药物”（`drug-center-plans`）和“库存”（`drug-center-stock`）按钮，以及 `onPlans`、`onStock` 参数和调用方传参（`MedicationsScreen.kt` 中的 `onStock`）。
3. **我的药物**：改用 GroupedList（UI-07 的 24/6 圆角，3dp 间距）。每行包括：
   - 左侧 40dp 浅色圆角方块，里面放药丸线条图标；
   - 药物名称；
   - 一个关联状态标签，三种状态：
     | 状态 | 文字 | 颜色 |
     |---|---|---|
     | 已关联官方资料 | 已关联 BDPM 官方资料 | success |
     | 已关联用户录入资料 | 已关联我录入的资料 | attention |
     | 未关联 | 未关联产品来源 | 中性灰 |
   - 已归档的药物额外加“已归档”中性标签，整行降低不透明度，但文字对比度仍须 ≥ 4.5:1（降低的是底色或图标，不能把文字压到不合格）；
   - 右侧箭头。
   - 列表下方一行小字：“关联资料只记录这条药物对应哪种商品，不改变剂量。”
   - 关联状态**只读取现有数据**，不新增查询字段。如果现有模型无法区分“官方 / 用户录入”，就在报告中写明，用现有能区分的程度显示，不要为此改 schema。
   - 保留 tag `drug-center-medication:<id>`。
4. **资料来源**：两行分组列表——“BDPM 官方目录”（盾牌图标，副标题为离线可用和数据版本，标签“官方”，success）、“我录入的资料”（铅笔图标，副标题为条数和“未经核实”，标签“未核实”，attention）。数据版本和条数来自现有来源；取不到时只显示固定说明，不要编造。
5. **了解这些资料**：原来的 `DrugCenterSection`（产品身份与来源、包装信息）改为可展开的分组行，默认收起，展开时箭头旋转并显示原说明文字。动效遵守 UI-07 的弹簧动效和“减少动态效果”设置。展开状态在旋转屏幕或进程重建后保持（参照 `CenterStateRestorationTest`）。
6. **尚未开放的模块**：surface 底色的分组行，左侧放灰色线条图标，右侧加“尚未开放”描边标签；行不可点击，TalkBack 读作“名称，尚未开放”。下方一行小字说明这些模块开放前不显示内容。五个模块的文字不变。

### C. 商品资料关联（`MedicationReferenceDialog.kt`、`BdpmCataloguePanel.kt`）

1. **顶栏**：返回按钮、标题“商品资料关联”，标题下面用小字副标题显示当前药物名称（数据已经在页面里）。
2. **边界说明卡**：surface 底色、24dp 圆角，左侧信息图标。显示现有 `ref2_boundary` 的含义，其中“不会改变剂量、方案或库存”一句加粗。
3. **当前关联卡**（仅在已有关联时显示）：
   - 白色、28dp 圆角，顶部是来源标签（BDPM 官方 / 我录入 · 未核实）；如果指定了包装，再加一个“已指定包装”的中性标签。
   - 下面依次是名称、成分 · 剂型 · 途径，以及 CIS 和包装（含 CIP13）的标签值对齐网格。编号用等宽数字。
   - 底部两个按钮：“查看资料”（tonal 胶囊）和“解除关联”（文字按钮）。“解除关联”保留原有的确认对话框。
4. **分段切换**：原来的两个 TextButton 标签页改为胶囊分段控件（与 UI-08 身心状态页同款）：“法国 HRT 药品目录” / “我录入的资料”。设置 `role=tab` 和选中状态语义。
5. **目录标签页**：
   - 搜索框改为胶囊形，右侧是主色胶囊按钮“离线搜索”；
   - 下方状态行显示结果数、目录名、数据版本；
   - 结果改用 GroupedList，每行包括名称、成分 · 剂型 · 途径、“BDPM 官方”标签和 CIS；
   - 点击后展开，显示包装单选卡片（选中时用主色描边和浅主色底）、文字按钮“仅选择产品，不指定包装”，以及主按钮“关联此资料”；
   - 一次只展开一项。
   - 原来的预览对话框“只读商品参考资料 → 关联此资料”和确认对话框“确认资料变更”的流程**保持不变**，只改触发它们的外观。如果展开内的“关联此资料”会让流程少一步确认，就保持原流程，并在报告中写明。
6. **我录入的资料标签页**：
   - 原来的四个过滤输入框：“商品名或成分名”放在胶囊搜索框里，剂型、规格、途径三个改为可点开的筛选胶囊（点开后仍是原来的输入，过滤逻辑不变）；
   - 结果卡片改用 GroupedList，标签为“我录入 · 未核实”（attention），并显示录入日期。
7. **底部**：描边胶囊按钮“＋ 自行录入商品资料”，下方一行小字：“找不到时可以手动录入，资料会标为‘未核实’。”

### D. 颜色与无障碍

- 只使用 UI-06 语义令牌。官方用 success，用户录入或未核实用 attention，尚未开放和未关联用中性色。**不使用红色**。
- 标签文字在浅色和深色模式下对比度都要 ≥ 4.5:1；有底色的标签一律用 onContainer 色（沿用 UI-07b 的规则）。
- 所有可点击元素 ≥ 48dp。
- 标签不能只靠颜色区分：每个标签都有文字。
- 四语长文本（尤其 fr）在 320dp 宽、字号 2.0 下不截断关键信息，标签允许换行。
