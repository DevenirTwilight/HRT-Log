## 负责人的决定

1. 两个页面左上角统一为 **← 返回**（图标按钮，无障碍名称“返回”），不再显示“取消”。
2. 药品资料中心**删除“药物”和“库存”两个按钮**；用户返回后从抽屉进入用药管理和库存。
3. 视觉风格沿用 UI-06 语义色、UI-07 Expressive 表现层（分组列表、胶囊按钮、大圆角主卡）和 UI-07b 纯线条图标。

## 样图要点

**药品资料中心**：青绿主卡（地区标签 + 只读说明 + 大号搜索胶囊）→“我的药物”分组列表（每条带关联状态标签：BDPM 官方 / 我录入的资料 / 未关联；已归档降低不透明度）→“资料来源”（官方 / 未核实）→“了解这些资料”可展开说明 →“尚未开放的模块”灰色行 + “尚未开放”描边标签。

**商品资料关联**：返回 + 标题 + 药物名副标题 → 边界说明卡（不改变剂量、方案、库存）→“当前关联”卡（来源标签、名称、成分、CIS、包装、查看资料 / 解除关联）→ 胶囊分段切换（法国 HRT 药品目录 / 我录入的资料）→ 搜索胶囊 + 离线搜索 → 结果分组列表，展开后单选包装、“仅选择产品，不指定包装”、“关联此资料”→ 底部“自行录入商品资料”。
