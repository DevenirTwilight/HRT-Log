## 负责人的决定（2026-10-28）

1. 所有给药途径共用一个界面；同一种分子（E2）的各途径**相加成一条合计曲线**，不分途径显示、不提供“分开显示”开关。
2. 结果放在最前面：估算大数字 + 一行依据（如“舌下与口服相加 · 基于 N 次服药记录”）。
3. 标题“浓度估算”本身已是提醒；页面内只保留**一句**提醒：“估算值，不能代替化验，也不能作为调整剂量的依据。”其余解释全部收进底部“模型与文献”。
4. 时间范围只有 3 天和 7 天，默认 3 天；删除 14 天、60 天。
5. 不显示“点按曲线查看……”和手势提示，点按功能让用户自己发现；点按后在点旁出现浮动读数。
6. 化验结果作为圆点画在曲线上；图底部用短竖线标出每次服药时刻。
7. 化验校准将来对合计整体校准（另案）；在那之前，有舌下记录时校准不可用，只显示“有舌下记录时，暂不能校准。”
8. 不再使用 25%–75%、5%–95% 区间带，以及“完整显示不确定性区间”开关。
