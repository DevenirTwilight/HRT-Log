## 0. 负责人决定（2026-10-28）与对旧决定的取代

负责人在本日明确作出以下决定。它们**取代** §67 D-1 中的对应条款，以及 §65 中关于普通页面显示的对应限制；其余条款不变。

1. **一个界面**：所有给药途径共用同一个浓度估算页面，不再区分“舌下文献情景页”和“其他途径兼容页”。
2. **E2 合计**：同一种分子（E2）的各途径估算**相加成一条合计曲线**和一个合计数字。不分途径显示，不提供“分开显示”开关。
3. **结果在最前面**：页面顶部是估算大数字（此刻的合计值），下面一行依据，例如“舌下与口服相加 · 基于 N 次服药记录”（只有一种途径时写该途径名）。取代 D-1 中“取消醒目的个人当前浓度数字”。
4. **只留一句提醒**：标题“浓度估算”本身已经是提醒。页面内只保留一句：“估算值，不能代替化验，也不能作为调整剂量的依据。”顶部的说明卡、文献情景卡、研究依据链接、图表提示等全部移走，所有来源、适用范围和限制都收进底部“模型与文献”。
5. **化验画在曲线上**：所有途径的化验结果都作为圆点画在合计曲线上。取代 D-1 中“真实化验单独显示，不与 M2 情景曲线叠加”。
6. **时间范围**：只保留 3 天和 7 天，默认 3 天，删除 14 天和 60 天。
7. **不显示操作提示**：删除“双指缩放，拖动平移，点按查看数值”这类提示，以及任何“点按曲线查看……”的提示条，让用户自己发现。
8. **不再使用区间带**：浓度页不再显示 25%–75%、5%–95% 区间带、它们的图例，以及“完整显示不确定性区间”开关和缩放说明。只改显示，不改计算和导出。

   - 没有舌下记录的用户，校准行为与现在完全相同。

## 2. 实现

### A. 合计曲线的计算方式（只在显示层做）

1. **分开算，再相加**：
   - 舌下 E2 部分：沿用现有 M2 结果（`ConcentrationPreview`），数值不变；
   - 其他途径 E2 部分：沿用现有兼容计算（`ConcentrationCalculator.compute`），数值不变；
   - 合计 = 两部分在同一时间点相加。
2. **避免重复计入舌下**：兼容计算的输入里如果包含舌下 E2，就会和 M2 重复计算。做法是在调用方（`NotesViewModel` 等 HISTORY_ONLY 文件）为合计用途**另行**调用一次兼容计算，只传入非舌下 E2 的药物与记录；不改计算器本身。现有给 PDF、化验快照等用的调用保持原样。
3. **基线只计一次**：M2 的 `C = B + A×H` 含背景 B。先查清兼容计算结果是否也含内源或背景基线：
   - 如果含，合计时只保留一份，并写清楚保留的是哪一份；
   - 如果无法在不改锁定文件的前提下分离，就停下报告。
4. **时间网格**：两部分时间网格不同时，在显示层插值到同一网格；点按读数用两部分各自的精确读数相加（M2 用 `valueAt`，兼容用 `evaluateAt`）。
5. **未来部分**：此刻之后用虚线，图例为“预测尾部”。各部分保持现有的未来行为：M2 不虚构未来给药，兼容计算沿用现有计划给药预测。**不新增任何未来给药假设。**
6. **单一途径**：只有一种途径时，合计就等于该途径的结果，数值必须与改动前逐点相同（回归测试见第 3 节）。
7. 其他药物（CPA、螺内酯、孕酮等，`OtherCurvesCard`）不参与 E2 合计，保持现有显示，放在 E2 图表卡之后。

### B. 页面结构（从上到下）

1. **顶栏**：导航按钮 + 标题“浓度估算”。现有的刷新按钮保留。
2. **缺失输入类提示**：例如需要体重、药物缺少信息、暂不支持的途径、没有可估算的药物、没有服药记录。这些现有卡片保留功能，放在估算卡**之后**；没有结果时才放在最前面。
3. **估算卡**（样图顶部的青绿大卡）：
   - 左上标签：多途径写“E2 合计”，单一途径写途径名（如“舌下 E2”）；已按化验校准时再加一个“已按化验校准”标签。
   - 大数字：此刻的合计估算值 + 单位。
   - 依据行：“舌下与口服相加 · 基于 N 次服药记录”，按实际参与的途径动态组合，N 为实际使用的服药记录数（沿用现有 `usedDoses` 等计数，合计时相加）。
   - 一句提醒：新增四语字符串，中文为“估算值，不能代替化验，也不能作为调整剂量的依据。”
   - 删除：原 `pk_disclaimer_short` 顶部信息条、M2 情景卡（`m2-scenario-card`）、`referenceNotice` 在顶部的展示、“研究依据”链接。
4. **E2 曲线卡**：
   - 标题“E2 曲线”；
   - 3 天 / 7 天胶囊分段控件，默认 3 天；
   - 图表：
     - 窗口为过去 3 天加未来 12 小时，或过去 7 天加未来 24 小时；
     - 3 天时横轴每 12 小时一个刻度（日期加粗 + “12时”）；7 天时每天一个刻度；
     - 合计曲线 3 天线宽约 2.6dp，7 天约 2dp；
     - 化验圆点；
     - 图底部为每次实际服药画一条短竖线（新增 `ChartData` 可选字段，传入已记录服药时刻，只画此刻之前的）；
     - “此刻”竖虚线。
   - 点按：在点旁显示浮动读数卡（日期时间 + 数值 + 单位），点在右半边时卡片出现在左侧，反之亦然；再点同一处或别处可关闭或更换。**不加**“估算值”字样。现有缩放、平移手势保留。
   - 图例：基于记录 / 预测尾部 / 化验结果 / 服药时刻。
   - 删除：区间带绘制与图例、`chart_full_band` 开关、`chart_scale_note`、`pk_chart_hint`、M2 的 `m2_chart_title` / 兼容的 `m2_compatibility_chart` 等两套标题。
   - 单位切换（pg/mL / pmol/L）放在卡片底部，行为不变。
   - 纵轴按可见窗口内的合计曲线和化验值自动缩放到整齐刻度。
5. **化验校准卡**：同一个入口，规则见第 0 节第 9 条；“管理化验结果”按钮保留。
6. **模型与参数**（分组列表）：
   - 体重（可编辑，行为不变）；
   - **模型与文献**：点开进入一个子页面或底部面板，集中放原来散落在页面上的全部说明，文字不删，只是搬家：
     - M2 说明（`m2_scenario_body`）；
     - 计算时间（“情景计算于 …”）、研究依据（原 `referenceNotice` 内容）；
     - `pk_assumptions`、`m2_parameter_scope`、`m2_weight_scope` / `pk_weight_note`、`pk_source`；
     - `ModelsCard`；
     - 新增一句“各途径相加时，背景基线只计一次。”
