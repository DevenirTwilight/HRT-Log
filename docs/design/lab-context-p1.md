# P1 Lab Context：冻结采样上下文

2026-10-07。用户要求继续，先落实原独立设计Lab Context。schema4→5，versionCode10，只维护full/原正式签名，无公开发布，不改PK参数。

问题：已有化验页从所有药物的当前doseTimes找最后一次，不能表达各成分或保留当时关系。新增lab_context_revision（lab_id、revision、captured_utc、origin、context_json），同一化验可有多个冻结版本。context含采样时间/时区/项目、阶段起止/版本快照、各已知成分最近实际事件ID+修订/剂量/途径/输入快照；缺成分的旧导入按药物另列未知。不得用当前药物配置推断实际成分/途径。

新化验录入时按同一数据库事务捕获。编辑数值/备注不重建（明确勾选附估算则新建回推版）；修改采样时间/时区/项目产生新版，旧版保留；显式“重建上下文”新增版本。origin为AT_ENTRY、SAMPLE_CHANGED或RECONSTRUCTED，captured_utc总是实际捕获时间，不冒充采样当时记录。旧化验迁移不回填，显示未保存上下文，可明确重建。删除化验级联删除该化验上下文；普通更新禁止修改已有context行。

附近窗口明确为采样前48小时（产品回顾窗口，不是医学阈值），迟服用已记录LATE状态，MISSED与AUTO_MISSED未确认分开，排除删除/跳过/未来事件。不把未记录写成零风险/正常；各成分并列不表示其与化验有因果关系。阶段按既有半开区间模型，早于记录范围标未知，LEGACY_RULE标回推。

可选PK：用户勾选后附采样时未校准的群体估算，过滤采样后的actual，无计划预测/无lab自校准；保存结果、模型/参数文档、版本/输入记录与缺失说明。只显示已有引擎支持的曲线；不判断正常或建议剂量，不把这次快照称完整历史模型bundle系统。旧版本结果保持冻结。

界面：化验卡片折叠上下文详情，默认最新，可选择旧版；显示采样日期/捕获日期/生成方式、方案与阶段、逐成分actual、48h计数和可选估算。无全局“最近任意药”误关联。CSV新增上下文修订文件；PDF包含最新上下文事实。备份包含新表，schema1–4缺新表可恢复，schema5要求新表；类型/大小/结构/修订顺序与样本字段校验，失败回滚。FK不会强迫旧实际事件一直存在，快照保留历史证据。

本批不含LabPanel/自定义analyte、Visit Pack或自动事实摘要。设计参考本项目longitudinal-hrt-record.md，独立实现，不复制竞品算法/UI。

验收（合成）：多成分不误取、未来/删除排除、已知/未知清楚、48h与边界、暂停/旧rule/未知阶段、当前配置或actual更正不覆写、采样更改新增版/数值编辑不新增、重复重建有序、schema4迁移与旧备份/新往返、恶意context拒绝回滚、四语/详情UI与CSV/PDF。
