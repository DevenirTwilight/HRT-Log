| 来源 | 内容 | 状态 |
|---|---|---|
| PR #19 REQUIREMENTS §65–66 | 用户授权：普通用户只看 M2 舌下游离 E2 文献参考模型，删除三模型选择；私下交付 APK | 用户决定，只在 PR #19 分支 |

**实质张力**：PR #19 的数值是“文献群体情景”，按定义不是个体预测。但它由**用户自己的记录**驱动、带 pg/mL 单位、显示为“当前值”。在用户眼里，功能上等同于个人绝对浓度估计。

改标题或缩小字号**不能**消除这一张力，也**不能**证明科学适用性。任何方案都需要用户书面决定，并把决定同步写进 REQUIREMENTS 和能力说明。不得修改 PR #18 的矩阵来“配合”。

## 2. D-1 三个方案

### 方案 A：保持 PR #19 现状

- 首屏：“M2 文献参考浓度 **312** pg/mL”（大号）+ 曲线 + 化验点同图。
- 必须附加：一段风险接受说明（见下），以及在“研究依据”中写明 PR #18 不允许 `m2_absolute_pgml` 的理由。
- 风险：最可能被读成“我现在的血药浓度”；与能力矩阵正面冲突。
- 需要：用户单独签署风险接受，写入 REQUIREMENTS，并注明“与 P2-BA 能力矩阵冲突，用户知情接受”。

### 方案 B：保留有单位曲线和点读，取消大号当前值，化验另轨（建议审议）

文案草稿（简中；四语需同步翻译和截图验收）：

- 卡片标题：“舌下 E2 文献情景（非你的血药浓度）”
- 卡片正文：“按你记录的舌下剂量和时间，叠加一项 6 名绝经后女性研究（Price 1997）的平均曲线。单位是这个数学情景的单位，不是对你的测量或经验证的预测。”
- 图上：有单位的曲线，点按读数显示“情景值 xxx pg/mL · 时间”；**不显示**大号“当前值”。
- 化验：放在图下方独立的“实测化验”列表或独立轨道，标“实测总 E2，未用于本情景”。
- “研究依据”折叠区：候选 `p2x-39`、B=24、A=434.8、研究人群、8–24 h 尾部不确定、独立外部验证 0、PR #18 用途分级。
- 与能力矩阵的关系：仍然输出由个人记录驱动的绝对单位曲线，与 `m2_absolute_pgml=false` **仍有张力**。B 降低误读，但不消除冲突，需要用户明确接受“条件性情景曲线”这一用途定义，并记录在案。
- 可执行的区分定义（供决策）：
  - “条件性情景”：不显示单一“当前值”主卡；每个数值都带“情景”字样；不与个人化验叠加比较；不提供趋势/目标判断；导出时同样标注。
  - “个体绝对预测”：以“你的浓度/当前浓度”呈现，或与化验比较、或用于判断高低。
  - B 满足前者，**不满足**能力矩阵对“绝对 pg/mL”的禁止。

### 方案 C：默认归一化曲线，绝对情景需显式开启

- 默认纵轴为“相对于 1 mg 后 1 小时的比例”；开关“显示文献情景单位（pg/mL）”，并在开启时显示说明。
- 与 PR #18 一致性最好（`m2_normalized_research` + opt-in）。
- 不符合用户此前“希望有单位曲线”的偏好；代理不得自行选择 C。

### 三方案都必须遵守

- 不改服药/化验原始数据，不改 `calculator_version=1/2` 快照。
- M2 不读取 Legacy 的 LabFit 标定。
- 混合途径只显示舌下分量，并明确“不提供合并总 E2”。
- 页面要统一时间基准：情景值、“现在”竖线、点读时间使用同一个 `asOf`。在页面停留期间定时更新（例如每分钟），或显示“计算于 hh:mm”。目前 PR #19 的 `asOf` 只在记录变化时更新（03 F-PK-8）。
- 顶部只保留一套说明；Legacy 的 `pk_disclaimer_short` 在 M2 模式下替换掉。

## 3. D-2：PDF 与新化验冻结估算

现状（PR #19 未改）：
- `NotesViewModel.exportPdf` → `conc.value.result`（Legacy，含舌下及 5–95% 区间）→ `PdfReport.drawChart`；
- `LabEstimate.capture` → Legacy `ConcentrationCalculator.compute` → 冻结 E2 值和区间。

### 三个选项

| 选项 | PDF | 新化验估算 | 风险 |
|---|---|---|---|
| D2-1 保留 Legacy 并标注 | 图例/标题写“Legacy 历史兼容模型（非 M2）” | 冻结时写 `model: legacy-compat`，界面同样标注 | 用户在 PDF 和页面看到两套舌下数字 |
| **D2-2 新结果中舌下暂不可用（当前倾向）** | 含舌下 E2 时，浓度图写“舌下 E2 模型估算暂不可用”；纯其他途径照旧 | 舌下 E2 冻结为“不可用（M2 未批准用于个体估算）”；其他途径照旧 | 用户失去旧功能；需要明确的空状态 |
| D2-3 暂时禁用“含浓度图”选项 | 选项灰显并说明 | 与 D2-2 相同 | 最简单，但能力损失最大 |

### 兼容性要求（任何选项）

- 旧冻结 JSON（`calculator_version=1/2`）、旧 Visit Pack 记录和 PDF 生成记录**不改写、不重算**；查看时标明“当时的模型”。
- 新增“不可用”语义时，`LabContext` 的 JSON envelope 必须让**旧版本应用**仍能读取（例如新增可选字段 `sl_unavailable_reason`，不改变已有字段的类型）。若需要改 Schema，单独提交迁移设计并再次授权。
- 旧加密备份可以恢复；新数据导出后，旧版本应用打开时不会崩溃（反向兼容至少要能显示“未知字段”）。

### D-2 验收设计（选定后）

- PDF：纯舌下、混合、纯其他途径、无记录四种情况，检查 PDF 文本层的图例/说明。
- 化验：同样四种情况冻结后读回；旧版 fixture（v1/v2 快照）逐字节不变，并可显示。
- 备份往返：schema 1→9 fixture 恢复，新的 LabContext 记录往返。
- Visit Pack：不含浓度图（现状即如此），确认未受影响。
