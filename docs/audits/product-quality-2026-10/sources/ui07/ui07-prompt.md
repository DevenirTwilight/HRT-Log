## 0. 目标与边界

在不改数据、逻辑、计算的前提下，加入 Material 3 Expressive 的四项表现手法：

1. 形状（含实心圆状态图标）；
2. 强调字体；
3. 弹簧动效；
4. 连接式分组列表。

**硬性边界**：
- 不升级 Compose（当前 BOM 2025.10.00 → Material 3 1.4.0）。
- 不使用任何 `@ExperimentalMaterial3ExpressiveApi` 或 `@ExperimentalMaterial3Api` 的新组件。按钮组、分裂按钮、FAB 菜单、波浪加载指示器、可伸缩顶栏等 1.5 正式版后再评估。
- 不新增依赖。图标用 `ImageVector` 或 `Canvas` 自绘。

## 2. 实现

### A. 实心圆状态图标（`core/ui` 新组件 `StatusIcon`）

所有服药状态的图标统一改用此组件，取代文字符号（✓ ✕ ½ ? —）和 UI-05 的各种图标容器。

外形：圆形容器 + 矢量线条图形。线条统一 round cap / round join；线宽为直径的 6.5%（40dp 时约 2.6dp）。

| 状态 | 容器 | 图形 |
|---|---|---|
| 已服（含晚服） | `success.accent` 实心圆（浅色主题即主色 #006A63） | 白色勾 |
| 部分完成 | `missed.container` 实心圆，右半边填 `success.accent` | 无 |
| 漏服 | `missed.container` 实心圆 + `missed.accent` 1.5dp 描边 | `missed.onContainer` 色叉 |
| 跳过 | `skipped.container` 实心圆 | `skipped.onContainer` 色短横 |
| 未确认 | 无填充，`unconfirmed.accent` 虚线描边（划线与间隔约 3:3） | `unconfirmed.onContainer` 色问号 |
| 今天（日历） | 无填充，白色或 `onPrimary` 实线环 | 中心圆点 |

- **尺寸**：提供 40、32、22、18dp 四档。线宽和描边按比例缩放，18dp 时也要清晰可辨。
- **深色主题、中对比度、高对比度**：一律取 UI-06 的对应令牌，不另写颜色。高对比度下描边与图形用 `onSurface`。
- **语义**：组件本身 `contentDescription = null`。状态文字由所在行或日格朗读，不能出现重复朗读。
- **应用位置**：
  - 首页今天卡“今天的记录”行；
  - “还没有记录”确认卡；
  - 日历（月、周、年）日格中的状态标记：日格底色保持 UI-06 规则，**只把标记换成 18dp 的 `StatusIcon`**；
  - 日历图例；
  - 服药记录页的状态；
  - 时间线中的漏服事件。

### B. 形状

- 在 `Tokens.kt`（UI-06 已有 `Corners.tag` 和 `Corners.pill`）中补充档位：`xs 8`、`s 12`、`m 16`、`l 20`、`xl 28`、`xxl 32`、`full`。
- 今天卡改为 32dp 圆角；首页其他卡片（确认卡、库存提醒、最近 7 天）改为 28dp。
- **按下形变**：今天卡“现在服用”、确认卡两个按钮、首页库存“添加库存”按下时，圆角从当前值（完全圆角或 28dp）弹性变为 16dp，同时缩小到 96%；松开后弹回。
  - 用稳定的 `animateDpAsState` / `animateFloatAsState` 加 `spring()`，参考参数 `dampingRatio = 0.6f`、`stiffness = Spring.StiffnessMediumLow`。
  - 交互源用 `MutableInteractionSource.collectIsPressedAsState()`。
  - 写成一个可复用的 `Modifier` 或组件，不在各处复制。
- 今天卡的 ⋮ 按钮改为 56dp、18dp 圆角的描边方块，与主按钮同高。

### C. 强调字体（`core/ui` 字体扩展，如 `NotesTheme.typeExtra`）

新增几种文字样式：

| 名称 | 用途 | 规格（字号 1 时） |
|---|---|---|
| `heroNumber` | 今天卡“下一次”的时间 | 64sp、字重 800、字距 −2sp、等宽数字 |
| `statNumber` | 库存余量、“第 n 天”、下一次服药（已记录状态下） | 28sp、字重 800、等宽数字 |
| `sectionTitle` | 首页各区块标题 | 16sp、字重 700 |
| `cardTitle` | 卡片主标题（药名、确认卡标题） | 20sp、字重 700 |

规则：
- 正文仍为字重 400，不引入新字体，中文使用系统字体。
- **字号放大**：`heroNumber` 和 `statNumber` 随系统字号放大到 1.3 倍后不再继续放大（参考 Android 14 的非线性字体缩放思路，用 `LocalDensity.fontScale` 自行限幅），其余文字照常放大。2× 字号、320dp 下不得截断，时间与“已过时间”标签放不下时换行。在报告中说明这样处理的理由：大号数字本身已远超 WCAG 的大字标准，限幅是为了不挤出主按钮。

### D. 弹簧动效

| 场景 | 动效 |
|---|---|
| 按下按钮 | 第 B 节的圆角与缩放 |
| 记录完成 | 新出现在“今天的记录”里的那一行，其 `StatusIcon` 从 0.3 倍放大到 1 倍并带轻微回弹（约 0.5 秒），整行从上方 14dp 滑入 |
| 今天卡切换到下一次 | 旧内容淡出，新内容淡入并轻微上移（`AnimatedContent` 加 spring） |
| 确认卡回答后 | 确认卡收起为一行结果（`AnimatedVisibility` 加 `expandVertically` / `shrinkVertically` 用 spring） |
| 展开 / 折叠 | UI-04 的“显示全部”、库存“包装记录”的展开用 spring 高度动画 |

- **减少动画**：系统“移除动画”开启（`Settings.Global.ANIMATOR_DURATION_SCALE == 0`）时，所有上述动效改为立即切换。写成一个统一的 `LocalReduceMotion` 并提供测试开关。
- 只做反馈，不做装饰性或循环动画。

**撤销按钮（条件项）**：样图中“已记录”状态带有“撤销”按钮。只有当现有服药记录页的“删除记录（移入回收站）”能完整回退这次服药（包括库存消耗、提醒状态、今天进度）时，才在今天卡显示 4 秒“已记录 · 撤销”，撤销调用同一个现有删除路径。否则**不做撤销**，只保留动效，并在报告中说明原因。不得为此新增写入路径。

### E. 连接式分组列表（`core/ui` 新组件 `GroupedList`）

- 每一项是独立容器，项与项之间留 3dp 缝隙。
- 第一项上方圆角 24dp、下方 6dp；中间项四角 6dp；最后一项上方 6dp、下方 24dp；只有一项时四角 24dp。
- 每项最小高度 56dp，整项可点击，有按压反馈。
- **应用位置**：今天卡下方的“今天的记录”（从今天卡内部移出，改为独立分组列表；今天卡只保留“下一次 / 同一时间 / 稍后”）、服药记录页的每日列表、医疗档案就诊列表、库存卡展开后的包装列表。
- 保留现有点击行为、测试 tag 和语义。

### F. 首页“最近 7 天”（可选，负责人如不需要请删除本节）

样图中，首页的月历换成了“最近 7 天”胶囊日期条（最近 7 天，以今天结尾），右上角有“完整日历”。

- 实现方式：**复用现有周视图的数据**，新增一个“最近 7 天”的显示样式作为首页默认视图。每天一个竖向胶囊：星期、日期、18dp 的 `StatusIcon`；今天用主色填充。
- “完整日历”切换到现有的月视图，原有日、周、月、年切换全部保留。选择用 `rememberSaveable` 保存。
- 日格朗读规则与月视图相同，例如“10月18日，未确认”。
- **不改**日历的数据计算。现有以月视图为前提的测试，改为显式切换到月视图后再断言，原断言含义保留，并逐条说明。

## 3. 测试

先写失败测试，再实现。

1. **`StatusIcon`**：
   - 每种状态的容器、描边、图形正确；
   - 四档尺寸可渲染；
   - 浅色、深色和三档对比度下，图形与容器 ≥ 3:1，容器与背景（或描边与背景）≥ 3:1；
   - 灰度下 5 种状态可区分（截图比对）；
   - 不产生重复朗读。
2. **按下形变**：按下时圆角与缩放到达目标值，松开后恢复；减少动画开启时没有中间帧。
3. **强调字体**：`heroNumber` 在字号 1、1.3、2 下的实际像素尺寸符合限幅规则；2× 字号、320dp 下今天卡不截断，主按钮可见。
4. **动效**：记录完成、今天卡切换、确认卡收起、展开折叠在减少动画开启时立即完成；关闭时最终状态与开启时一致。
5. **`GroupedList`**：一项、两项、多项的圆角规则；56dp 最小高度；点击回调与原列表一致。
6. **撤销（如实现）**：撤销后数据库、库存、今天进度与“在服药记录页删除这条记录”逐字段一致。
7. **最近 7 天（如实现）**：7 天范围、今天高亮、切换到完整日历再返回、进程重建后保留选择、TalkBack 朗读。
