# 身心状态重新设计：设计文档（2026-10-07 审核通过，按 15b 修改）

日期：2026-10-07。依据：`REQUIREMENTS.md` 第 15、15a 节；来源见 `docs/wellbeing-research.md`（下文"研究 §x"）。
**状态：审核通过（`REQUIREMENTS.md` 15b），以下已按审核意见修改，进入实现。** 不改浓度模型代码，不发布版本。

---

## 0. 总原则

1. **不计分、不判断、不给建议。** 不算总分，不显示"正常/异常""偏高/偏低""可能有某某问题"，不对比"应有的效果"。
2. **只原样引用来源。** 症状、监测要求一律来自研究文档里**已核实**的条目，逐字引用并注明出处。未核实的不进界面。不添加来源里没有的话（包括急救电话、"请拨打…"）。
3. **各药同等对待。** 每种药按各自官方来源列出，不额外加警告。没有官方资料的药只说明"无官方资料"。
4. **原创界面。** 条目名称、文案、图标、配色、交互都是新的，不沿用 Trans Memo 的分类和星级打分。
5. **不评判用药方式**（包括自行用药、药物来源）。
6. **地区和界面语言分开设置**；地区只影响"某国的规定"和上报渠道，不减少症状内容。

## 1. 页面结构

"身心状态"页改为三个标签：

| 标签 | 内容 | 频率 |
|---|---|---|
| **今天** | 每日状态（§2）+ 当日备注（沿用现有 `day_note`） | 每天，可跳过 |
| **症状记录** | 按当前在用药物出现的官方症状勾选（§4） | 想记时记 |
| **阶段回顾** | 按 HAS R40 四个方面的阶段记录（§3） | 每月或复诊前 |

页面右上角"复诊摘要"导出 PDF（§7）。

## 2. 每日状态（原创，替换现有 11 项星级）

### 2.1 交互
- 每项是一行**五档滑块**，两端用文字标注（例如"很低 —— 很高"），**不用星星**；不选即为"未记录"。存储仍为 1–5 的整数（与现有数据和 Trans Memo 导入兼容）。
- 图标：每项一个新的线性图标（从 Material Symbols 中选用与 Trans Memo 不同的图标，例如：天气类表示心情、电池表示精力、月亮表示睡眠、手掌表示身体舒适度）。
- 不显示"平均分"文字；统计改为**每项一条小折线**（预留与浓度曲线同一时间轴，§8）。

### 2.2 默认条目（4 项，均为通用概念，名称与描述为原创）

| 键（新） | 中文名 | 两端 | 依据 |
|---|---|---|---|
| `DAY_MOOD` | 今天的心情 | 很低落 —— 很好 | SOC8 12.9 正文要求评估 "psychological well-being"（研究 §2.2）；HAS §4.2.4 "le recueil du ressenti de la personne"（研究 §2.1） |
| `DAY_ENERGY` | 精力 | 很疲惫 —— 很充沛 | 同上（个人感受） |
| `DAY_SLEEP` | 睡得怎么样 | 很差 —— 很好 | 同上 |
| `DAY_BODY` | 身体舒适度 | 很不舒服 —— 很舒服 | 同上；具体不适去"症状记录"勾选 |

用户可以：开关任意条目、调整顺序、**新增自定义条目**（名称自填，同样五档）。

### 2.3 现有数据的去向（见 §9 迁移，15b 第 1 条）
- 旧 `MOOD`、`ENERGY`、`SLEEP_QUALITY` 与新 `DAY_MOOD`、`DAY_ENERGY`、`DAY_SLEEP` 是同一概念（1–5，越高越好）：迁移时**并入新条目**（同一条目改用新键，历史分数原样保留），不再作为旧条目。
- 其余 8 个旧条目（`OVERALL`、`EMO_STABILITY`、`AGGRESSIVENESS`、`LIBIDO`、`PAIN`、`PERIOD_LIKE`、`APPETITE`、`SKIN_QUALITY`）归入"**以前的条目**"分组，名称不加"（旧）"（附录 A）。迁移时**最近 30 天内有记录的保持启用**，没有的默认隐藏；历史折线和导出始终可见，可在"管理条目"里重新开关。
- Trans Memo 导入器：`MOOD`→`DAY_MOOD`、`DYNAMISM`→`DAY_ENERGY`、`SLEEP_QUALITY`→`DAY_SLEEP`；其余映射到以前的条目键。

## 3. 阶段回顾（按 HAS R40 四个方面）

依据：HAS R40 « vérifier la tolérance …, l'efficacité du traitement, les facteurs de risque et la satisfaction de la personne »（研究 §2.1，专家共识 AE）。页面顶部固定说明：
> "这四个方面来自法国 HAS 2025 推荐 R40 中医生复诊时的问诊内容。这里只供你自己记录，不是诊断工具。"

每次阶段回顾一条记录：日期 + 四个部分，全部选填。

### 3.1 效果
- 列出**两份来源共有的效果条目**（研究 §2.2、§2.3）：体脂分布变化、肌肉量和力量减少、皮肤变软/出油减少、性欲减少、自发勃起减少、乳房发育、睾丸体积减小、体毛减少、头发变化。（"精子生成减少"无法自我观察，不列；"声音"两份来源都写不会改变，不列。）
- 每条三档：**还没注意到 / 注意到变化 / 不确定**，加一行自由备注。每个效果条目都可以在"管理条目"里隐藏（15b 第 8 条）。**不显示"按时间应该已出现"之类的比较，不根据用药时长做任何判断。**
- 每条旁边有"来源"按钮：展开显示内分泌学会 2017 Table 13 与 SOC8 附录 C 表 1 的"开始/最大"原文（两列并排，注明两者数值不同、表注 "Estimates represent clinical observations"）。

### 3.2 耐受
- 自动汇总本阶段在"症状记录"里勾过的症状（只列出，不评价）。
- 自由文字："本阶段的其他不适或副作用"。
- 一行说明（来源原话）：HAS R45 « L'évaluation de la tolérance clinique est à considérer au même titre que les dosages sanguins. »（附中文译文，标"译文"）。

### 3.3 风险因素
- 自由文字："本阶段健康情况或其他用药的变化"。
- 是否吸烟：是 / 否 / 不填（依据：HAS R46 提到吸烟是血栓风险因素；内分泌学会 4.1 正文 "tobacco use"，研究 §2.1、§2.3）。
- 血压（收缩压/舒张压，mmHg）、体重（kg）：可选，默认不填，**只存数字，不显示任何范围或评判**（15b 第 7 条，方案 B）。浓度估算仍只用设置里的当前体重。

### 3.4 满意度
- 五档："对目前治疗的满意程度"（很不满意 —— 很满意），加自由文字。**不是量表，不算分**。（没有采用 GENDER-Q、GCLS 等量表，研究 §5。）

## 4. 按药物的症状记录

### 4.1 出现规则
- 根据用户**在用的药物**（分子 + 途径 + 酯型）匹配来源（表 4.3）。停用的药不显示。
- 同一症状出现在多种药的来源里时**只显示一次**，下方注明"来自：A、B"。症状的合并依据是我们给每条原文分配的"症状组"（例如"腿部疼痛或肿胀"），合并只影响显示，每个来源的原话都保留。
- 地区不影响症状内容；所有已核实来源并列显示（例如"法国 ANSM；台湾卫福部"）。

### 4.2 显示与记录
- 每个症状组一行勾选框；勾选 = "今天注意到"。可加备注。**不计数、不打分、不提示"可能是某病"。**
- 名称用当前界面语言的**中性译名**（例如"腿部疼痛或肿胀"），点开显示：
  - 每个来源的**原文原话**（法文、中文原样），出处（文件名、版本/日期、章节、链接），以及来源要求的动作原话（例如 « prévenez immédiatement votre médecin »、"必须立即联系医生"、"儘速回診"、"最好停止用药"）。
  - 非原文语言时附"译文（非官方）"。
- **"立即"醒目显示**（15a 第 2 条）：来源动作原话含 immédiatement / 立即 的症状组放在页面最上方单独一张卡片，标题为来源原词的醒目标签（例如红色徽章「立即」），与普通条目分开；卡片里只有来源原话和出处，**不加任何电话或"去急诊"之类文字**。
- 来源动作只有"尽快""就诊""报告医生"的，放普通区域，原话照录，不升级也不降级。
- 勾选后**不弹窗、不提醒**；只在界面上保留来源原话（"说明书写：…"）。

### 4.3 药物与来源对应（只用研究文档里的已核实来源）

| 在用药物 | 来源（研究 §） | 动作原话中的最强措辞 |
|---|---|---|
| 雌二醇 口服 | PROVAMES notice（§3.1） | « prévenez immédiatement votre médecin » |
| 戊酸雌二醇 口服 | 补佳乐 说明书（第三方转载，§3.2）；PROGYNOVA notice（法国已归档，注明"法国已停售"，§3.1） | "立即停止治疗""必须立即联系医生"；« prévenez immédiatement » |
| 雌二醇 凝胶 | OESTRODOSE、ESTREVA notice（§3.1）；爱斯妥 说明书（第三方转载，§3.2） | « immédiatement »；爱斯妥为"最好停止用药" |
| 雌二醇 贴片 | DERMESTRIL notice（§3.1） | « immédiatement » |
| 雌二醇 / 戊酸雌二醇 舌下 | 按所用产品（口服片）的说明书显示，并注明"说明书未涉及舌下用法"（15b 第 4 条） | 同口服 |
| 醋酸环丙孕酮 | ANDROCUR notice（§3.3）；ANSM 问答（§3.3）；台湾卫福部 2022（§3.3） | « informer immédiatement » / « consultez immédiatement »；ANSM "consultez votre médecin"；台湾"儘速回診" |
| 螺内酯 | 法国、大陆说明书都没有面向患者的就医症状清单 → 显示"官方来源未列出"（15a 第 3 条） | — |
| 孕酮、比卡鲁胺、其他、自定义 | 未调研 / 无官方资料 → 显示"无官方资料" | — |

- **台湾卫福部 2013（CPA + 炔雌醇复方）不用于单方 CPA**，只在用户添加的是复方时才显示（当前药物类型里没有复方，暂不出现）。
- 第三方转载的条目旁标"第三方转载"，并写核准日期、各站修改日期、网址、查看日期（15a 第 4 条）。补佳乐、爱斯妥按"已核实（第三方转载）"使用；tfsci.mtf.wiki 不算独立来源（15b 第 3 条）。
- 来源数据放在随应用打包的 `symptom-sources.json`（版本号 + 每条来源的 id、产品、地区、类型、URL、日期、章节、原文、症状组、动作原话），和浓度参数一样**不写死在代码里**。

### 4.4 "官方监测建议"（按地区显示，注明"某国的规定"）
| 显示条件 | 内容（原话 + 出处） |
|---|---|
| 地区=法国 且 在用螺内酯 | HAS R32：血压、电解质、肌酐（« surveillance de la pression artérielle, ionogramme sanguin et de la créatininémie »，第 19 页） |
| 地区=法国 且 在用 CPA | ANSM：IRM « en début de traitement, à renouveler dans les 5 ans, puis tous les 2 ans »；治疗超过一年每年签署 « attestation d'information »（"法国的规定"） |

## 6. 化验与用药记录的小改动

- **药物来源 / 批号**：在**库存包装**（`supply_container`）上新增两个可选字段 `source_note`（自由文字）和 `batch`；默认不填，不评判来源；在添加包装和库存页里填写，导出中显示（15b 第 5 条）。
- **化验**：沿用现有化验页（单位由用户选择，已支持 pmol/L ↔ pg/mL 等；血钾、肌酐、泌乳素已在列表中）。确认并保持：**不显示目标值，不显示"偏高/偏低"**。用户从化验单抄录的参考范围保留显示，**不变色、不解读**（15b 第 6 条）。

## 7. 复诊摘要（PDF）

复用现有 `Exports.write` 的 PDF 管线，新增一个"复诊摘要"导出，用户选日期范围：
1. 在用药物与方案（不含剂量建议，只照录用户的设置）
2. 服药记录统计（沿用现有）
3. 化验（原值 + 用户选的单位 + 用户抄的参考范围，不解读）
4. 症状勾选：日期、症状组、来源出处
5. 阶段回顾全文
6. 每日状态的简表（每项的记录天数与折线，不算平均分）

页脚注明："本摘要由用户自行记录，不是诊断。"

## 9. 数据结构与迁移

### 9.1 新的表和字段（数据库版本 1 → 2）
| 变更 | 说明 |
|---|---|
| `checkin_item` 新增 `legacy INTEGER NOT NULL DEFAULT 0` | 标记"以前的条目"；MOOD/ENERGY/SLEEP_QUALITY 改键为 DAY_*；补齐缺少的新内置键；其余 8 个旧键 legacy=1，最近 30 天有记录才启用 |
| 新表 `review_effect(effect_id TEXT PK, enabled)` | 阶段回顾效果条目的显示开关（没有行 = 显示） |
| `checkin_score` | 不变（1–5） |
| 新表 `stage_review(id, date, effects_json, tolerance_note, risk_note, smoking, systolic, diastolic, weight_kg, satisfaction, satisfaction_note)` | 阶段回顾；效果每条三档存 JSON（键为效果 id）；血压、体重可选 |
| 新表 `symptom_check(date, group_id, note, PRIMARY KEY(date, group_id))` | 症状勾选；`group_id` 引用 `symptom-sources.json` 中的症状组 |
| `supply_container` 新增 `source_note TEXT NULL`、`batch TEXT NULL` | 药物来源 / 批号 |
| `SchemaGuards` | 为新表加约束触发器（日期格式、取值范围），与现有表一致 |

### 9.2 Room 迁移
- 手写 `Migration(1, 2)`（`ALTER TABLE … ADD COLUMN` + `CREATE TABLE`），全部是新增，**不改动、不删除现有数据**；迁移后按 §2.3 并入/标记旧条目（"最近 30 天"以迁移当天为准），补齐新内置条目。
- 导出 schema 2，用 Room `MigrationTestHelper` 写迁移测试（Robolectric）：用 schema 1 建库并写入合成数据 → 迁移 → 检查所有原有行、分数、备注逐行相同；MOOD/ENERGY/SLEEP_QUALITY 的分数并入 DAY_*；其余旧条目按最近 30 天是否有记录决定启用；新表为空。

### 9.3 旧备份恢复（硬性要求，15a 第 1 条）
- 现状：`restoreBackup` 要求备份的 schema 等于当前版本，否则拒绝。
- 改为：读取备份 JSON 的 `schema`：
  - 等于当前版本 → 原样恢复。
  - **小于当前版本** → 先在内存中按顺序执行"备份升级"（v1→v2：给 `checkin_item` 每行补 `legacy` 并按迁移规则赋值、插入新内置条目、给 `supply_container` 每行补两个空字段、新表为空），再恢复。升级规则与 Room 迁移共用同一份常量，测试两条路径结果一致。
  - 大于当前版本 → 拒绝，提示"备份来自更新的版本"。
- 测试（合成数据，不用真实备份）：在仓库里提交一份**由当前 0.2.0 代码生成的合成 v1 备份**（固定测试密码，内容全为合成药名/记录）作为测试资源；测试用新版代码恢复它，检查药物、服药记录、库存账本、身心分数、备注、化验全部还原；并入新条目和按最近使用决定隐藏都正确（恢复时以传入的"今天"为准）。另测：备份升级结果 == Room 迁移结果。
- 伪装模式开启前强制导出的就是这种备份，因此这项测试作为发布前必过项。

### 9.4 Trans Memo 导入器
导入器继续把 Trans Memo 的分类映射到旧内置键（导入的分数进入"以前的条目"），对应的合成数据测试保持通过；导入不会写入新的 4 个条目。

## 10. 血压和体重（审核选定方案 B）

阶段回顾里可选记录收缩压/舒张压（mmHg）和体重（kg），默认不填，只存数字，不显示任何范围或评判；导出复诊摘要时原样列出。浓度估算仍只用设置里的当前体重（15b 第 7 条）。

---|---|---|
| A. 不记录（现状） | 阶段回顾不涉及血压、体重 | 无 |
| B. 阶段回顾里可选记一次 | 收缩压/舒张压（mmHg）、体重（kg），只存数字，不显示任何范围或评判 | 新增字段；体重历史会出现，需要改"没有体重历史"的规则，浓度页仍只用当前体重 |
| C. 独立的测量记录 | 新表按日期记录血压、体重，画折线 | 改动最大；同样需要改规则 |
