<summary>English</summary>

This emergency hotfix replaces the original 0.2.0 downloads. The displayed version remains 0.2.0; Android build number increases to 4. The code has not been rolled back.

- Fixes inventory duration, stale data across screens, repeated encrypted-database errors and access to real data after disguise unlock.
- Imported doses can be explicitly linked to a daily schedule without guessing or deducting stock twice.
- Calculator/Notes remain usable without a password. The real secret opens HRT; the alternate code opens independent encrypted Private Notes with CRUD and no HRT UI.
- Removes the redundant PIN after real disguise authentication; preserves lock-on-leave and normal App Lock. Uses neutral system/task/notification identity.
- Includes the independently rewritten literature-based concentration models and lab fitting. The old ported engine is removed. Estimates differ from the original release and cannot replace lab tests or provide dosing advice.

Choose the full APK with disguise, or play without it. Both share an application ID and the existing private production signing certificate. **Production 0.2.0 installations can update in place without uninstalling; back up first. Debug-signed CI installations cannot be overwritten by a production-signed APK: export an encrypted backup and keep its password before changing installations and restoring. Uninstalling deletes local data.**

Private Notes are excluded from HRT backups; removing the alternate code or disabling disguise erases them. Static APK analysis, installation origin, signatures, old system caches and exported medical documents may reveal the app. OEM devices, biometric hardware, battery policies, vendor pickers and backup restoration still need physical-device validation.

Source and CI links are above. The implementation passed 200 unit tests (2 PDF tests skipped due to Robolectric), 28 real Android tests including two-process restart, lint and full/play release builds. Checksums and the unchanged public production-certificate fingerprint are attached. Third-party notices reflect removal of the old ported model; no upstream permission is claimed.
