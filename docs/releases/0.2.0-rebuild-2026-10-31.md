**这是用默认分支最新代码重新构建的 0.2.0。** 版本名仍为 0.2.0，源码 commit `f112e10`。此前的公开文件（源码 `76627bf`）已从本页移除，其哈希留档在仓库 `docs/releases/`。

主要功能：

- 完全离线：不申请 INTERNET 权限，无账户、无统计、无广告。“关于”页的外部链接只在你点击时用浏览器打开。
- 用药计划与提醒、库存与补药提醒；服药记录、历史与回收站。
- 按已发表研究估算的雌二醇（E2）浓度曲线，可用你录入的化验值校准。曲线是有条件的估算，不是你本人的血药测量，不能代替化验，也不提供剂量建议。
- 化验记录（可批量录入）、身体状态（症状与感受）记录、复诊与问题清单、就诊资料包。
- 医疗档案：你主动添加的 PDF / 图片文件加密保存在应用私有存储中，可在应用内阅读（Android 9 及以上的 PDF 支持翻页与缩放，图片可缩放）。
- 治疗阶段时间线与里程碑。
- PDF 报告与就诊资料导出、CSV 导出。**导出文件不加密**，保存到哪里由你在系统文件选择器中决定。
- 应用锁（PIN，可选生物识别）；记录保存在 SQLCipher 加密数据库中。
- 加密备份（`.pnbak`，Argon2id + AES-256-GCM，密码由你设定，忘记无法找回）；包含医疗文件的完整医疗加密备份是另一种文件（`.pnmedbk2`），同样需要你设定的密码。
- 计算器 / 记事本伪装（`full` 版）。记事本伪装界面里输入的文字不加密，请勿写入敏感内容。伪装不能防御 root、系统被攻破或查看已安装应用列表。
- 简体中文、繁體中文、English、Français 四种语言。

本次重新构建的界面变化：中性暖白底色；青绿主色不变，蓝 / 紫 / 玫红只用于图标块、标签、日期方块等小面积点缀（化验与浓度估算为紫，复诊与医疗档案为蓝，身心状态为玫红）；复诊页新增顶部卡片与日期方块；校准卡的三个按钮放在同一个自动换行的行里；PDF 文件方块用蓝色。

**升级：** 使用同一私有正式签名（证书 SHA-256 见 `SIGNING_CERTIFICATE.txt`），此前公开版和私下测试版都可直接覆盖安装，保留本机数据；建议先导出加密备份，不要卸载或清除数据。CI 调试签名版无法直接覆盖，需先导出加密备份并保留密码，再换装、恢复。卸载会删除本机数据。

隐私说明见仓库 `PRIVACY.md`（应用内“关于 → 隐私”可离线查看四语版本）。真机 ARM 覆盖安装与人工读屏（TalkBack）尚未实测（NOT_RUN）。`SHA256SUMS.txt` 为附件校验摘要。

<summary>English</summary>

**This is 0.2.0 rebuilt from the current default branch.** The displayed version stays 0.2.0. Source commit `f112e10`. The previous public files (source `76627bf`) have been removed from this page; their hashes are archived in the repository under `docs/releases/`.

Main features:

- Fully offline: no INTERNET permission, no account, analytics or ads. The external link on the About screen only opens your browser when you tap it.
- Medication schedules and reminders, stock and refill reminders; dose records, history and recycle bin.
- Estradiol (E2) concentration curves estimated from published studies, optionally calibrated with lab values you enter. They are conditional estimates, not measurements of your own blood levels; they cannot replace lab tests and give no dosing advice.
- Lab records (with batch entry), wellbeing (symptoms and how you feel) records, appointments and question lists, visit packs.
- Medical records: PDF / image files you add yourself are stored encrypted in the app's private storage and can be read in the app (on Android 9 and newer the PDF reader supports page navigation and zoom; images can be zoomed).
- Treatment stage timeline and milestones.
- PDF report and visit pack export, CSV export. **Exports are not encrypted**; you choose where they are saved in Android's file picker.
- App lock (PIN, optional biometrics); records are stored in a SQLCipher-encrypted database.
- Encrypted backups (`.pnbak`, Argon2id + AES-256-GCM, password chosen by you; a forgotten password cannot be recovered). The complete medical encrypted backup that includes medical files is a separate file type (`.pnmedbk2`) and also needs a password you choose.
- Calculator / Notes disguise (`full` flavor). Text typed into the Notes disguise screen is not encrypted. Disguise does not protect against root, a compromised system or someone inspecting installed apps.
- Simplified Chinese, Traditional Chinese, English and French.

Interface changes in this rebuild: a neutral warm-white base; the main teal stays, while blue / purple / rose are used only as small accents on icon tiles, tags and date tiles (labs and concentration estimates purple, visits and medical records blue, wellbeing rose); a header card and date tiles on the visits page; the three calibration-card actions share one wrapping row; PDF file tiles are blue.

**Updating:** same private production signing key (certificate SHA-256 in `SIGNING_CERTIFICATE.txt`). Earlier public and private test versions can be updated in place, keeping local data; export an encrypted backup first and do not uninstall or clear data. Debug-signed CI installations cannot be overwritten: export an encrypted backup and keep its password before switching and restoring. Uninstalling deletes local data.

Privacy notice: `PRIVACY.md` in the repository (also offline in the app, About → Privacy, in four languages). In-place update on a physical ARM device and manual screen-reader (TalkBack) testing have not been done (NOT_RUN). `SHA256SUMS.txt` lists the asset checksums.

- Analyses (saisie par lot possible), suivi du bien-être (symptômes et ressenti), rendez-vous et listes de questions, dossiers de consultation.
